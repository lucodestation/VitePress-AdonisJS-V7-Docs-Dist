终端 UI ​

本指南涵盖终端 UI 的各个方面。你将了解到以下主题：

  • 显示不同严重级别的日志消息
  • 添加加载动画和操作指示器
  • 使用颜色格式化文本
  • 渲染具有自定义对齐方式的表格
  • 使用贴纸创建带边框的内容
  • 构建带进度更新的动画任务运行器

概述 ​

Ace 终端 UI 由 @poppinss/cliui 包提供支持，它提供用于显示日志、渲染表格、显示动画任务等的辅助函数。

所有终端 UI 原语都以测试为设计目标。编写测试时，你可以启用“raw”模式以禁用颜色和格式化，使得在内存中收集日志并对其编写断言变得容易。这种设计确保你的命令在为用户提供丰富视觉体验的同时保持可测试性。

显示日志消息 ​

CLI 日志记录器提供用于显示不同严重级别消息的方法。每个日志级别使用不同的颜色和图标，帮助用户快速识别消息的重要性。

ts
import { BaseCommand } from '@adonisjs/core/ace'

export default class DeployCommand extends BaseCommand {
  static commandName = 'deploy'

  async run() {
    /**
     * 调试消息 - 有助于故障排查
     */
    this.logger.debug('Loading deployment configuration')

    /**
     * 信息消息 - 一般信息
     */
    this.logger.info('Deploying application to production')

    /**
     * 成功消息 - 操作成功完成
     */
    this.logger.success('Deployment completed successfully')

    /**
     * 警告消息 - 潜在问题
     */
    this.logger.warning('SSL certificate expires in 30 days')

    /**
     * 错误和致命消息 - 写入 stderr
     */
    this.logger.error(new Error('Failed to upload assets'))
    this.logger.fatal(new Error('Deployment failed completely'))
  }
}

error 和 fatal 方法写入 stderr 而不是 stdout，使用户更容易将错误输出与正常输出分开重定向。

添加前缀和后缀 ​

你可以为日志消息添加前缀和后缀文本以提供额外上下文。前缀和后缀都以降低的不透明度显示，以区别于主消息。

ts
/**
 * 添加显示正在运行的命令的后缀
 */
this.logger.info('Installing packages', {
  suffix: 'npm i --production'
})

/**
 * 添加显示进程 ID 的前缀
 */
this.logger.info('Starting worker', {
  prefix: process.pid
})

创建加载动画 ​

加载动画在消息后显示动画点，在长时间运行的操作期间提供视觉反馈。你可以在操作完成时更新消息文本并停止动画。

ts
/**
 * 创建加载动画
 */
const animation = this.logger.await('Installing packages', {
  suffix: 'npm i'
})

/**
 * 启动动画
 */
animation.start()

/**
 * 随进度继续更新消息
 */
setTimeout(() => {
  animation.update('Unpacking packages', {
    suffix: undefined
  })
}, 2000)

/**
 * 完成时停止动画
 */
setTimeout(() => {
  animation.stop()
  this.logger.success('Installation complete')
}, 4000)

显示操作状态 ​

日志记录器操作提供一致的方式来显示操作状态，具有自动样式和颜色编码。这在执行多个顺序任务时特别有用。

ts
/**
 * 创建操作指示器
 */
const createFile = this.logger.action('creating config/auth.ts')

try {
  await this.createConfigFile()

  /**
   * 将操作标记为成功
   * 可选：显示耗时
   */
  createFile.displayDuration().succeeded()
} catch (error) {
  /**
   * 将操作标记为失败并附带错误
   */
  createFile.failed(error)
}

操作可以标记为三种不同的状态：

ts
/**
 * 操作成功完成
 */
action.succeeded()

/**
 * 操作被跳过并附带原因
 */
action.skipped('File already exists')

/**
 * 操作失败并附带错误
 */
action.failed(new Error('Permission denied'))

使用颜色格式化文本 ​

Ace 使用 kleur 为文本应用 ANSI 颜色代码。通过 this.colors 属性访问 kleur 的链式 API，以前景色、背景色和文本样式格式化文本。

ts
import { BaseCommand } from '@adonisjs/core/ace'

export default class StatusCommand extends BaseCommand {
  static commandName = 'status'

  async run() {
    /**
     * 应用前景色
     */
    this.logger.info(this.colors.red('[ERROR]'))
    this.logger.info(this.colors.green('[SUCCESS]'))
    this.logger.info(this.colors.yellow('[WARNING]'))

    /**
     * 组合背景色和前景色
     */
    this.logger.info(this.colors.bgGreen().white(' CREATED '))
    this.logger.info(this.colors.bgRed().white(' FAILED '))

    /**
     * 应用文本样式
     */
    this.logger.info(this.colors.bold('Important message'))
    this.logger.info(this.colors.dim('Less important details'))
  }
}

渲染表格 ​

表格将数据组织成行和列，使用户易于浏览和比较信息。使用 this.ui.table 方法创建表格，它返回一个 Table 实例用于定义表头和行。

ts
import { BaseCommand } from '@adonisjs/core/ace'

export default class ListMigrationsCommand extends BaseCommand {
  static commandName = 'migration:list'

  async run() {
    /**
     * 创建新表格
     */
    const table = this.ui.table()

    /**
     * 定义表头
     */
    table.head([
      'Migration',
      'Duration',
      'Status',
    ])

    /**
     * 添加表格行
     */
    table.row([
      '1590591892626_tenants.ts',
      '2ms',
      'DONE'
    ])

    table.row([
      '1590595949171_entities.ts',
      '2ms',
      'DONE'
    ])

    /**
     * 将表格渲染到终端
     */
    table.render()
  }
}

你可以通过用颜色方法包裹值来对任何表格单元格应用颜色格式化。

ts
table.row([
  '1590595949171_entities.ts',
  '2ms',
  this.colors.green('DONE')
])

table.row([
  '1590595949172_users.ts',
  '5ms',
  this.colors.red('FAILED')
])

右对齐列 ​

默认情况下，所有列都是左对齐的。你可以通过将列定义为带有 hAlign 属性的对象来右对齐列。右对齐列时，请确保也右对齐相应的表头。

ts
/**
 * 右对齐状态列表头
 */
table.head([
  'Migration',
  'Batch',
  {
    content: 'Status',
    hAlign: 'right'
  },
])

/**
 * 右对齐状态列数据
 */
table.row([
  '1590595949171_entities.ts',
  '2',
  {
    content: this.colors.green('DONE'),
    hAlign: 'right'
  }
])

渲染全宽表格 ​

默认情况下，表格自动调整列大小以适合其内容。但是，你可以使用 fullWidth 方法以完整终端宽度渲染表格。

在全宽模式下，除一列外的所有列使用其内容宽度，而指定的“流式”列扩展以填充剩余空间。默认情况下，第一列是流式的。

ts
/**
 * 以完整终端宽度渲染表格
 */
table.fullWidth().render()

你可以使用 fluidColumnIndex 方法更改哪一列扩展以填充可用空间。

ts
/**
 * 使第二列（索引 1）成为流式列
 */
table
  .fullWidth()
  .fluidColumnIndex(1)
  .render()

使用贴纸创建带边框的内容 ​

贴纸在带边框的框中渲染内容，将用户注意力吸引到重要信息上，如服务器地址、配置说明或关键后续步骤。

ts
import { BaseCommand } from '@adonisjs/core/ace'

export default class ServeCommand extends BaseCommand {
  static commandName = 'serve'

  async run() {
    /**
     * 创建用于显示服务器信息的贴纸
     */
    const sticker = this.ui.sticker()

    sticker
      .add('Started HTTP server')
      .add('')
      .add(`Local address:   ${this.colors.cyan('http://localhost:3333')}`)
      .add(`Network address: ${this.colors.cyan('http://192.168.1.2:3333')}`)
      .render()
  }
}

对于显示分步说明，使用 this.ui.instructions 方法代替。它为每一行添加箭头符号（>）前缀，清楚地表明这些是操作项。

ts
/**
 * 显示安装后说明
 */
const instructions = this.ui.instructions()

instructions
  .add('Run npm install to install dependencies')
  .add('Copy .env.example to .env and configure your environment')
  .add('Run node ace migrate to set up the database')
  .render()

构建动画任务运行器 ​

任务部件提供精致的 UI，用于执行和显示多个耗时操作的进度。它支持两种渲染模式：精简模式（用于生产使用）和详细模式（用于调试）。

在精简模式下，只有当前正在运行的任务展开以显示进度更新。在详细模式下，每条进度消息都记录在自己的行上，使调试问题更容易。

创建基本任务 ​

使用 this.ui.tasks 方法创建任务部件，然后使用 add 方法添加单个任务。

ts
import { BaseCommand } from '@adonisjs/core/ace'

export default class SetupCommand extends BaseCommand {
  static commandName = 'setup'

  async run() {
    /**
     * 创建任务部件
     */
    const tasks = this.ui.tasks()

    /**
     * 添加任务并执行它们
     */
    await tasks
      .add('clone repo', async (task) => {
        await this.cloneRepository()
        return 'Completed'
      })
      .add('update package file', async (task) => {
        try {
          await this.updatePackageFile()
          return 'Updated'
        } catch (error) {
          return task.error('Unable to update package file')
        }
      })
      .add('install dependencies', async (task) => {
        await this.installDependencies()
        return 'Installed'
      })
      .run()
  }
}

每个任务回调必须返回状态消息。返回普通字符串表示成功，而将返回值包裹在 task.error() 中表示失败。你也可以抛出异常将任务标记为失败。

报告任务进度 ​

在任务回调内不要使用 console.log 或 this.logger，而是使用 task.update 方法报告进度。这确保进度更新在精简模式和详细模式下都正确显示。

ts
/**
 * 模拟异步工作的辅助函数
 */
const sleep = () => new Promise<void>((resolve) => setTimeout(resolve, 50))

const tasks = this.ui.tasks()

await tasks
  .add('clone repo', async (task) => {
    /**
     * 任务执行时报告进度
     */
    for (let i = 0; i <= 100; i = i + 2) {
      await sleep()
      task.update(`Downloaded ${i}%`)
    }

    return 'Completed'
  })
  .run()

在精简模式下，只有最新进度消息可见。在详细模式下，所有消息在发生时记录。

启用详细模式 ​

你可能想允许用户启用详细输出以进行调试。这通常通过接受 --verbose 标志来完成。

ts
import { BaseCommand, flags } from '@adonisjs/core/ace'

export default class DeployCommand extends BaseCommand {
  static commandName = 'deploy'

  /**
   * 接受详细标志
   */
  @flags.boolean({
    description: 'Enable verbose output'
  })
  declare verbose: boolean

  async run() {
    /**
     * 根据标志启用详细模式
     */
    const tasks = this.ui.tasks({
      verbose: this.verbose
    })

    await tasks
      .add('build assets', async (task) => {
        // 任务实现
      })
      .run()
  }
}

用户现在可以使用 --verbose 运行你的命令以查看详细的进度日志进行调试。
