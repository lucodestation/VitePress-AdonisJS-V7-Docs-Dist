Prompt ​

本指南涵盖在自定义命令中使用 prompt。你将了解到以下主题：

  • 显示文本和密码输入提示
  • 创建单选和多选列表
  • 使用确认和切换提示
  • 验证和转换用户输入
  • 使用自动完成进行可搜索列表
  • 测试带 prompt 的命令

概述 ​

Prompt 通过允许用户通过直观的终端控件而不是命令行参数或标志提供输入，实现交互式命令行体验。这对于需要引导用户完成多步骤流程、收集密码等敏感信息或允许从选项列表中选择的命令特别有用。

Ace prompt 由 @poppinss/prompts 包提供支持，它支持多种 prompt 类型，包括文本输入、密码字段、确认、单选和多选列表以及自动完成搜索。所有 prompt 都支持验证、默认值以及在用户输入返回给你的命令之前对其进行转换。

Ace prompt 的一个关键特性是其测试支持。编写测试时，你可以捕获 prompt 并以编程方式响应它们，使得测试交互式命令变得容易，而无需手动输入。

显示文本输入 ​

文本输入 prompt 接受来自用户的自由格式文本。使用 this.prompt.ask 方法显示文本输入 prompt，将提示消息作为第一个参数提供。

ts
import { BaseCommand } from '@adonisjs/core/ace'

export default class MakeModelCommand extends BaseCommand {
  static commandName = 'make:model'

  async run() {
    /**
     * 询问模型名称
     */
    const modelName = await this.prompt.ask('Enter the model name')

    this.logger.info(`Creating model: ${modelName}`)
  }
}

添加验证 ​

你可以通过在 options 对象中提供 validate 函数来验证用户输入。该函数接收用户的输入，应返回 true 接受值，或返回错误消息字符串拒绝它。

ts
const modelName = await this.prompt.ask('Enter the model name', {
  validate(value) {
    return value.length > 0
      ? true
      : 'Model name is required'
  }
})

如果验证失败，prompt 显示错误消息并再次请求输入，直到用户提供有效值。

提供默认值 ​

默认值作为建议出现，用户可以通过按 Enter 接受。这对于提供常见值或合理的默认值很有用。

ts
const modelName = await this.prompt.ask('Enter the model name', {
  default: 'User'
})

收集密码 ​

密码 prompt 在终端中屏蔽用户输入，用星号或圆点替换每个字符。这对于收集密码、API 密钥或令牌等敏感信息至关重要。

使用 this.prompt.secure 方法显示密码 prompt。

ts
import { BaseCommand } from '@adonisjs/core/ace'

export default class SetupCommand extends BaseCommand {
  static commandName = 'setup'

  async run() {
    /**
     * 安全地收集数据库密码
     */
    const password = await this.prompt.secure('Enter database password')

    this.logger.info('Password collected securely')
  }
}

你可以像文本输入一样为密码 prompt 添加验证。

ts
const password = await this.prompt.secure('Enter account password', {
  validate(value) {
    return value.length >= 8
      ? true
      : 'Password must be at least 8 characters long'
  }
})

创建选择列表 ​

选择 prompt 显示一个选项列表，用户可以使用箭头键导航并按 Enter 选择。当你需要用户从预定义选项中挑选时，这是理想的选择。

使用 this.prompt.choice 方法显示单选列表。该方法接受提示消息作为第一个参数，选项数组作为第二个参数。

ts
import { BaseCommand } from '@adonisjs/core/ace'

export default class ConfigureCommand extends BaseCommand {
  static commandName = 'configure'

  async run() {
    /**
     * 让用户选择他们的包管理器
     */
    const packageManager = await this.prompt.choice('Select package manager', [
      'npm',
      'yarn',
      'pnpm'
    ])

    this.logger.info(`Using ${packageManager}`)
  }
}

自定义选项显示 ​

当你希望显示文本与返回值不同时，将选项定义为带有 name 和 message 属性的对象。name 是你的命令接收的内容，而 message 是用户看到的内容。

ts
const driver = await this.prompt.choice('Select database driver', [
  {
    name: 'sqlite',
    message: 'SQLite'
  },
  {
    name: 'mysql',
    message: 'MySQL'
  },
  {
    name: 'pg',
    message: 'PostgreSQL'
  }
])

this.logger.info(`Selected driver: ${driver}`)
// 如果用户选择 "PostgreSQL"，driver 将为 "pg"

允许多选 ​

多选 prompt 让用户使用空格键切换选择，从列表中选择多个选项。当用户需要选择多个功能、包或配置时，这很有用。

使用 this.prompt.multiple 方法显示多选列表。参数与选择 prompt 相同。

ts
import { BaseCommand } from '@adonisjs/core/ace'

export default class InstallCommand extends BaseCommand {
  static commandName = 'install:packages'

  async run() {
    /**
     * 让用户选择多个数据库驱动
     */
    const drivers = await this.prompt.multiple('Select database drivers', [
      {
        name: 'sqlite',
        message: 'SQLite'
      },
      {
        name: 'mysql',
        message: 'MySQL'
      },
      {
        name: 'pg',
        message: 'PostgreSQL'
      }
    ])

    this.logger.info(`Installing drivers: ${drivers.join(', ')}`)
  }
}

该方法返回所选值的数组。用户可以选择全部、部分或不选择任何选项。

确认操作 ​

确认 prompt 要求用户回答是或否的问题。它们对于破坏性操作或需要用户明确同意的操作至关重要。

使用 this.prompt.confirm 方法显示是/否确认。该方法返回布尔值。

ts
import { BaseCommand } from '@adonisjs/core/ace'

export default class ResetCommand extends BaseCommand {
  static commandName = 'db:reset'

  async run() {
    /**
     * 删除数据之前确认
     */
    const shouldDelete = await this.prompt.confirm(
      'Want to delete all files?'
    )

    if (shouldDelete) {
      this.logger.warning('Deleting all files...')
      // 执行删除
    } else {
      this.logger.info('Operation cancelled')
    }
  }
}

自定义是/否标签 ​

如果你希望将是/否标签自定义为更具上下文的内容，使用 this.prompt.toggle 方法。该方法接受两个字符串的数组，分别用于是和无标签。

ts
const shouldDelete = await this.prompt.toggle(
  'Want to delete all files?',
  ['Yup', 'Nope']
)

if (shouldDelete) {
  this.logger.warning('Deleting all files...')
}

使用自动完成 ​

自动完成 prompt 结合了选择与搜索功能，允许用户对大量选项进行模糊搜索。当处理在标准选择列表中难以操作的众多选项时，这特别有用。

使用 this.prompt.autocomplete 方法显示可搜索列表。

ts
import { BaseCommand } from '@adonisjs/core/ace'

export default class SelectCityCommand extends BaseCommand {
  static commandName = 'select:city'

  async run() {
    /**
     * 让用户从大量列表中搜索并选择
     */
    const selectedCity = await this.prompt.autocomplete(
      'Select your city',
      await this.getCitiesList()
    )

    this.logger.info(`You selected: ${selectedCity}`)
  }

  private async getCitiesList() {
    /**
     * 返回大量城市名称数组
     */
    return [
      'New York',
      'Los Angeles',
      'Chicago',
      'Houston',
      // ... 还有数百个城市
    ]
  }
}

用户可以输入以过滤列表，prompt 将基于模糊搜索显示匹配的选项。

理解 Prompt 选项 ​

所有 prompt 类型都通过第二个参数接受一组通用选项。这些选项允许你自定义 prompt 行为、验证输入和转换返回值。

选项接受的 prompt描述
default所有 prompt未输入值时使用的默认值。对于 select、multiselect 和 autocomplete prompt，值必须是选项数组索引。
name所有 promptprompt 的唯一名称，用于在测试中识别 prompt。
hint所有 prompt显示在 prompt 旁边的提示文本，为用户提供额外上下文。
result所有 prompt转换 prompt 返回值。输入值取决于 prompt 类型（例如，multiselect 返回所选选项的数组）。
format所有 prompt在用户输入时实时格式化输入值。格式化仅应用于 CLI 输出，不应用于返回值。
validate所有 prompt验证用户输入。返回 true 接受值，或返回字符串错误消息拒绝它。
limitautocomplete限制显示的选项数量。用户需要滚动才能看到更多选项。

转换返回值 ​

result 函数转换 prompt 返回的值。这对于将用户输入转换为不同格式或类型很有用。

ts
const modelName = await this.prompt.ask('Enter the model name', {
  result(value) {
    /**
     * 转换为 PascalCase 用于类名
     */
    return value.charAt(0).toUpperCase() + value.slice(1)
  }
})

格式化显示值 ​

format 函数改变用户输入时输入在终端中的显示方式，而不影响实际返回值。

ts
const email = await this.prompt.ask('Enter your email', {
  format(value) {
    /**
     * 用户输入时将电子邮件显示为小写
     */
    return value.toLowerCase()
  }
})

添加提示 ​

提示提供出现在 prompt 旁边的额外上下文或说明。

ts
const tableName = await this.prompt.ask('Enter table name', {
  hint: 'Use plural form (e.g., users, posts)'
})
