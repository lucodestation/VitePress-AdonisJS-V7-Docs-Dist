命令参数 ​

本指南涵盖在自定义命令中定义命令参数。你将了解到以下主题：

  • 定义位置参数
  • 使参数可选
  • 接受多个值
  • 转换参数值

概述 ​

参数是用户在执行命令时在命令名称之后提供的位置值。与可以按任意顺序指定的标志不同，参数必须按照它们在命令类中定义的准确顺序提供。

例如，在命令 node ace make:controller users --resource 中，单词 users 是一个参数，而 --resource 是一个标志。参数非常适合具有自然顺序的必需输入值，如文件名、资源名称或实体标识符。

定义你的第一个参数 ​

你将命令参数定义为使用 @args 装饰器装饰的类属性。Ace 将按照它们在类中出现的相同顺序接受参数，因此属性顺序很重要。

最常见的参数类型是字符串参数，它接受任何文本值。使用 @args.string 装饰器定义字符串参数。

ts
import { BaseCommand, args } from '@adonisjs/core/ace'

export default class GreetCommand extends BaseCommand {
  static commandName = 'greet'
  static description = 'Greet a user by name'

  /**
   * 定义一个必需的字符串参数
   */
  @args.string()
  declare name: string

  async run() {
    this.logger.info(`Hello, ${this.name}!`)
  }
}

用户现在可以通过为 name 参数提供值来运行你的命令。

sh
node ace greet John

# 输出：Hello, John!

如果用户忘记提供必需的参数，Ace 将显示一条错误消息，指示缺少哪个参数。

接受多个值 ​

有些命令需要为单个参数接受多个值。例如，处理多个文件的命令可能接受任意数量的文件名。

使用 @args.spread 装饰器接受多个值。spread 参数必须是你命令中的最后一个参数，因为它捕获所有剩余的值。

ts
import { BaseCommand, args } from '@adonisjs/core/ace'

export default class GreetCommand extends BaseCommand {
  static commandName = 'greet'
  static description = 'Greet multiple users by name'

  /**
   * 接受多个名称作为数组
   */
  @args.spread()
  declare names: string[]

  async run() {
    this.names.forEach((name) => {
      this.logger.info(`Hello, ${name}!`)
    })
  }
}

用户现在可以在运行命令时提供任意数量的值。

sh
node ace greet John Jane Bob

# 输出：
# Hello, John!
# Hello, Jane!
# Hello, Bob!

自定义参数名称和描述 ​

参数名称出现在帮助屏幕和错误消息中。默认情况下，Ace 使用你的属性名称的短横线命名版本作为参数名称。例如，名为 userName 的属性在帮助输出中变为 user-name。

你可以使用 argumentName 选项自定义参数名称。

ts
@args.string({
  argumentName: 'user-name'
})
declare name: string

添加描述帮助用户理解他们应该提供什么值。当用户运行 node ace greet --help 时，描述出现在帮助屏幕中。

ts
@args.string({
  argumentName: 'user-name',
  description: 'Name of the user to greet'
})
declare name: string

使参数可选 ​

所有参数默认都是必需的，确保用户在你的命令执行之前提供必要的输入。但是，你可以通过将 required 选项设置为 false 使参数可选。

可选参数必须在所有必需参数之后。此顺序要求防止参数解析中的歧义。

ts
import { BaseCommand, args } from '@adonisjs/core/ace'

export default class GreetCommand extends BaseCommand {
  static commandName = 'greet'

  @args.string({
    description: 'Name of the user to greet'
  })
  declare name: string

  /**
   * 带有自定义措辞的可选问候消息
   */
  @args.string({
    description: 'Custom greeting message',
    required: false,
  })
  declare message?: string

  async run() {
    const greeting = this.message || 'Hello'
    this.logger.info(`${greeting}, ${this.name}!`)
  }
}

现在用户可以在有或没有第二个参数的情况下运行命令。

sh
node ace greet John
# 输出：Hello, John!

node ace greet John "Good morning"
# 输出：Good morning, John!

提供默认值 ​

你可以使用 default 属性为可选参数指定默认值。当用户不提供值时，Ace 使用默认值代替。

ts
@args.string({
  description: 'Name of the user to greet',
  required: false,
  default: 'guest'
})
declare name: string

有了默认值，参数变为可选，但你的代码始终可以期望字符串值而不是处理 undefined。

sh
node ace greet
# 使用默认值 "guest"
# 输出：Hello, guest!

转换参数值 ​

parse 方法允许你在参数值分配给类属性之前转换或验证它。这对于规范化输入、转换类型或执行验证很有用。

parse 方法接收来自命令行的原始字符串值，并且必须返回转换后的值。

ts
@args.string({
  argumentName: 'user-name',
  description: 'Name of the user to greet',
  parse(value) {
    /**
     * 将名称转换为大写
     */
    return value ? value.toUpperCase() : value
  }
})
declare name: string

现在当用户提供名称时，它会在你的命令的 run 方法执行之前自动转换为大写。

sh
node ace greet john
# 名称被转换为 "JOHN"
# 输出：Hello, JOHN!

你也可以通过在值无效时抛出错误来使用 parse 方法进行验证。

ts
@args.string({
  description: 'Email address of the user',
  parse(value) {
    if (!value.includes('@')) {
      throw new Error('Please provide a valid email address')
    }
    return value.toLowerCase()
  }
})
declare email: string

访问所有参数 ​

你可以使用 this.parsed.args 属性访问用户提供的所有参数，包括它们的原始值。这对于调试或当你需要检查完整参数列表时很有用。

ts
import { BaseCommand, args } from '@adonisjs/core/ace'

export default class GreetCommand extends BaseCommand {
  static commandName = 'greet'
  static description = 'Greet a user by name'

  @args.string()
  declare name: string

  async run() {
    /**
     * 将所有参数作为键值对象访问
     */
    console.log(this.parsed.args)
    // 输出：{ name: 'John' }

    this.logger.info(`Hello, ${this.name}!`)
  }
}
