REPL ​

在本指南中，你将了解到以下主题：

  • 启动和导航 REPL 会话
  • 导入模块和访问服务
  • 使用内置辅助方法
  • 访问命令历史和结果
  • 添加自定义 REPL 方法
  • 使用编辑器模式

概述 ​

AdonisJS REPL 扩展了标准的 Node.js REPL，添加了应用感知功能，使与代码库的交互变得容易。与基本的 Node.js REPL 不同，AdonisJS REPL 会启动你的应用、加载其服务，并为常见任务提供便捷的快捷方式。

REPL 在开发期间对于快速实验、调试和数据探索特别有用。你可以直接导入 TypeScript 文件、无需手动导入即可访问容器服务、通过 IoC 容器创建类实例，并使用特定于你应用的自定义方法扩展 REPL。

启动 REPL 会话 ​

你可以使用 node ace repl 命令启动 REPL 会话。这会启动你的 AdonisJS 应用并打开一个交互式提示符，你可以在其中执行代码。

sh
node ace repl

启动后，你会看到一个提示符，可以在其中输入 JavaScript 代码并按 Enter 执行它。输出立即出现在下一行，为测试和探索创建快速的反馈循环。

使用编辑器模式 ​

虽然 REPL 非常适合单行表达式，但有时你需要编写多行代码块。编辑器模式允许你在执行之前编写多行代码。

在 REPL 提示符下输入 .editor 命令进入编辑器模式。

sh
> (js) .editor
# // Entering editor mode (Ctrl+D to finish, Ctrl+C to cancel)

在编辑器模式下，你可以编写多行代码。按 Ctrl+D 执行整个代码块，或按 Ctrl+C 取消并退出编辑器模式而不执行任何内容。

sh
> (js) .editor

# // Entering editor mode (Ctrl+D to finish, Ctrl+C to cancel)
const users = await User.query()
  .where('isActive', true)
  .orderBy('createdAt', 'desc')
  .limit(10)

console.log(`Found ${users.length} active users`)
# // Press Ctrl+D to execute

访问之前的结果 ​

REPL 提供特殊变量来访问之前执行命令的结果和错误，当你忘记存储值时，无需重新运行代码。

访问最后的结果 ​

如果你执行了一个语句但忘记将其结果赋值给变量，可以使用 _（下划线）变量访问它。

sh
> (js) helpers.string.random(32)
# 'Z3y8QQ4HFpYSc39O2UiazwPeKYdydZ6M'

> (js) _
# 'Z3y8QQ4HFpYSc39O2UiazwPeKYdydZ6M'

> (js) _.length
# 32

当你想要对结果执行额外操作而不重新执行原始命令时，这特别有用。

访问最后的错误 ​

同样，你可以使用 _error 变量访问上一条命令引发的任何异常。这有助于检查错误详情，而不会用 try/catch 块弄乱你的代码。

sh
> (js) helpers.string.random()
# Error: The value of "size" is out of range...

> (js) _error.message
# 'The value of "size" is out of range. It must be >= 0 && <= 2147483647. Received NaN'

> (js) _error.stack
# (full error stack trace)

导航命令历史 ​

REPL 维护你执行过的所有命令的历史记录，保存在你的主目录中的 .adonisjs_v7_repl_history 文件里。这允许你回忆和重新执行以前的命令，而无需重新输入。

你可以通过两种方式导航命令历史：

  • 箭头键导航：按向上箭头 ↑ 键一次循环浏览之前的命令。按向下箭头 ↓ 在历史中向前移动。

  • 搜索模式：按 Ctrl+R 进入反向搜索模式，然后输入字符以在你的历史记录中搜索匹配的命令。再次按 Ctrl+R 循环浏览多个匹配项。

sh
> (js) [Press Ctrl+R]
(reverse-i-search)`query': const users = await User.query()

退出 REPL 会话 ​

你可以通过输入 .exit 或快速连续按两次 Ctrl+C 退出 REPL 会话。

sh
> (js) .exit
# Goodbye!

当你退出时，AdonisJS 执行优雅关闭，在进程终止之前关闭数据库连接并清理资源。

注意，当你修改代码库时，REPL 会话不会自动重新加载。如果你更改了应用代码，必须退出并重启 REPL 会话以使更改生效。

导入模块 ​

Node.js 不支持在 REPL 会话中使用 import 语句，因此你必须使用动态 import() 表达式代替。导入时，你需要解构模块导出或访问特定属性。

sh
> (js) const { default: User } = await import('#models/user')
# undefined

> (js) await User.all()
# [User, User, User, ...]

语法 const { default: User } 解构模块中的默认导出。当你只想要默认导出时，这可能很冗长。

使用 importDefault 辅助函数 ​

为了简化导入默认导出，REPL 提供 importDefault 辅助方法，自动提取默认导出。

sh
> (js) const User = await importDefault('#models/user')
# undefined

> (js) const Post = await importDefault('#models/post')
# undefined

> (js) await Post.query().where('published', true)
# [Post, Post, Post, ...]

这在处理模型、服务或任何导出单个默认值的模块时特别方便。

使用辅助方法 ​

REPL 包含多个内置辅助方法，为导入服务、创建类实例和管理 REPL 上下文等常见任务提供快捷方式。

你可以通过输入 .ls 命令查看所有可用的辅助方法。

sh
> (js) .ls

# GLOBAL METHODS:
importDefault         Returns the default export for a module
make                  Make class instance using "container.make" method
loadApp               Load "app" service in the REPL context
loadEncryption        Load "encryption" service in the REPL context
loadHash              Load "hash" service in the REPL context
loadRouter            Load "router" service in the REPL context
loadConfig            Load "config" service in the REPL context
loadTestUtils         Load "testUtils" service in the REPL context
loadHelpers           Load "helpers" module in the REPL context
clear                 Clear a property from the REPL context
p                     Promisify a function. Similar to Node.js "util.promisify"

加载服务 ​

你可以使用 load* 辅助方法将服务加载到 REPL 上下文中，而不是手动导入。

sh
> (js) await loadRouter()
# Imported router. You can access it using the "router" property

> (js) router.toJSON()
# { routes: [...], ... }

> (js) await loadHash()
# Imported hash. You can access it using the "hash" property

> (js) await hash.make('secret')
# '$argon2id$v=19$m=65536,t=3,p=4$...'

每个 load* 方法导入相应的服务，并使其作为 REPL 上下文中的属性可用，消除了导入语句的需要。

创建类实例 ​

make 方法使用 IoC 容器创建具有自动依赖注入的类实例。

sh
> (js) const userService = await make('App/Services/UserService')
# undefined

> (js) await userService.findById(1)
# User { id: 1, email: 'user@example.com', ... }

当你想要测试具有构造函数依赖的服务或类时，这很有用，因为容器会自动解析并注入它们。

Promisify 函数 ​

p 方法将基于回调的函数 promisify，类似于 Node.js util.promisify。

sh
> (js) const readFile = p(fs.readFile)
# undefined

> (js) await readFile('package.json', 'utf8')
# '{ "name": "my-app", ... }'

添加自定义 REPL 方法 ​

你可以使用特定于你的应用的自定义方法扩展 REPL。这对于创建你在开发期间频繁使用的快捷方式很有用，例如加载所有模型或填充测试数据。

自定义方法通常在仅在 REPL 环境中运行的预加载文件中定义。

创建 REPL 预加载文件 ​

首先，生成一个配置为仅在 REPL 环境中运行的预加载文件。

sh
node ace make:preload repl -e=repl

# CREATE: start/repl.ts

定义自定义方法 ​

在预加载文件中，使用 repl.addMethod 定义自定义方法。例如，让我们创建一个从 app/models 目录导入所有模型的方法。

ts
import app from '@adonisjs/core/services/app'
import repl from '@adonisjs/core/services/repl'
import { fsImportAll } from '@adonisjs/core/helpers'

/**
 * 添加一个方法一次性加载所有模型
 */
repl.addMethod(
  'loadModels',
  async () => {
    /**
     * 从 models 目录导入所有文件
     */
    const models = await fsImportAll(app.makePath('app/models'))

    /**
     * 使模型在 REPL 上下文中可用
     */
    repl.server!.context.models = models

    /**
     * 通知用户模型已加载
     */
    repl.notify(
      'Imported models. You can access them using the "models" property'
    )

    /**
     * 再次显示提示符
     */
    repl.server!.displayPrompt()
  },
  {
    description: 'Load all models from app/models directory',
    usage: 'await loadModels()'
  }
)

repl.addMethod 接受三个参数：

  1. 方法名称：你在 REPL 中调用该方法时使用的名称
  2. 实现：执行操作的异步函数
  3. 选项（可选）：包含 description 和 usage 属性的对象，出现在帮助输出中

使用你的自定义方法 ​

重启 REPL 会话后，你的自定义方法变得可用。

sh
node ace repl

> (js) .ls
# GLOBAL METHODS:
# loadModels            Load all models from app/models directory
# ...

> (js) await loadModels()
# Imported models. You can access them using the "models" property

> (js) Object.keys(models)
# ['User', 'Post', 'Comment', ...]

> (js) await models.User.all()
# [User, User, User, ...]

你可以在同一个预加载文件中定义多个自定义方法，以创建针对你应用需求量身定制的全面开发快捷方式集。
