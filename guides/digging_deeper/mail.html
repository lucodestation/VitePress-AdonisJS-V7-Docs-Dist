邮件 ​

本指南涵盖从你的 AdonisJS 应用发送电子邮件。你将了解到如何：

  • 为 SMTP、Resend、Postmark、Mailgun、SparkPost、Brevo 和 SES 等服务配置邮件传输
  • 使用流畅的 Message API 发送电子邮件
  • 为后台投递排队电子邮件
  • 将电子邮件组织到可重用的邮件类中
  • 添加附件、嵌入图片和包含日历邀请
  • 使用 fake mailer 测试电子邮件功能

概述 ​

@adonisjs/mail 包提供统一的 API，用于通过各种提供商发送电子邮件。构建在 Nodemailer 之上，它添加了流畅的配置 API、将邮件组织为类的支持、广泛的测试 API，以及通过 messenger 进行后台邮件投递。

该包引入两个关键概念。传输（transport） 是底层投递机制（SMTP 服务器、Resend 或 Mailgun 等 API 服务）。邮件器（mailer） 是传输的已配置实例，你使用它发送电子邮件。你可以在应用中配置多个邮件器，每个使用不同的传输或具有不同设置的同一传输，并在运行时切换它们。

安装 ​

使用以下命令安装和配置该包：

sh
node ace add @adonisjs/mail

你可以在安装期间预选传输：

sh
node ace add @adonisjs/mail --transports=resend --transports=smtp
查看 add 命令执行的步骤

  1. 使用检测到的包管理器安装 @adonisjs/mail 包。

  2. 在 adonisrc.ts 文件中注册以下服务提供者和命令。

    ts
    {
  commands: [
    // ...其他命令
    () => import('@adonisjs/mail/commands')
  ],
  providers: [
    // ...其他提供者
    () => import('@adonisjs/mail/mail_provider')
  ]
}

  3. 创建 config/mail.ts 文件。

  4. 为所选邮件服务定义环境变量及其验证。

配置 ​

邮件配置位于 config/mail.ts。此文件定义你的邮件器、默认发件人地址和传输设置。

另请参阅：配置存根

ts
import env from '#start/env'
import { defineConfig, transports } from '@adonisjs/mail'

const mailConfig = defineConfig({
  /**
   * 未指定时使用的邮件器
   */
  default: 'smtp',

  /**
   * 未在单个邮件上设置时使用的全局"发件人"地址
   */
  from: {
    address: 'hello@example.com',
    name: 'My App',
  },

  /**
   * 未在单个邮件上设置时使用的全局"回复至"地址
   */
  replyTo: {
    address: 'support@example.com',
    name: 'My App Support',
  },

  /**
   * 配置一个或多个邮件器。每个邮件器使用一个传输
   * 并可以有自己的设置。
   */
  mailers: {
    smtp: transports.smtp({
      host: env.get('SMTP_HOST'),
      port: env.get('SMTP_PORT'),
    }),

    resend: transports.resend({
      key: env.get('RESEND_API_KEY'),
      baseUrl: 'https://api.resend.com',
    }),
  },
})

export default mailConfig
选项描述
default当你调用 mail.send() 而未指定邮件器时使用的邮件器。
from全局发件人地址。除非在单个邮件上覆盖，否则使用此地址。
replyTo全局回复至地址。除非在单个邮件上覆盖，否则使用此地址。
mailers包含你已配置邮件器的对象。每个键是邮件器名称，每个值是传输配置。

发送你的第一封邮件 ​

导入邮件服务并调用 send 方法。回调接收一个 Message 实例以配置电子邮件。

ts
import type { HttpContext } from '@adonisjs/core/http'
import mail from '@adonisjs/mail/services/main'
import User from '#models/user'

export default class UsersController {
  async store({ request }: HttpContext) {
    const user = await User.create(request.all())

    /**
     * 创建用户后发送欢迎邮件。
     * 回调配置消息属性。
     */
    await mail.send((message) => {
      message
        .to(user.email)
        .from('welcome@example.com')
        .subject('Welcome to our app!')
        .htmlView('emails/welcome', { user })
    })

    return user
  }
}

mail.send 方法使用默认邮件器立即投递电子邮件。对于高流量的生产应用，你应该改为排队电子邮件进行后台投递。

配置消息 ​

Message 类提供用于构建电子邮件的流畅 API。你在传递给 mail.send 或 mail.sendLater 的回调中接收一个实例。

主题和发件人 ​

ts
await mail.send((message) => {
  message
    .subject('Your order has shipped')
    .from('orders@example.com')
})

from 方法接受字符串或带有地址和名称的对象：

ts
await mail.send((message) => {
  message.from({
    address: 'orders@example.com',
    name: 'Acme Store'
  })
})

收件人 ​

使用 to、cc 和 bcc 设置收件人。每个方法接受字符串、对象或数组。

ts
await mail.send((message) => {
  message
    .to(user.email)
    .cc(user.manager.email)
    .bcc('audit@example.com')
})
ts
await mail.send((message) => {
  message
    .to({
      address: user.email,
      name: user.fullName,
    })
    .cc([
      { address: 'team-lead@example.com', name: 'Team Lead' },
      { address: 'pm@example.com', name: 'Project Manager' }
    ])
})

使用 replyTo 方法设置回复至地址：

ts
await mail.send((message) => {
  message
    .from('noreply@example.com')
    .replyTo('support@example.com')
})

邮件内容 ​

使用 html 和 text 方法定义内联 HTML 和纯文本内容，或使用 htmlView 和 textView 渲染 Edge 模板。

ts
await mail.send((message) => {
  /**
   * 内联内容适用于简单邮件
   */
  message.html(`
    <h1>Reset your password</h1>
    <p>Click <a href="${resetUrl}">here</a> to reset your password.</p>
  `)

  message.text(`
    Reset your password
    Visit ${resetUrl} to reset your password.
  `)
})

对于大多数电子邮件，Edge 模板提供更好的组织：

sh
node ace make:view emails/password_reset_html
node ace make:view emails/password_reset_text
ts
await mail.send((message) => {
  /**
   * 渲染 Edge 模板，将数据作为第二个参数传递
   */
  message.htmlView('emails/password_reset_html', { user, resetUrl })
  message.textView('emails/password_reset_text', { user, resetUrl })
})

排队电子邮件 ​

同步发送电子邮件会在等待邮件提供商响应时阻塞请求处理。为了更好的性能，使用 mail.sendLater 排队电子邮件进行后台投递。

ts
import mail from '@adonisjs/mail/services/main'

export default class UsersController {
  async store({ request }: HttpContext) {
    const user = await User.create(request.all())

    /**
     * 排队电子邮件而不是立即发送。
     * 请求在不等候投递的情况下完成。
     */
    await mail.sendLater((message) => {
      message
        .to(user.email)
        .from('welcome@example.com')
        .subject('Welcome!')
        .htmlView('emails/welcome', { user })
    })

    return user
  }
}

默认情况下，邮件 messenger 使用内存队列。这意味着如果你的进程在发送之前终止，排队的电子邮件会丢失。

WARNING

内存 messenger 适合开发但不推荐用于生产。如果你的应用崩溃或重启时队列中有待处理的电子邮件，那些电子邮件将永远不会被发送。对于生产部署，使用像 BullMQ 这样的持久队列。

使用 BullMQ 进行持久排队 ​

对于生产应用，使用 BullMQ 和 Redis 配置持久队列。这确保电子邮件在进程重启后仍然存活。

sh
npm i bullmq

创建一个自定义 messenger，将电子邮件任务存储在 Redis 中：

ts
import { Queue } from 'bullmq'
import mail from '@adonisjs/mail/services/main'

const emailsQueue = new Queue('emails')

mail.setMessenger((mailer) => {
  return {
    async queue(mailMessage, config) {
      /**
       * 存储编译后的消息、配置和邮件器名称。
       * 工作进程将接收此消息并发送。
       */
      await emailsQueue.add('send_email', {
        mailMessage,
        config,
        mailerName: mailer.name,
      })
    }
  }
})

创建一个工作进程来处理队列。在单独的进程中运行：

ts
import { Worker } from 'bullmq'
import mail from '@adonisjs/mail/services/main'

new Worker('emails', async (job) => {
  if (job.name === 'send_email') {
    const { mailMessage, config, mailerName } = job.data

    /**
     * 使用指定的邮件器发送预编译的消息
     */
    await mail.use(mailerName).sendCompiled(mailMessage, config)
  }
})

在邮件器之间切换 ​

使用 mail.use() 通过特定邮件器而不是默认邮件器发送电子邮件。

ts
import mail from '@adonisjs/mail/services/main'

/**
 * 通过默认邮件器发送事务性电子邮件
 */
await mail.send((message) => {
  message.subject('Order confirmed')
})

/**
 * 通过 Mailgun 发送营销电子邮件
 */
await mail.use('mailgun').send((message) => {
  message.subject('Weekly newsletter')
})

/**
 * 通过特定邮件器排队电子邮件
 */
await mail.use('resend').sendLater((message) => {
  message.subject('Your report is ready')
})

邮件器实例在进程生命周期内被缓存。要关闭连接并从缓存中移除它，使用 mail.close()：

ts
import mail from '@adonisjs/mail/services/main'

/**
 * 关闭 mailgun 连接并从缓存中移除
 */
await mail.close('mailgun')

/**
 * 下次调用创建新实例
 */
mail.use('mailgun')

附件 ​

文件附件 ​

使用 attach 方法和绝对文件路径附加文件：

ts
import app from '@adonisjs/core/services/app'

await mail.send((message) => {
  message.attach(app.makePath('storage/invoices/inv-001.pdf'))
})

自定义附件文件名和其他选项：

ts
await mail.send((message) => {
  message.attach(app.makePath('storage/invoices/inv-001.pdf'), {
    filename: 'invoice-october-2024.pdf',
    contentType: 'application/pdf',
  })
})
选项描述
filename附件的显示名称。默认为文件的基本名称。
contentTypeMIME 类型。如果未设置则从扩展名推断。
contentDispositionattachment（默认）或 inline。
headers自定义头作为键值对。

从流和缓冲区附加 ​

使用 attachData 处理来自流或缓冲区的动态内容：

ts
import fs from 'node:fs'

await mail.send((message) => {
  /**
   * 从可读流附加
   */
  message.attachData(fs.createReadStream('./report.pdf'), {
    filename: 'report.pdf'
  })

  /**
   * 从缓冲区附加
   */
  message.attachData(Buffer.from('Hello world'), {
    filename: 'greeting.txt',
    encoding: 'utf-8',
  })
})

WARNING

不要将 attachData 与 mail.sendLater 一起使用。排队的电子邮件被序列化为 JSON，因此流无法存储，缓冲区会显著增加存储大小。尝试排队带有流附件的电子邮件将失败。相反，先将文件保存到磁盘，然后使用带文件路径的 attach。

嵌入图片 ​

使用 Edge 模板中的 embedImage 辅助函数直接在 HTML 内容中嵌入图片。这使用 CID（Content-ID）附件，在电子邮件客户端中显示可靠。

edge
<img src="{{ embedImage(app.makePath('assets/logo.png')) }}" alt="Logo" />

辅助函数返回 cid: URL 并自动将图片添加为附件。

对于动态图片数据，使用 embedImageData：

edge
<img src="{{ embedImageData(chartBuffer, { filename: 'chart.png' }) }}" />

日历邀请 ​

使用 icalEvent 方法附加日历事件。你可以提供原始 iCalendar 内容或使用流畅 API。

ts
import { DateTime } from 'luxon'

await mail.send((message) => {
  message.icalEvent((calendar) => {
    calendar.createEvent({
      summary: 'Project kickoff meeting',
      start: DateTime.now().plus({ days: 1 }).set({ hour: 10 }),
      end: DateTime.now().plus({ days: 1 }).set({ hour: 11 }),
      location: 'Conference Room A',
    })
  }, {
    method: 'REQUEST',
    filename: 'meeting.ics',
  })
})

日历对象是 ical-generator 的实例。

从文件或 URL 加载邀请内容：

ts
import app from '@adonisjs/core/services/app'

await mail.send((message) => {
  /**
   * 从本地文件
   */
  message.icalEventFromFile(
    app.resourcesPath('invites/standup.ics'),
    { method: 'REQUEST', filename: 'standup.ics' }
  )

  /**
   * 从 URL
   */
  message.icalEventFromUrl(
    'https://example.com/calendar/event-123.ics',
    { method: 'REQUEST', filename: 'event.ics' }
  )
})

自定义头 ​

使用 header 方法添加自定义头：

ts
await mail.send((message) => {
  message.header('X-Entity-Ref', 'order-12345')
  message.header('X-Priority', '1')
})

对于不应被编码或折叠的头，使用 preparedHeader：

ts
await mail.send((message) => {
  message.preparedHeader(
    'X-Custom-Data',
    'value with special chars or very long content'
  )
})

List 头 ​

辅助方法简化了用于邮件列表功能的常见 List-* 头：

ts
await mail.send((message) => {
  message.listUnsubscribe({
    url: 'https://example.com/unsubscribe?token=abc',
    comment: 'Unsubscribe from this list'
  })

  message.listHelp('support@example.com?subject=help')

  /**
   * 对于其他 List-* 头
   */
  message.addListHeader('post', 'https://example.com/list/post')
})

Gmail 和 Yahoo 等邮箱提供商要求批量发件人支持一键退订（RFC 8058）。它允许提供商通过向你的退订 URL 发送单个 HTTP POST 来让收件人退订，因此收件人无需离开收件箱或加载确认页面。

通过将 { oneClick: true } 作为第二个参数传递给 listUnsubscribe 来启用它。除了你的 List-Unsubscribe URL 之外，AdonisJS 还会发出 List-Unsubscribe-Post: List-Unsubscribe=One-Click 头，表示一键支持。你传递的 URL 必须是接受 POST 请求并立即退订收件人的 https 端点。

ts
await mail.send((message) => {
  message.listUnsubscribe('https://example.com/unsubscribe?token=abc', {
    oneClick: true
  })
})

另请参阅：Nodemailer list 头文档

基于类的邮件 ​

对于复杂应用，将电子邮件组织到专用类中，而不是内联回调。这提高了可测试性并保持控制器专注于请求处理。

sh
node ace make:mail verify_email
ts
import User from '#models/user'
import router from '@adonisjs/core/services/router'
import { BaseMail } from '@adonisjs/mail'

export default class VerifyEmailNotification extends BaseMail {
  /**
   * 为常见消息选项设置类属性
   */
  from = 'noreply@example.com'
  subject = 'Please verify your email address'

  constructor(private user: User) {
    super()
  }

  /**
   * 在 prepare 方法中配置消息。
   * 发送之前自动调用。
   */
  prepare() {
    const verifyUrl = router.makeUrl('email.verify', {
      token: this.user.verificationToken
    })

    this.message
      .to(this.user.email)
      .htmlView('emails/verify_email', {
        user: this.user,
        verifyUrl,
      })
  }
}

通过将实例传递给 mail.send 或 mail.sendLater 发送电子邮件：

ts
import mail from '@adonisjs/mail/services/main'
import VerifyEmailNotification from '#mails/verify_email'

export default class AuthController {
  async register({ request }: HttpContext) {
    const user = await User.create(request.all())

    await mail.sendLater(new VerifyEmailNotification(user))

    return { message: 'Check your email to verify your account' }
  }
}
属性/方法描述
from默认发件人地址。在 prepare 中用 message.from() 覆盖。
subject默认主题行。在 prepare 中用 message.subject() 覆盖。
replyTo默认回复至地址。
prepare()配置消息。发送之前自动调用。
build()从 BaseMail 继承。调用 prepare 并编译消息。

测试 ​

邮件包提供 fake mailer 用于测试电子邮件功能而不实际发送电子邮件。

使用 fake mailer ​

调用 mail.fake() 拦截所有电子邮件。返回的对象包含用于断言的 mails 属性。

ts
import { test } from '@japa/runner'
import mail from '@adonisjs/mail/services/main'
import VerifyEmailNotification from '#mails/verify_email'

test.group('Users | register', () => {
  test('sends verification email on registration', async ({ client }) => {
    /**
     * Fake 邮件器。`using` 关键字在测试结束时
     * 自动恢复真实邮件器。
     */
    using fake = mail.fake()

    await client
      .post('/register')
      .form({ email: 'user@example.com', password: 'secret123' })

    /**
     * 断言电子邮件已发送
     */
    fake.mails.assertSent(VerifyEmailNotification, ({ message }) => {
      return message
        .hasTo('user@example.com')
        .hasSubject('Please verify your email address')
    })
  })

  test('does not send password reset when user not found', async ({ client }) => {
    using fake = mail.fake()

    await client
      .post('/forgot-password')
      .form({ email: 'unknown@example.com' })

    fake.mails.assertNotSent(PasswordResetNotification)
  })
})

如果你需要更多控制真实邮件器何时恢复，也可以手动调用 mail.restore()。

断言方法 ​

mails 对象提供以下断言方法：

方法描述
assertSent(Mail, finder?)断言已发送某个邮件类。可选 finder 回调用于额外检查。
assertNotSent(Mail, finder?)断言未发送某个邮件类。
assertSentCount(count)断言已发送的电子邮件总数。
assertSentCount(Mail, count)断言特定类已发送的电子邮件数量。
assertNoneSent()断言未发送任何电子邮件。
assertQueued(Mail, finder?)断言电子邮件已通过 sendLater 排队。
assertNotQueued(Mail, finder?)断言电子邮件未排队。
assertQueuedCount(count)断言排队的电子邮件总数。
assertQueuedCount(Mail, count)断言特定类排队的电子邮件数量。
assertNoneQueued()断言未排队任何电子邮件。

直接测试邮件类 ​

通过构建邮件类而不发送来隔离测试它们：

ts
import { test } from '@japa/runner'
import { UserFactory } from '#database/factories/user_factory'
import VerifyEmailNotification from '#mails/verify_email'

test.group('VerifyEmailNotification', () => {
  test('builds correct message', async () => {
    const user = await UserFactory.create()
    const email = new VerifyEmailNotification(user)

    /**
     * 构建消息并渲染模板
     */

     * 断言消息属性

    email.message.assertFrom('noreply@example.com')
    email.message.assertSubject('Please verify your email address')

     * 断言渲染的内容

    email.message.assertHtmlIncludes('/verify/')
  })
})

自定义传输 ​

创建自定义传输以集成包中未包含的邮件提供商。传输封装 Nodemailer 传输并规范化其响应。

ts
import nodemailer from 'nodemailer'
import mandrillTransport from 'nodemailer-mandrill-transport'
import { MailResponse } from '@adonisjs/mail'
import type { NodeMailerMessage, MailTransportContract } from '@adonisjs/mail/types'

export type MandrillConfig = {
  auth: {
    apiKey: string
  }
}

export class MandrillTransport implements MailTransportContract {
  #config: MandrillConfig

  constructor(config: MandrillConfig) {
    this.#config = config
  }

  async send(
    message: NodeMailerMessage,
    config?: MandrillConfig
  ): Promise<MailResponse> {
    /**
     * 使用合并的配置创建 nodemailer 传输
     */
    const transporter = nodemailer.createTransport(
      mandrillTransport({ ...this.#config, ...config })
    )

    const response = await transporter.sendMail(message)

    /**
     * 返回规范化的响应
     */
    return new MailResponse(response.messageId, response.envelope, response)
  }
}

创建用于配置文件的工厂函数：

ts
import type { MailManagerTransportFactory } from '@adonisjs/mail/types'

export function mandrillTransport(
  config: MandrillConfig
): MailManagerTransportFactory {
  return () => new MandrillTransport(config)
}

在你的配置中注册传输：

ts
import env from '#start/env'
import { defineConfig } from '@adonisjs/mail'
import { mandrillTransport } from '#app/mail/transports/mandrill'

const mailConfig = defineConfig({
  mailers: {
    mandrill: mandrillTransport({
      auth: {
        apiKey: env.get('MANDRILL_API_KEY'),
      },
    }),
  },
})

自定义模板引擎 ​

默认情况下，邮件包使用 Edge 渲染电子邮件模板。要使用不同的模板引擎，覆盖 Message 类上的静态 templateEngine 属性。

ts
import { Message } from '@adonisjs/mail'

Message.templateEngine = {
  async render(templatePath, data) {
    /**
     * 使用你偏好的模板引擎
     */
    return myTemplateEngine.render(templatePath, data)
  }
}
