缓存 ​

本指南涵盖 AdonisJS 应用中的缓存。你将了解到如何：

  • 使用不同驱动（Redis、Memory、Database、DynamoDB）配置缓存存储
  • 存储、检索和失效缓存数据
  • 使用 L1（内存）和 L2（分布式）层的多层缓存
  • 使用命名空间和标签组织缓存条目
  • 通过宽限期、缓存击穿保护和超时提升弹性
  • 使用 Ace 命令管理缓存

概述 ​

@adonisjs/cache 包为你的 AdonisJS 应用提供统一的缓存 API。它构建在 Bentocache 之上，超越了简单的键值存储，提供多层缓存、缓存击穿保护、宽限期等功能。

该包引入两个关键概念。驱动是底层存储机制（Redis、内存、数据库）。存储是组合一个或多个驱动的配置好的缓存层。你可以在应用中配置多个存储，每个都有不同的驱动和设置，并在运行时切换它们。

多层缓存是最突出的功能。通过将内存 L1 缓存与分布式 L2 缓存（如 Redis）结合，你获得本地内存的速度以及共享缓存的持久性和可扩展性。与单层方法相比，这种设置可以提供快 2,000 倍到 5,000 倍的响应。

安装 ​

使用以下命令安装和配置该包：

sh
node ace add @adonisjs/cache
查看 add 命令执行的步骤

  1. 使用检测到的包管理器安装 @adonisjs/cache 包。

  2. 在 adonisrc.ts 文件中注册以下服务提供者和命令。

    ts
    {
  commands: [
    // ...其他命令
    () => import('@adonisjs/cache/commands')
  ],
  providers: [
    // ...其他提供者
    () => import('@adonisjs/cache/cache_provider')
  ]
}

  3. 创建 config/cache.ts 文件。

  4. 为所选驱动定义环境变量及其验证。

配置 ​

缓存配置位于 config/cache.ts。此文件定义你的存储、默认存储和驱动特定的设置。

另请参阅：配置存根

ts
import { defineConfig, store, drivers } from '@adonisjs/cache'

const cacheConfig = defineConfig({
  /**
   * 未指定时使用的存储
   */
  default: 'redis',

  /**
   * 所有缓存条目的默认 TTL。
   * 可以按存储或按操作覆盖。
   */
  ttl: '30s',

  /**
   * 配置一个或多个存储。每个存储定义
   * 其缓存层和驱动设置。
   */
  stores: {
    /**
     * 结合内存速度和 Redis 持久性
     * 以及跨实例同步的多层存储。
     */
    redis: store()
      .useL1Layer(drivers.memory({ maxSize: '100mb' }))
      .useL2Layer(drivers.redis({ connectionName: 'main' }))
      .useBus(drivers.redisBus({ connectionName: 'main' })),

    /**
     * 用于单实例应用的简单内存存储
     */
    memory: store()
      .useL1Layer(drivers.memory({ maxSize: '100mb' })),

    /**
     * 使用 Lucid 连接的数据库支持的存储
     */
    database: store()
      .useL2Layer(drivers.database({ connectionName: 'default' })),
  },
})

export default cacheConfig

可用驱动 ​

Redis

使用 Redis 作为分布式缓存。需要安装和配置 @adonisjs/redis 包。兼容 Redis、Upstash、Vercel KV、Valkey、KeyDB 和 DragonFly。

ts
{
  stores: {
    redis: store()
      .useL2Layer(drivers.redis({
        connectionName: 'main',
      }))
  }
}

另请参阅：Redis 设置指南

Memory

使用内存 LRU（最近最少使用）缓存。最适合作为多层设置中的 L1 层或用于单实例应用。

ts
{
  stores: {
    memory: store()
      .useL1Layer(drivers.memory({
        maxSize: '100mb',
        maxItems: 1000,
      }))
  }
}
Database

使用你的数据库作为缓存存储。需要 @adonisjs/lucid。缓存表默认自动创建。

ts
{
  stores: {
    database: store()
      .useL2Layer(drivers.database({
        connectionName: 'default',
        tableName: 'cache',
        autoCreateTable: true,
      }))
  }
}
DynamoDB

使用 AWS DynamoDB 作为缓存存储。需要 @aws-sdk/client-dynamodb。你必须事先创建表，使用名为 key 的字符串分区键并在 ttl 属性上启用 TTL。

sh
npm i @aws-sdk/client-dynamodb
ts
{
  stores: {
    dynamo: store()
      .useL2Layer(drivers.dynamodb({
        table: { name: 'cache' },
        region: 'us-east-1',
        credentials: {
          accessKeyId: env.get('AWS_ACCESS_KEY_ID'),
          secretAccessKey: env.get('AWS_SECRET_ACCESS_KEY'),
        },
      }))
  }
}

存储和检索数据 ​

导入缓存服务以与你的缓存交互。所有缓存操作都通过 cache 对象可用。

ts
import cache from '@adonisjs/cache/services/main'

获取和设置值 ​

最常见的模式是 getOrSet。它尝试在缓存中查找值，如果缺失，则执行工厂函数计算值、存储它并返回。

ts
import type { HttpContext } from '@adonisjs/core/http'
import cache from '@adonisjs/cache/services/main'
import Post from '#models/post'

export default class PostsController {
  async index({ request }: HttpContext) {
    const page = request.input('page', 1)

    const posts = await cache.getOrSet({
      key: `posts:page:${page}`,
      ttl: '10m',
      factory: () => Post.query().paginate(page, 20),
    })

    return posts
  }
}

当你需要对流程有更多控制时，也可以独立使用 get 和 set。

ts
import cache from '@adonisjs/cache/services/main'

/**
 * 存储带有 5 分钟 TTL 的值
 */
await cache.set({
  key: 'app:settings',
  value: { maintenance: false, theme: 'dark' },
  ttl: '5m',
})

/**
 * 检索值。如果键不存在则返回 undefined。
 */
const settings = await cache.get({ key: 'app:settings' })

/**
 * 存储永不过期的值
 */
await cache.setForever({
  key: 'app:version',
  value: '2.0.0',
})

WARNING

缓存数据必须可序列化为 JSON。如果你缓存 Lucid 模型，在存储之前调用 .toJSON() 或 .serialize()，或使用 getOrSet（它自动处理序列化）。

检查存在性 ​

使用 has 和 missing 检查缓存中是否存在键，而不检索其值。

ts
import cache from '@adonisjs/cache/services/main'

if (await cache.has({ key: 'products:featured' })) {
  // 键存在于缓存中
}

if (await cache.missing({ key: 'products:featured' })) {
  // 键不存在
}

拉取值 ​

pull 方法检索值并立即从缓存中删除它。这对于一次性数据（如闪存消息或临时令牌）很有用。

ts
import cache from '@adonisjs/cache/services/main'

/**
 * 在一次操作中获取令牌并从缓存中移除它
 */
const token = await cache.pull({ key: `email-verify:${userId}` })

删除数据 ​

使用 delete 移除单个条目，使用 deleteMany 移除多个条目，或使用 clear 移除所有条目。

ts
import cache from '@adonisjs/cache/services/main'

/**
 * 删除单个键
 */
await cache.delete({ key: 'posts:page:1' })

/**
 * 一次删除多个键
 */
await cache.deleteMany({
  keys: ['posts:page:1', 'posts:page:2', 'posts:page:3'],
})

/**
 * 删除缓存中的所有条目
 */
await cache.clear()

标签 ​

标签让你分组相关缓存条目，以便一起使它们失效。当更改影响多个缓存值时，这特别有用。例如，当帖子更新时，你可以使可能显示它的所有页面失效。

ts
import cache from '@adonisjs/cache/services/main'
import Post from '#models/post'

export default class PostsController {
  async index({ request }: HttpContext) {
    const page = request.input('page', 1)

    /**
     * 用 "posts" 标记缓存页面，以便在任何帖子
     * 更改时使所有页面失效。
     */
    const posts = await cache.getOrSet({
      key: `posts:page:${page}`,
      ttl: '10m',
      tags: ['posts'],
      factory: () => Post.query().paginate(page, 20),
    })

    return posts
  }

  async update({ params, request }: HttpContext) {
    const post = await Post.findOrFail(params.id)
    post.merge(request.all())
    await post.save()

    /**
     * 使标记为 "posts" 的所有缓存条目失效。
     * 每个分页页面将在下次请求时刷新。
     */
    await cache.deleteByTag({ tags: ['posts'] })

    return post
  }
}

你可以为单个条目分配多个标签。当任何标签失效时，条目即失效。

ts
import cache from '@adonisjs/cache/services/main'

await cache.getOrSet({
  key: `dashboard:user:${userId}`,
  ttl: '5m',
  tags: ['dashboard', `user:${userId}`],
  factory: () => buildDashboard(userId),
})

/**
 * 使特定用户的仪表盘失效
 */
await cache.deleteByTag({ tags: [`user:${userId}`] })

/**
 * 或使所有仪表盘失效
 */
await cache.deleteByTag({ tags: ['dashboard'] })

TIP

避免为每个条目使用太多标签。BentoCache 使用客户端标签，意味着每次检索都会检查标签失效时间戳。每个条目的大量标签会减慢查找速度。

命名空间 ​

命名空间将缓存键分组在共同前缀下，允许你清除命名空间中的所有条目而不影响缓存的其余部分。

ts
import cache from '@adonisjs/cache/services/main'

const usersCache = cache.namespace('users')

/**
 * 键自动添加 "users:" 前缀
 * 这会将值存储在 "users:42" 下
 */
await usersCache.set({ key: '42', value: { name: 'John' } })
await usersCache.set({ key: '43', value: { name: 'Jane' } })

/**
 * 从命名空间检索
 */
const user = await usersCache.get({ key: '42' })

/**
 * 仅清除 "users" 命名空间。
 * 其他缓存条目不受影响。
 */
await usersCache.clear()

切换存储 ​

当你配置多个存储时，可以使用 use 方法在它们之间切换。没有它，将使用默认存储。

ts
import cache from '@adonisjs/cache/services/main'

/**
 * 使用默认存储
 */
await cache.getOrSet({
  key: 'products:featured',
  factory: () => Product.query().where('featured', true).exec(),
})

/**
 * 为短生命周期数据使用 "memory" 存储
 */
await cache.use('memory').set({
  key: 'rate-limit:user:42',
  value: 1,
  ttl: '1m',
})

/**
 * 为长生命周期数据使用 "database" 存储
 */
await cache.use('database').setForever({
  key: 'site:config',
  value: { theme: 'dark' },
})

多层缓存 ​

多层缓存将快速的内存 L1 缓存与持久的分布式 L2 缓存结合。这是运行多个实例的生产应用的推荐设置。

工作原理 ​

当你读取一个值时，缓存首先检查 L1（内存）层。如果找到值，它会立即返回而无需任何网络调用。如果缺失，它从 L2（Redis）层获取，在 L1 中存储副本并返回。

当你写入或删除值时，两层都会更新。总线（bus） 通知其他应用实例清除其过时的 L1 条目，因此每个实例保持一致。

配置 ​

组合 useL1Layer、useL2Layer 和 useBus 创建多层存储。

ts
import { defineConfig, store, drivers } from '@adonisjs/cache'

const cacheConfig = defineConfig({
  default: 'multitier',

  stores: {
    multitier: store()
      .useL1Layer(drivers.memory({ maxSize: '100mb' }))
      .useL2Layer(drivers.redis({ connectionName: 'main' }))
      .useBus(drivers.redisBus({ connectionName: 'main' })),
  },
})

export default cacheConfig

TIP

如果你的应用运行在单个实例上，可以省略总线。总线仅在多个实例需要同步其 L1 缓存时才需要。

总线仅向其他实例发送失效消息（而不是实际值）。当实例收到失效消息时，它从其 L1 缓存中移除该键。下一次读取将从 L2 获取更新后的值。

宽限期 ​

宽限期允许你在后台刷新值时提供稍微过时的缓存数据。这使你的应用对数据源的临时中断（数据库停机、API 失败）具有弹性。

当缓存条目过期但仍在其宽限期内时，缓存将过时值返回给调用者并触发后台刷新。如果刷新失败（例如因为数据库宕机），则继续提供过时值而不是返回错误。

ts
import cache from '@adonisjs/cache/services/main'
import Product from '#models/product'

const products = await cache.getOrSet({
  key: 'products:featured',

  /**
   * 数据在 10 分钟内是"新鲜"的
   */
  ttl: '10m',

  /**
   * 过期后，过时数据仍可用 6 小时。
   * 如果工厂在此窗口期间失败，则返回
   * 过时值而不是错误。
   */
  grace: '6h',

  factory: () => Product.query().where('featured', true).exec(),
})

退避策略 ​

当工厂调用在宽限期内失败时，你通常不希望在每次后续请求时重试。graceBackoff 选项设置重试尝试之间的延迟。

ts
const products = await cache.getOrSet({
  key: 'products:featured',
  ttl: '10m',
  grace: '6h',

  /**
   * 刷新失败后，等待 5 分钟再重试。
   * 期间提供过时数据。
   */
  graceBackoff: '5m',

  factory: () => Product.query().where('featured', true).exec(),
})

你也可以在配置中全局启用宽限期，这样就不必在每个操作上重复它们。

ts
const cacheConfig = defineConfig({
  default: 'redis',
  ttl: '10m',
  grace: '6h',
  graceBackoff: '30s',

  stores: {
    // ...
  },
})

缓存击穿保护 ​

缓存击穿发生在缓存条目过期且许多并发请求同时尝试重新生成它时，压垮你的数据源。BentoCache 自动防止这一点。

当第一个请求发现缺失或过期的键时，它获取锁并执行工厂函数。同一键的所有其他并发请求等待锁释放，然后接收缓存结果。这意味着无论同时到达多少请求，只发生一次工厂执行。

例如，如果 10,000 个请求同时命中一个过期的键，只进行一次数据库查询。其他 9,999 个请求在结果可用后接收缓存结果。此保护是内置的，无需配置。

超时 ​

超时防止慢速工厂函数阻塞你的响应。BentoCache 支持两种类型。

软超时 ​

软超时与宽限期配合使用。如果工厂耗时超过超时且宽限窗口内存在过时条目，则立即返回过时值，同时工厂在后台继续运行。

ts
const products = await cache.getOrSet({
  key: 'products:featured',
  ttl: '10m',
  grace: '6h',

  /**
   * 如果工厂耗时超过 200ms，立即返回
   * 过时值。工厂在后台继续运行
   * 以更新缓存。
   */
  timeout: '200ms',

  factory: () => Product.query().where('featured', true).exec(),
})

TIP

软超时仅在宽限期内有过时条目可用时才生效。如果不存在过时条目（首次填充缓存），请求会等待工厂完成。

硬超时 ​

硬超时设置等待工厂的绝对时间限制。如果超过，则抛出异常。工厂在后台继续执行，以便后续请求的缓存会被填充。

ts
const products = await cache.getOrSet({
  key: 'products:featured',
  ttl: '10m',

  /**
   * 如果工厂耗时超过 1 秒，抛出错误。
   */
  hardTimeout: '1s',

  factory: () => Product.query().where('featured', true).exec(),
})

你可以组合两种超时。软超时快速返回过时数据，硬超时充当安全网。

ts
const products = await cache.getOrSet({
  key: 'products:featured',
  ttl: '10m',
  grace: '6h',
  timeout: '200ms',
  hardTimeout: '1s',
  factory: () => Product.query().where('featured', true).exec(),
})

自适应缓存 ​

自适应缓存让你根据正在缓存的数据动态调整缓存选项。当理想 TTL 取决于实际值时，这很有用。

工厂函数接收一个上下文对象，带有辅助方法以在检查获取的数据后调整缓存行为。

ts
import cache from '@adonisjs/cache/services/main'

const token = await cache.getOrSet({
  key: `auth:token:${provider}`,
  ttl: '1h',
  factory: async (ctx) => {
    const token = await fetchOAuthToken(provider)

    /**
     * 根据令牌的实际过期时间设置 TTL
     * 而不是使用固定值
     */
    ctx.setOptions({ ttl: `${token.expiresIn}s` })

    return token
  },
})

上下文对象还提供：

  • ctx.skip() 阻止缓存返回的值
  • ctx.fail() 阻止缓存并抛出错误
  • ctx.setTags([...]) 根据缓存值动态设置标签
  • ctx.gracedEntry 访问宽限期内的过时值（如果有）

Edge 集成 ​

缓存服务在你的 Edge 模板中可用。你可以使用它直接在视图中显示缓存值。

edge
<p>Hello {{ await cache.get({ key: 'username' }) }}</p>

Ace 命令 ​

@adonisjs/cache 包提供用于从终端管理缓存的 Ace 命令。

cache:clear ​

从存储、命名空间或标签中移除所有条目。

sh
# 清除默认存储
node ace cache:clear

# 清除特定存储
node ace cache:clear redis

# 清除特定命名空间
node ace cache:clear --namespace=users

# 清除匹配特定标签的条目
node ace cache:clear --tags=products --tags=users

cache:delete ​

从缓存中移除特定键。

sh
# 从默认存储删除
node ace cache:delete posts:page:1

# 从特定存储删除
node ace cache:delete posts:page:1 redis

cache:prune ​

从不支持自动 TTL 过期的驱动（如数据库和文件系统驱动）中移除过期条目。Redis 原生处理过期，不需要修剪。

sh
# 修剪默认存储
node ace cache:prune

# 修剪特定存储
node ace cache:prune database

方法参考 ​

所有方法都可以在从 @adonisjs/cache/services/main 导入的 cache 对象上使用。它们也可用于 cache.use() 和 cache.namespace() 返回的实例。

getOrSet（返回类型：Promise<T>）

尝试从缓存获取值。如果缺失，执行工厂函数，缓存结果并返回。

ts
await cache.getOrSet({
  key: 'users:1',
  ttl: '10m',
  grace: '6h',
  tags: ['users'],
  factory: () => User.find(1),
})

get（返回类型：Promise<T | undefined>）

从缓存中检索值。如果键不存在则返回 undefined。

ts
const user = await cache.get({ key: 'users:1' })

set（返回类型：Promise<void>）

在缓存中存储带有可选 TTL 的值。

ts
await cache.set({ key: 'users:1', value: user, ttl: '10m' })

setForever（返回类型：Promise<void>）

在缓存中存储永不过期的值。

ts
await cache.setForever({ key: 'app:version', value: '2.0.0' })

has（返回类型：Promise<boolean>）

检查缓存中是否存在键。

ts
const exists = await cache.has({ key: 'users:1' })

missing（返回类型：Promise<boolean>）

检查缓存中是否不存在键。

ts
const notCached = await cache.missing({ key: 'users:1' })

pull（返回类型：Promise<T | undefined>）

从缓存中检索值并立即删除它。

ts
const token = await cache.pull({ key: 'verify:token:123' })

delete（返回类型：Promise<void>）

从缓存中移除单个键。

ts
await cache.delete({ key: 'users:1' })

deleteMany（返回类型：Promise<void>）

从缓存中移除多个键。

ts
await cache.deleteMany({ keys: ['users:1', 'users:2'] })

deleteByTag（返回类型：Promise<void>）

移除与给定标签关联的所有条目。

ts
await cache.deleteByTag({ tags: ['users'] })

clear（返回类型：Promise<void>）

从缓存（或当前命名空间）中移除所有条目。

ts
await cache.clear()

namespace（返回类型：CacheNamespace）

返回命名空间实例。返回实例上的所有操作都限定到该命名空间。

ts
const usersCache = cache.namespace('users')
await usersCache.set({ key: '1', value: user })

use（返回类型：CacheStore）

按名称返回特定存储实例。

ts
const redisCache = cache.use('redis')
await redisCache.get({ key: 'users:1' })
