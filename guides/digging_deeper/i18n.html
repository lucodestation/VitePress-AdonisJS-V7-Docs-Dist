国际化与本地化 ​

本指南涵盖 AdonisJS 应用中的国际化（i18n）和本地化。你将了解到如何：

  • 配置 i18n 包并设置支持的语言环境
  • 为多种语言存储和组织翻译文件
  • 在控制器和 Edge 模板中解析和格式化翻译
  • 自动翻译验证错误消息
  • 使用 ICU 消息格式处理动态内容（复数、日期、数字、性别）
  • 格式化货币、日期和相对时间等值
  • 创建自定义翻译加载器和格式化器

概述 ​

在构建面向全球受众的应用时，你需要两种能力：本地化（将文本翻译成多种语言）和国际化（根据地区惯例格式化日期、数字和货币等值）。@adonisjs/i18n 包同时提供这两者。

本地化涉及为你应用支持的每种语言编写翻译，并在 Edge 模板、验证消息或直接通过 i18n API 中引用它们。与其在代码库中硬编码像 "Welcome back!" 这样的字符串，不如将翻译存储在专用文件中并按键查找。这使得添加新语言变得简单直接，无需修改应用代码。

国际化处理格式化方面。同一个日期在美国可能显示为 "January 10, 2026"，而在法国显示为 "10 janvier 2026"。i18n 包在底层使用浏览器标准的 Intl API，为你提供对数字、货币、日期、时间等的区域感知格式化。

该包通过中间件与 AdonisJS 集成，中间件从 Accept-Language 头检测用户的首选语言，创建特定语言环境的 i18n 实例，并通过 HTTP 上下文在整个请求生命周期中使其可用。

安装 ​

使用以下命令安装和配置该包：

sh
node ace add @adonisjs/i18n
查看 add 命令执行的步骤

  1. 使用检测到的包管理器安装 @adonisjs/i18n 包。

  2. 在 adonisrc.ts 文件中注册以下服务提供者。

    ts
    {
  providers: [
    // ...其他提供者
    () => import('@adonisjs/i18n/i18n_provider')
  ]
}

  3. 创建 config/i18n.ts 文件。

  4. 在 middleware 目录中创建 detect_user_locale_middleware。

  5. 在 start/kernel.ts 文件中注册以下中间件。

    ts
    router.use([
  () => import('#middleware/detect_user_locale_middleware')
])

配置 ​

i18n 包的配置存储在 config/i18n.ts 文件中。

ts
import app from '@adonisjs/core/services/app'
import { defineConfig, formatters, loaders } from '@adonisjs/i18n'

const i18nConfig = defineConfig({
  defaultLocale: 'en',
  formatter: formatters.icu(),

  loaders: [
    loaders.fs({
      location: app.languageFilesPath()
    })
  ],
})

export default i18nConfig

另请参阅：配置存根

配置选项 ​

选项描述
defaultLocale当你的应用不支持用户语言时的回退语言环境。翻译和值格式化都会回退到此语言环境。
formatter存储翻译的消息格式。AdonisJS 默认使用 ICU 消息格式，这是 Crowdin 和 Lokalise 等翻译服务广泛接受的标准。你也可以创建自定义格式化器。
fallbackLocales定义语言环境之间回退关系的键值对。例如，你可能向讲加泰罗尼亚语的用户显示西班牙语内容。
supportedLocales你的应用支持的语言环境数组。如果省略，则从翻译文件推断。
loaders用于加载翻译的加载器集合。默认文件系统加载器从 resources/lang 读取。你可以创建自定义加载器以从数据库或远程服务加载翻译。

配置回退语言环境 ​

当特定语言环境的翻译缺失时，i18n 包可以在使用默认语言环境之前回退到相关语言。这对于地区变体很有用。

ts
export default defineConfig({
  formatter: formatters.icu(),
  defaultLocale: 'en',
  fallbackLocales: {
    'de-CH': 'de',  // 瑞士德语回退到德语
    'fr-CH': 'fr',  // 瑞士法语回退到法语
    ca: 'es'        // 加泰罗尼亚语回退到西班牙语
  }
})

配置支持的语言环境 ​

默认情况下，该包从你的翻译文件推断支持的语言环境。如果你有 en、fr 和 es 的翻译目录，这些会自动成为你支持的语言环境。要显式定义支持的语言环境，使用 supportedLocales 选项。

ts
export default defineConfig({
  formatter: formatters.icu(),
  defaultLocale: 'en',
  supportedLocales: ['en', 'fr', 'it']
})

存储翻译 ​

翻译存储在 resources/lang 目录中。为每种语言使用 IETF 语言标签格式（如 en、fr、de）创建子目录。

sh
resources
└── lang
    ├── en
    └── fr

对于地区变体，创建带有地区代码的子目录。当键缺失时，AdonisJS 会自动从地区翻译回退到基础翻译。

sh
resources
├── lang
│   ├── en        # 英语（基础）
│   ├── en-us     # 英语（美国）
│   └── en-gb     # 英语（英国）

另请参阅：ISO 语言代码

翻译文件格式 ​

将翻译存储在 .json 或 .yaml 文件中。你可以创建嵌套目录以更好地组织。

sh
resources
├── lang
│   ├── en
│   │   └── messages.json
│   └── fr
│       └── messages.json

翻译使用 ICU 消息语法，支持插值、复数化和格式化。

json
{
  "greeting": "Hello world"
}
json
{
  "greeting": "Bonjour le monde"
}

解析翻译 ​

要查找和格式化翻译，使用 i18nManager.locale 方法创建特定语言环境的 I18n 类实例。

ts
import i18nManager from '@adonisjs/i18n/services/main'

/**
 * 为特定语言环境创建 I18n 实例
 */
const en = i18nManager.locale('en')
const fr = i18nManager.locale('fr')

使用 .t 方法按键格式化翻译。键遵循 filename.path.to.key 模式。

ts
import i18nManager from '@adonisjs/i18n/services/main'

const i18n = i18nManager.locale('en')
i18n.t('messages.greeting') // "Hello world"
ts
import i18nManager from '@adonisjs/i18n/services/main'

const i18n = i18nManager.locale('fr')
i18n.t('messages.greeting') // "Bonjour le monde"

理解回退行为 ​

每个 I18n 实例都有基于你的 fallbackLocales 配置的预配置回退语言。当主语言的翻译缺失时，使用回退。

ts
export default defineConfig({
  defaultLocale: 'en',
  fallbackLocales: {
    'de-CH': 'de',
    'fr-CH': 'fr'
  }
})
ts
import i18nManager from '@adonisjs/i18n/services/main'

const swissGerman = i18nManager.locale('de-CH')
swissGerman.fallbackLocale // "de"（来自 fallbackLocales）

const swissFrench = i18nManager.locale('fr-CH')
swissFrench.fallbackLocale // "fr"（来自 fallbackLocales）

const english = i18nManager.locale('en')
english.fallbackLocale // "en"（使用 defaultLocale）

处理缺失的翻译 ​

当主语言环境和回退语言环境中都缺失翻译时，.t 方法返回错误字符串。

ts
import i18nManager from '@adonisjs/i18n/services/main'

const i18n = i18nManager.locale('en')
i18n.t('messages.hero_title')
// "translation missing: en, messages.hero_title"

要替换为自定义回退值，将其作为第二个参数传递。

ts
import i18nManager from '@adonisjs/i18n/services/main'

const i18n = i18nManager.locale('en')
i18n.t('messages.hero_title', '')
// ""（空字符串而不是错误消息）

对于全局回退策略，在你的配置中定义 fallback 函数。此函数接收翻译路径和语言环境代码，并必须返回字符串。

ts
import { defineConfig } from '@adonisjs/i18n'

export default defineConfig({
  defaultLocale: 'en',
  formatter: formatters.icu(),
  fallback: (identifier, locale) => {
    return '' // 为所有缺失的翻译返回空字符串
  },
})

在 HTTP 请求期间检测用户语言环境 ​

安装期间创建的 detect_user_locale_middleware 自动处理语言环境检测。它从传入请求读取 Accept-Language 头，为检测到的语言环境创建 I18n 实例，并通过 HTTP 上下文共享它。

有了这个中间件，你可以在控制器和 Edge 模板中访问翻译。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class PostsController {
  async store({ i18n, session, response }: HttpContext) {
    // 创建帖子...

    session.flash('success', {
      message: i18n.t('post.created')
    })

    return response.redirect().back()
  }
}

在 Edge 模板中，使用 t 辅助函数。

edge
<h1>{{ t('messages.heroTitle') }}</h1>

自定义语言环境检测 ​

中间件是你应用代码库的一部分，因此你可以修改 getRequestLocale 方法以使用自定义检测逻辑。例如，你可能从用户个人资料、cookie 或 URL 参数而不是 Accept-Language 头读取语言环境。

翻译验证消息 ​

detect_user_locale_middleware 挂钩到请求验证器，以从你的翻译文件提供验证消息。

ts
export default class DetectUserLocaleMiddleware {
  static {
    RequestValidator.messagesProvider = (ctx) => {
      return ctx.i18n.createMessagesProvider()
    }
  }
}

将验证翻译存储在 shared 键下的 validator.json 文件中。为验证规则或特定的 字段 + 规则 组合定义消息。

json
{
  "shared": {
    "fields": {
      "first_name": "first name"
    },
    "messages": {
      "required": "Enter {field}",
      "username.required": "Choose a username for your account",
      "email": "The email must be valid"
    }
  }
}
json
{
  "shared": {
    "fields": {
      "first_name": "Prénom"
    },
    "messages": {
      "required": "Remplisser le champ {field}",
      "username.required": "Choissisez un nom d'utilisateur pour votre compte",
      "email": "L'email doit être valide"
    }
  }
}

直接使用 VineJS 的翻译 ​

在 HTTP 请求期间，中间件自动为验证注册自定义消息提供者。在 HTTP 请求之外（在 Ace 命令或队列任务中）使用 VineJS 时，显式注册消息提供者。

ts
import { createJobValidator } from '#validators/jobs'
import i18nManager from '@adonisjs/i18n/services/main'

/**
 * 为所需语言环境获取 i18n 实例
 */
const i18n = i18nManager.locale('fr')

await createJobValidator.validate(data, {
  /**
   * 手动注册消息提供者
   */
  messagesProvider: i18n.createMessagesProvider()
})

ICU 消息格式 ​

ICU（Unicode 国际组件）消息格式是存储需要动态内容的翻译的标准。它支持插值、数字格式化、日期格式化、复数化和基于性别的选择。

插值 ​

使用单花括号引用动态值。

json
{
  "greeting": "Hello { username }"
}
edge
{{ t('messages.greeting', { username: 'Virk' }) }}
{{-- 输出：Hello Virk --}}

TIP

ICU 消息语法不支持嵌套数据集。在插值期间只能访问扁平对象的属性。如果你需要嵌套数据，在传递给翻译函数之前将其扁平化。

要在翻译中包含 HTML，在 Edge 模板中使用三花括号以防止转义。

json
{
  "greeting": "<p>Hello <strong>{ username }</strong></p>"
}
edge
{{{ t('messages.greeting', { username: 'Virk' }) }}}

数字格式化 ​

使用 {key, number, format} 语法格式化数值。格式可以包含数字骨架以实现精确控制。

json
{
  "bagel_price": "The price of this bagel is {amount, number, ::currency/USD}"
}
edge
{{ t('bagel_price', { amount: 2.49 }) }}
{{-- 输出：The price of this bagel is $2.49 --}}

更多格式化示例：

消息输出
Length: {length, number, ::measure-unit/length-meter}Length: 5 m
Balance: {price, number, ::currency/USD compact-long}Balance: $1 thousand

日期和时间格式化 ​

使用 {key, date, format} 或 {key, time, format} 语法格式化 Date 对象或 Luxon DateTime 实例。

json
{
  "shipment_update": "Your package will arrive on {expectedDate, date, medium}"
}
edge
{{ t('shipment_update', { expectedDate: luxonDateTime }) }}
{{-- 输出：Your package will arrive on Oct 16, 2023 --}}

对于时间格式化：

json
{
  "appointment": "You have an appointment today at {appointmentAt, time, ::h:m a}"
}
txt
You have an appointment today at 2:48 PM

支持的日期/时间模式 ​

ICU 提供许多模式，但只有以下可通过 ECMA402 Intl API 使用：

符号描述
G纪元指示符
y年
M月份
L独立月份
d日
E星期几
e本地星期几（不支持 e..eee）
c独立本地星期几（不支持 c..ccc）
aAM/PM 标记
h小时 [1-12]
H小时 [0-23]
K小时 [0-11]
k小时 [1-24]
m分钟
s秒
z时区

复数规则 ​

ICU 对复数化有一流支持。plural 格式根据数值选择不同文本。

yaml
cart_summary: >
  You have {itemsCount, plural,
    =0 {no items}
    one {1 item}
    other {# items}
  } in your cart
edge
{{ t('messages.cart_summary', { itemsCount: 1 }) }}
{{-- 输出：You have 1 item in your cart --}}

# 标记是数值的占位符，根据语言环境规则格式化。

edge
{{ t('messages.cart_summary', { itemsCount: 1000 }) }}
{{-- 输出：You have 1,000 items in your cart --}}

复数类别 ​

{key, plural, matches} 语法将值匹配到以下类别：

类别何时使用
zero有零项语法的语言（阿拉伯语、拉脱维亚语）
one有一项语法的语言（许多西方语言）
two有两项语法的语言（阿拉伯语、威尔士语）
few有小数字语法的语言（因语言而异）
many有较大数字语法的语言（阿拉伯语、波兰语、俄语）
other没有其他匹配时的默认类别；用于英语等语言中的"复数"
=value精确匹配特定数值

Select 格式 ​

select 格式通过将值与多个选项匹配来选择输出。这对于性别特定文本或其他分类选择很有用。

yaml
auto_reply: >
  {gender, select,
    male {He}
    female {She}
    other {They}
  } will respond shortly.
edge
{{ t('messages.auto_reply', { gender: 'female' }) }}
{{-- 输出：She will respond shortly. --}}

Select ordinal 格式 ​

selectordinal 格式根据语言环境规则处理序数（1st、2nd、3rd 等）。

yaml
anniversary_greeting: >
  It's my {years, selectordinal,
    one {#st}
    two {#nd}
    few {#rd}
    other {#th}
  } anniversary
edge
{{ t('messages.anniversary_greeting', { years: 2 }) }}
{{-- 输出：It's my 2nd anniversary --}}

序数类别与复数类别相同（zero、one、two、few、many、other、=value）。

格式化值 ​

i18n 包提供根据语言环境惯例格式化值的方法。这些方法使用 Node.js Intl API 并具有优化性能。

formatNumber ​

使用 Intl.NumberFormat 类格式化数值。

ts
import i18nManager from '@adonisjs/i18n/services/main'

i18nManager
  .locale('en')
  .formatNumber(123456.789, {
    maximumSignificantDigits: 3
  })
// "123,000"

参阅：Intl.NumberFormat 选项

formatCurrency ​

将数值格式化为货币。此方法自动设置 style: 'currency'。

ts
import i18nManager from '@adonisjs/i18n/services/main'

i18nManager
  .locale('en')
  .formatCurrency(200, {
    currency: 'USD'
  })
// "$200.00"

formatDate ​

使用 Intl.DateTimeFormat 类格式化 Date 对象或 Luxon DateTime 实例。

ts
import i18nManager from '@adonisjs/i18n/services/main'
import { DateTime } from 'luxon'

i18nManager
  .locale('en')
  .formatDate(new Date(), {
    dateStyle: 'long'
  })
// "January 10, 2026"

i18nManager
  .locale('en')
  .formatDate(DateTime.local(), {
    dateStyle: 'long'
  })
// "January 10, 2026"

参阅：Intl.DateTimeFormat 选项

formatTime ​

将日期值格式化为时间字符串。此方法默认设置 timeStyle: 'medium'。

ts
import i18nManager from '@adonisjs/i18n/services/main'

i18nManager
  .locale('en')
  .formatTime(new Date())
// "2:48:30 PM"

formatRelativeTime ​

使用 Intl.RelativeTimeFormat 类将值格式化为相对时间（如 "in 2 hours" 或 "3 days ago"）。

ts
import { DateTime } from 'luxon'
import i18nManager from '@adonisjs/i18n/services/main'

const futureDate = DateTime.local().plus({ hours: 2 })

i18nManager
  .locale('en')
  .formatRelativeTime(futureDate, 'hours')
// "in 2 hours"

使用 'auto' 单位自动选择最合适的单位。

ts
import { DateTime } from 'luxon'
import i18nManager from '@adonisjs/i18n/services/main'

const nearFuture = DateTime.local().plus({ hours: 2 })
i18nManager.locale('en').formatRelativeTime(nearFuture, 'auto')
// "in 2 hours"

const farFuture = DateTime.local().plus({ hours: 200 })
i18nManager.locale('en').formatRelativeTime(farFuture, 'auto')
// "in 8 days"

参阅：Intl.RelativeTimeFormat 选项

formatPlural ​

使用 Intl.PluralRules 类查找数字的复数类别。当你需要在代码中而不是翻译字符串中处理复数化时，这很有用。

ts
import i18nManager from '@adonisjs/i18n/services/main'

i18nManager.locale('en').formatPlural(0)  // "other"
i18nManager.locale('en').formatPlural(1)  // "one"
i18nManager.locale('en').formatPlural(2)  // "other"

参阅：Intl.PluralRules 选项

formatList ​

使用 Intl.ListFormat 类将字符串数组格式化为人类可读的列表。

ts
import i18nManager from '@adonisjs/i18n/services/main'

i18nManager
  .locale('en')
  .formatList(['Me', 'myself', 'I'], { type: 'conjunction' })
// "Me, myself, and I"

i18nManager
  .locale('en')
  .formatList(['5 hours', '3 minutes'], { type: 'unit' })
// "5 hours, 3 minutes"

参阅：Intl.ListFormat 选项

formatDisplayNames ​

使用 Intl.DisplayNames 类将货币、语言、地区和日历的代码格式化为人类可读的名称。

ts
import i18nManager from '@adonisjs/i18n/services/main'

i18nManager
  .locale('en')
  .formatDisplayNames('INR', { type: 'currency' })
// "Indian Rupee"

i18nManager
  .locale('en')
  .formatDisplayNames('en-US', { type: 'language' })
// "American English"

参阅：Intl.DisplayNames 选项

配置 i18n Ally VSCode 扩展 ​

VSCode 的 i18n Ally 扩展提供内联翻译预览、缺失翻译检测和快速编辑。要为 AdonisJS 配置它，在你的 .vscode 目录中创建两个文件。

sh
mkdir -p .vscode
touch .vscode/i18n-ally-custom-framework.yml
touch .vscode/settings.json
json
{
  "i18n-ally.localesPaths": [
    "resources/lang"
  ],

监听缺失的翻译 ​

订阅 i18n:missing:translation 事件以跟踪应用中的缺失翻译。这对于开发期间的日志记录或告警很有用。

ts
import emitter from '@adonisjs/core/services/emitter'

emitter.on('i18n:missing:translation', function (event) {
  console.log(event.identifier)   // 缺失的翻译键
  console.log(event.hasFallback)  // 是否使用了回退
  console.log(event.locale)       // 请求的语言环境
})

重新加载翻译 ​

i18n 包在启动时加载翻译文件并在内存中缓存它们。如果你在应用运行时修改翻译文件，使用 reloadTranslations 方法刷新缓存。

ts
import i18nManager from '@adonisjs/i18n/services/main'

export default class AdminController {
  async refreshTranslations() {
    await i18nManager.reloadTranslations()
  }
}

进阶：创建自定义翻译加载器 ​

翻译加载器负责从持久存储加载翻译。默认文件系统加载器从 resources/lang 读取，但你可以创建自定义加载器以从数据库、远程 API 或任何其他来源读取。

加载器必须实现 TranslationsLoaderContract 接口，具有返回按语言环境分组的翻译的 load 方法。

ts
import type {
  LoaderFactory,
  TranslationsLoaderContract,
} from '@adonisjs/i18n/types'

/**
 * 加载器的配置选项
 */
export type DbLoaderConfig = {
  connection: string
  tableName: string
}

/**
 * 加载器实现
 */
export class DbLoader implements TranslationsLoaderContract {
  constructor(public config: DbLoaderConfig) {}

  async load() {
    /**
     * 在此查询数据库并返回按语言环境分组
     * 且键已扁平化的翻译
     */
    return {
      en: {
        'messages.greeting': 'Hello world',
        'messages.farewell': 'Goodbye',
      },
      fr: {
        'messages.greeting': 'Bonjour le monde',
        'messages.farewell': 'Au revoir',
      }
    }
  }
}

/**
 * 用于在配置中引用加载器的工厂函数
 */
export function dbLoader(config: DbLoaderConfig): LoaderFactory {
  return () => {
    return new DbLoader(config)
  }
}

使用自定义加载器 ​

使用工厂函数在配置文件中引用加载器。

ts
import { defineConfig } from '@adonisjs/i18n'
import { dbLoader } from '#app/i18n/db_loader'

const i18nConfig = defineConfig({
  defaultLocale: 'en',
  formatter: formatters.icu(),
  loaders: [
    dbLoader({
      connection: 'pg',
      tableName: 'translations'
    })
  ]
})

export default i18nConfig

进阶：创建自定义翻译格式化器 ​

翻译格式化器根据特定格式处理翻译字符串。默认 ICU 格式化器处理 ICU 消息语法，但你可以为其他格式（如 Fluent）创建自定义格式化器。

格式化器必须实现 TranslationsFormatterContract 接口，具有 format 方法。

ts
import type {
  FormatterFactory,
  TranslationsFormatterContract,
} from '@adonisjs/i18n/types'

/**
 * 格式化器实现
 */
export class FluentFormatter implements TranslationsFormatterContract {
  format(
    message: string,
    locale: string,
    data?: Record<string, any>
  ): string {
    /**
     * 使用你选择的格式处理消息
     * 并返回格式化后的字符串
     */
    return message // 你的格式化逻辑
  }
}

/**
 * 用于在配置中引用格式化器的工厂函数
 */
export function fluentFormatter(): FormatterFactory {
  return () => {
    return new FluentFormatter()
  }
}

使用自定义格式化器 ​

使用工厂函数在配置文件中引用格式化器。

ts
import { defineConfig } from '@adonisjs/i18n'
import { fluentFormatter } from '#app/i18n/fluent_formatter'

const i18nConfig = defineConfig({
  defaultLocale: 'en',
  formatter: fluentFormatter()
})

export default i18nConfig
