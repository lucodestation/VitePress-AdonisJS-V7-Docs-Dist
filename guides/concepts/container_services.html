容器服务 ​

本指南涵盖 AdonisJS 中的容器服务。你将了解到：

  • 什么是容器服务以及它们如何工作
  • 如何在应用中使用现有服务
  • 何时使用服务与依赖注入
  • 如何为包创建自己的服务

概述 ​

容器服务是 AdonisJS 中的一种便捷模式，简化了你访问框架功能的方式。当你需要使用路由、哈希或日志记录等功能时，你可以导入一个即用型实例，而不是手动构造类或直接与 IoC 容器交互。

这种模式存在是因为许多框架组件需要 IoC 容器已经知道如何提供的依赖。为了不让你在每个文件中自己解析这些依赖，AdonisJS 包将预配置的实例作为标准 ES 模块导出暴露出来。你像导入任何其他模块一样导入它们，它们立即就能工作。

理解容器服务 ​

没有容器服务，你有两种方式使用框架类。你可以导入一个类并自己构造它，手动提供其所有依赖。

ts
import { Router } from '@adonisjs/core/http'

export const router = new Router(/** Router 依赖 */)

或者，你可以使用 IoC 容器的 make 方法构造类，让容器处理依赖解析。

ts
import app from '@adonisjs/core/services/app'
import { Router } from '@adonisjs/core/http'

export const router = await app.make(Router)

容器服务通过做与第二种方法完全相同的事情来消除这种繁琐，但将其打包为便捷的导入。服务模块内部使用 IoC 容器并导出解析后的实例。

ts
import router from '@adonisjs/core/services/router'
import hash from '@adonisjs/core/services/hash'
import logger from '@adonisjs/core/services/logger'

当你导入一个服务时，你得到的是一个由 IoC 容器构造的单例实例，其所有依赖都已正确注入。服务本身只是一个薄封装，使该实例作为标准模块导出可用。

使用容器服务 ​

当你安装 AdonisJS 包时，容器服务自动可用。无需配置或注册。你只需导入服务并使用它。

以下是使用 Drive 服务将文件上传到 S3 的示例。

ts
import drive from '@adonisjs/drive/services/main'

export class PostsController {
  async store(post: Post, coverImage: File) {
    const coverImageName = 'random_name.jpg'

    /**
     * drive 服务让你直接访问
     * DriveManager 实例。使用它选择磁盘
     * 并执行文件操作。
     */
    const disk = drive.use('s3')
    await disk.put(coverImageName, coverImage)

    post.coverImage = coverImageName
    await post.save()
  }
}

这种方法很直接，除了导入服务之外不需要任何设置。Drive 服务是单例，因此同一实例在整个应用中共享。

改用依赖注入 ​

对于偏好依赖注入的应用，你可以将底层类直接注入到你的服务或控制器中。这种方法使你的代码更可测试，因为依赖可以轻松地被模拟或打桩。

以下是使用构造函数注入的相同文件上传功能。

ts
import { Disk } from '@adonisjs/drive'
import { inject } from '@adonisjs/core'

@inject()
export class PostService {
  /**
   * Disk 实例由 IoC 容器注入。
   * 这使得在测试期间交换实现或
   * 使用不同的磁盘配置变得容易。
   */
  constructor(protected disk: Disk) {
  }

  async save(post: Post, coverImage: File) {
    const coverImageName = 'random_name.jpg'

    await this.disk.put(coverImageName, coverImage)

    post.coverImage = coverImageName
    await post.save()
  }
}

使用依赖注入时，IoC 容器自动解析并注入 Disk 实例。你的类声明它需要什么，容器提供它。这种模式在编写需要与框架细节保持解耦的业务逻辑时特别有价值。

创建自己的服务 ​

如果你正在构建包或想要将自己的容器绑定作为服务暴露，你可以遵循 AdonisJS 内部使用的相同模式。容器服务只是一个从容器解析绑定并导出它的模块。

你可以在 GitHub 上查看完整实现以了解 Drive 包如何创建其服务。

ts
import app from '@adonisjs/core/services/app'

let drive: DriveManager

await app.booted(async () => {
  drive = await app.container.make('drive')
})

export { drive as default }

服务等待应用启动，然后从容器解析绑定并导出它。这确保所有服务提供者在服务尝试解析它们之前已注册其绑定。
