调试 ​

本指南涵盖 AdonisJS 应用的调试技术。你将了解到如何：

  • 配置 VSCode 以使用断点调试你的应用
  • 从命令行使用 Node.js 检查器
  • 使用 NODE_DEBUG 查看框架级调试日志
  • 使用 @dump 和 @dd 检查 Edge 模板中的变量
  • 在开发期间启用漂亮的错误页面

概述 ​

调试是开发中必不可少的一部分，AdonisJS 支持多种方法，具体取决于你的需求。对于快速检查，简单的 console.log 语句通常就足够了。对于更复杂的问题，你可以使用 VSCode 的集成调试器来设置断点、单步执行代码并检查变量。当你需要了解框架内部发生了什么时，调试日志提供了对 AdonisJS 内部的可见性。

Edge 模板有自己的调试工具 @dump 和 @dd，它们直接在浏览器中渲染变量内容。在开发期间，当出现问题时，异常处理器会自动显示包含堆栈跟踪和请求信息的详细错误页面。

VSCode 调试器 ​

VSCode 调试器提供最强大的调试体验，允许你设置断点、逐行单步执行代码，并检查调用栈和变量。当调试无法用简单日志语句解决的复杂问题时，使用此方法。

在项目根目录创建 .vscode/launch.json 文件，包含开发服务器、测试运行器和附加模式的配置。

json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Dev server",
      "program": "${workspaceFolder}/ace.js",
      "args": ["serve", "--hmr"],
      "skipFiles": ["<node_internals>/**"]
    },
    {
      "type": "node",
      "request": "launch",
      "name": "Tests",
      "program": "${workspaceFolder}/ace.js",
      "args": ["test", "--watch"],
      "skipFiles": ["<node_internals>/**"]
    },
    {
      "type": "node",
      "request": "attach",
      "name": "Attach Program",
      "port": 9229,
      "autoAttachChildProcesses": true,
      "skipFiles": ["<node_internals>/**"]
    }
  ]
}

Dev server 配置在启用 HMR 的情况下启动你的应用，非常适合调试 HTTP 请求处理、中间件和控制器。Tests 配置在监视模式下运行测试套件，允许你通过在测试文件或应用代码中设置断点来调试失败的测试。

调试 Ace 命令 ​

Attach Program 配置使用附加模式，而不是启动特定命令。这让你可以通过使用 --inspect 标志启动任何 Ace 命令，然后附加调试器来调试它。

调试 Ace 命令的步骤：

  1. 使用 Cmd+Shift+P（macOS）或 Ctrl+Shift+P（Windows/Linux）打开命令面板
  2. 搜索 Debug: Select and Start Debugging
  3. 选择 Attach Program 选项
  4. 使用 --inspect 标志运行你的 Ace 命令。
bash
node --inspect ace migration:run

调试器将附加到正在运行的进程，你的断点将被命中。

Node.js 检查器 ​

如果你不使用 VSCode 或更喜欢其他调试界面，可以直接使用 Node.js 检查器。使用 --inspect 标志启动开发服务器。

bash
node ace --inspect serve --hmr

这会在端口 9229 上启动 Node.js 检查器。然后你可以通过在 Chrome 中导航到 chrome://inspect 使用 Chrome DevTools 连接，或使用任何其他支持 Node.js 检查器协议的调试器。

框架调试日志 ​

AdonisJS 包包含调试日志，提供对框架内部的可见性。这些日志默认禁用，因为它们很冗长，但当你需要了解框架级别发生了什么时，它们非常宝贵。

在启动应用时设置 NODE_DEBUG 环境变量以启用调试日志。

bash
NODE_DEBUG=adonisjs:* node ace serve --hmr

通配符 * 启用来自所有 AdonisJS 包的日志。如果你已经知道要调查哪个包，直接指定它以减少噪音。

bash
# 仅调试 HTTP 层
NODE_DEBUG=adonisjs:http node ace serve --hmr

# 调试会话处理
NODE_DEBUG=adonisjs:session node ace serve --hmr

# 调试应用生命周期
NODE_DEBUG=adonisjs:app node ace serve --hmr

包名称遵循 adonisjs:<package-name> 约定，其中包名称对应你要调试的 AdonisJS 包。

Edge 模板调试 ​

使用 Edge 模板时，你可以使用 @dump 和 @dd 直接在浏览器中检查变量。这些标签渲染任何值的格式化表示，让你轻松理解模板接收到的数据。

@dump 标签 ​

@dump 标签输出值的格式化表示，并继续渲染模板的其余部分：

edge
{{-- 检查组件 props --}}
@dump($props.all())

{{-- 检查整个模板状态 --}}
@dump(state)

{{-- 检查特定变量 --}}
@dump(post)

@dd 标签 ​

@dd 标签（dump and die，转储并终止）立即停止模板渲染，只显示转储的值。当你想要专注于特定值而不需要页面其余输出时使用它：

edge
@dd(post)

{{-- 此行以下的任何内容都不会渲染 --}}
<h1>{{ post.title }}</h1>

设置 dumper ​

@dump 和 @dd 标签需要加载 dumper 的前端资源。将 @stack('dumper') 指令添加到布局的 <head> 部分。

edge
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    @stack('dumper')
  </head>
  <body>
    @!section('content')
  </body>
</html>

官方 AdonisJS 启动套件默认包含此设置。

配置 dumper ​

你可以通过从 config/app.ts 导出 dumper 配置来自定义 dumper 格式化输出的方式。

ts
import { defineConfig as dumperConfig } from '@adonisjs/core/dumper'

export const dumper = dumperConfig({
  /**
   * 控制台输出的设置（例如 console.log）
   */
  console: {
    depth: 10,
    collapse: ['DateTime', 'Date'],
    inspectStaticMembers: true,
  },

  /**
   * HTML 输出的设置（@dump 和 @dd）
   */
  html: {
    depth: 10,
    inspectStaticMembers: true,
  },
})

以下选项适用于 console 和 html 打印机。

showHidden

类型：boolean，默认值：false

包含不可枚举属性

depth

类型：number，默认值：5

嵌套结构（对象、数组、Map、Set）的最大深度

inspectObjectPrototype

类型：boolean | string，默认值：unless-plain-object

包含原型属性。设置为 true 表示所有对象，false 表示不包含，或 'unless-plain-object' 表示仅类实例。

inspectArrayPrototype

类型：boolean，默认值：false

包含数组原型属性

inspectStaticMembers

类型：boolean，默认值：false

包含类的静态成员

maxArrayLength

类型：number，默认值：100

数组、Map 和 Set 显示的最大项数

maxStringLength

类型：number，默认值：1000

字符串显示的最大字符数

collapse

类型：string[]，默认值：[]

不应进一步展开的构造函数名称数组

异常处理器调试模式 ​

在开发期间，当发生未处理的异常时，AdonisJS 会显示由 Youch 提供支持的详细错误页面。这些页面包括完整的堆栈跟踪、请求信息和应用状态，使问题诊断变得容易。

调试模式在开发环境中自动启用，在生产环境中禁用。此行为由异常处理器配置控制。
