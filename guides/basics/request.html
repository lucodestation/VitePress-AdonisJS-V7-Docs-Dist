Request ​

本指南涵盖 AdonisJS 中 HTTP 请求的处理。你将了解到：

  • 读取请求体和上传的文件
  • 访问查询字符串和路由参数
  • 处理请求头和元数据
  • 读取 cookie
  • 理解请求 ID 生成
  • 配置可信代理和 IP 地址提取

概述 ​

Request 类保存与 HTTP 请求相关的所有信息，包括请求体、上传的文件、查询字符串、URL、方法、头和 cookie。你通过 HttpContext 的 request 属性访问它，该属性在路由处理器、中间件和异常处理器中可用。

读取请求体和文件 ​

请求体包含客户端发送的数据，通常来自 HTML 表单或 API 请求。AdonisJS 使用 bodyparser 根据 Content-Type 头自动解析请求体，将 JSON、表单数据和 multipart 数据转换为易于使用的 JavaScript 对象。

访问整个请求体 ​

使用 all 方法将请求体中的所有数据作为对象检索。当你想要一起处理所有提交的字段时，这很有用。

ts
import router from '@adonisjs/core/services/router'

router.post('/signup', ({ request }) => {
  const body = request.all()
  console.log(body)
  // { fullName: 'John Doe', email: 'john@example.com', password: 'secret' }
})

TIP

类型安全和验证： 请求体数据不是类型安全的，因为 bodyparser 只收集和解析原始请求数据，不进行验证。使用验证系统确保请求数据的运行时安全和 TypeScript 类型安全。

访问特定字段 ​

当你需要从请求体中读取特定字段时，使用 input 方法。此方法接受字段名和可选的默认值（如果字段不存在）。

ts
import router from '@adonisjs/core/services/router'

router.post('/signup', ({ request }) => {
  const email = request.input('email')
  const newsletter = request.input('newsletter', false)

  console.log(email)
  console.log(newsletter)
})

你也可以使用 only 方法检索多个特定字段，或使用 except 方法检索除某些字段之外的所有字段。

ts
import router from '@adonisjs/core/services/router'

router.post('/signup', ({ request }) => {
  /**
   * 仅获取 fullName 和 email，忽略其他字段
   */
  const credentials = request.only(['fullName', 'email'])
  console.log(credentials)

  /**
   * 获取除 password 之外的所有字段
   */
  const safeData = request.except(['password'])
  console.log(safeData)
})

访问上传的文件 ​

通过 multipart 表单数据上传的文件使用 file 方法访问。该方法返回一个文件对象，包含元数据以及用于验证和存储的方法。

另请参阅：文件上传指南了解详细的文件处理和存储

ts
import router from '@adonisjs/core/services/router'

router.post('/avatar', ({ request }) => {
  const avatar = request.file('avatar')
  console.log(avatar)
})

你可以在访问文件时通过提供验证选项来验证文件。

ts
import router from '@adonisjs/core/services/router'

router.post('/avatar', ({ request }) => {
  const avatar = request.file('avatar', {
    size: '2mb',
    extnames: ['jpg', 'png', 'jpeg']
  })

  console.log(avatar)
})

TIP

文件验证方式： 你可以在使用 request.file() 访问文件时验证，或使用验证器验证。推荐使用验证器方式，因为它提供与其他请求数据一致的验证和更好的错误处理。

可用方法 ​

方法描述
all()将所有请求体数据作为对象返回
body()all() 方法的别名
input(key, defaultValue?)返回特定字段值，可选默认值
only(keys)仅返回指定字段
except(keys)返回除指定字段之外的所有字段
file(key, options?)返回上传的文件，可选验证

读取请求查询字符串和路由参数 ​

查询字符串和路由参数是通过 URL 传递数据的两种不同方式。查询字符串是 URL 中 ? 之后的部分（如 ?page=1&limit=10），而路由参数是路由模式中定义的动态段（如 /posts/:id）。

访问查询字符串参数 ​

使用 qs 方法将所有查询字符串参数作为对象检索。

ts
import router from '@adonisjs/core/services/router'

router.get('/posts', ({ request }) => {
  const queryString = request.qs()
  console.log(queryString)
  // { page: '1', limit: '10', orderBy: 'created_at' }
})

你可以使用 input 方法访问单个查询参数，该方法对请求体数据和查询字符串参数都有效。

ts
import router from '@adonisjs/core/services/router'

router.get('/posts', ({ request }) => {
  const page = request.input('page', 1)
  const limit = request.input('limit', 20)
  const orderBy = request.input('orderBy', 'id')

  console.log({ page, limit, orderBy })
})

访问路由参数 ​

路由参数通过 param 方法或直接访问 params 对象来获取。params 对象也可直接在 HttpContext 上使用。

ts
import router from '@adonisjs/core/services/router'

router.get('/posts/:id', ({ request }) => {
  const id = request.param('id')
  console.log(id)
})

可用方法 ​

方法描述
qs()将所有查询字符串参数作为对象返回
param(key, defaultValue?)返回特定路由参数，可选默认值
params()将所有路由参数作为对象返回

读取请求头、方法、URL 和 IP 地址 ​

请求元数据包括请求如何发起、来自何处以及客户端期望的响应格式等信息。这包括 HTTP 头、请求方法（GET、POST 等）、请求的 URL 和客户端的 IP 地址。

访问请求头 ​

使用 header 方法读取特定头值。头名称不区分大小写。

ts
import router from '@adonisjs/core/services/router'

router.get('/profile', ({ request }) => {
  const authToken = request.header('Authorization')
  const userAgent = request.header('User-Agent')

  console.log(authToken)
  console.log(userAgent)
})

你可以使用 headers 方法检索所有头。

ts
import router from '@adonisjs/core/services/router'

router.get('/debug', ({ request }) => {
  const allHeaders = request.headers()
  console.log(allHeaders)
})

访问请求方法 ​

请求方法（GET、POST、PUT、DELETE 等）通过 method 方法获取。

ts
import router from '@adonisjs/core/services/router'

router.all('/endpoint', ({ request }) => {
  const method = request.method()
  console.log(method) // 'GET', 'POST', 等
})

访问请求 URL ​

使用 url 方法获取不含域名和协议的请求 URL，或使用 completeUrl 获取包含域名的完整 URL。

ts
import router from '@adonisjs/core/services/router'

router.get('/posts', ({ request }) => {
  const path = request.url()
  console.log(path) // '/posts?page=1'

  const fullUrl = request.completeUrl()
  console.log(fullUrl) // 'https://example.com/posts?page=1'
})

访问客户端 IP 地址 ​

ip 方法返回客户端的 IP 地址。当你的应用位于反向代理或负载均衡器之后时，你需要配置可信代理以正确检测真实客户端 IP。

ts
import router from '@adonisjs/core/services/router'

router.get('/track', ({ request }) => {
  const clientIp = request.ip()
  console.log(clientIp)
})

当请求经过多个代理时，ips 方法返回 IP 地址数组。

ts
import router from '@adonisjs/core/services/router'

router.get('/track', ({ request }) => {
  const ipChain = request.ips()
  console.log(ipChain) // ['client-ip', 'proxy-1', 'proxy-2']
})

可用方法 ​

方法描述
header(key, defaultValue?)返回特定头值
headers()将所有头作为对象返回
method()返回 HTTP 方法（GET、POST 等）
url()返回不含域名的请求 URL
completeUrl()返回包含域名的完整 URL
ip()返回客户端 IP 地址
ips()在代理后返回 IP 数组
getPreviousUrl(allowedHosts, fallback?)从 Referer 头返回经过验证的前一个 URL

读取请求 cookie ​

Cookie 是存储在客户端浏览器中并随每个请求发送的小块数据。AdonisJS 提供通过 Request 类读取普通 cookie 和签名/加密 cookie 的方法。

访问签名 cookie ​

使用 cookie 方法读取签名 cookie 值。默认情况下，所有 cookie 都是签名的。

ts
import router from '@adonisjs/core/services/router'

router.get('/preferences', ({ request }) => {
  const theme = request.cookie('theme', 'light')
  const language = request.cookie('language', 'en')

  console.log({ theme, language })
})

访问加密 cookie ​

使用 encryptedCookie 读取加密 cookie。此方法自动解密并验证 cookie 值。

ts
import router from '@adonisjs/core/services/router'

router.get('/dashboard', ({ request }) => {
  const sessionId = request.encryptedCookie('session_id')
  console.log(sessionId)
})

可用方法 ​

方法描述
cookie(key, defaultValue?)返回签名 cookie 值
cookiesList()将所有 cookie 作为对象返回，不进行解密或取消签名
encryptedCookie(key, defaultValue?)返回解密后的 cookie 值
plainCookie(key, defaultValue?)返回普通 cookie 的值

读取请求 ID 并理解 ID 生成 ​

AdonisJS 中的每个 HTTP 请求都被分配一个唯一的请求 ID。此 ID 对于分布式追踪、日志记录以及在应用和微服务之间关联相关操作非常有用。

访问请求 ID ​

使用 id 方法检索分配给当前请求的唯一标识符。

ts
import router from '@adonisjs/core/services/router'

router.get('/api/posts', ({ request }) => {
  const requestId = request.id()
  console.log(`Processing request: ${requestId}`)
})

请求 ID 如何生成 ​

AdonisJS 按优先顺序使用以下方法之一生成请求 ID。

TIP

你必须在 config/app.ts 文件中启用请求 ID 生成，AdonisJS 才会生成请求 ID（在缺少 X-Request-Id 头的情况下）。

  1. 从 X-Request-Id 头： 如果客户端或代理发送了 X-Request-Id 头，AdonisJS 使用该值。这允许你跨多个服务追踪请求。
  2. 由 AdonisJS 生成： 如果不存在 X-Request-Id 头，AdonisJS 默认使用 uuid 包生成唯一 ID（如果已启用）。

使用请求 ID 进行分布式追踪 ​

请求 ID 在分布式系统中特别有价值，其中单个用户请求可能触发跨多个服务的操作。通过在每个操作中记录请求 ID，你可以追踪请求在系统中的完整流程。

ts
import router from '@adonisjs/core/services/router'
import logger from '@adonisjs/core/services/logger'

router.post('/checkout', async ({ request }) => {
  const requestId = request.id()

  logger.info({ requestId }, 'Starting checkout process')
  // 你的结账逻辑
  logger.info({ requestId }, 'Checkout completed')
})

内容协商 ​

内容协商允许你的应用根据客户端接受的内容提供不同的响应格式或语言。Request 类提供读取 Accept、Accept-Language、Accept-Charset 和 Accept-Encoding 头的方法，并将它们与你的应用支持的格式进行匹配。

选择响应格式 ​

使用 accepts 方法根据客户端的 Accept 头确定最佳响应格式。当你的 API 可以返回 JSON、HTML 或 XML 等多种格式的数据时，这很有用。

ts
import router from '@adonisjs/core/services/router'

router.get('/posts', ({ request, response }) => {
  const bestFormat = request.accepts(['html', 'json'])

  if (bestFormat === 'json') {
    return response.json({ posts: [] })
  }

  if (bestFormat === 'html') {
    return response.view('posts/index')
  }

  // 客户端不接受任何支持的格式
  return response.status(406).send('Not Acceptable')
})

types 方法按客户端偏好顺序返回所有接受的内容类型。

ts
import router from '@adonisjs/core/services/router'

router.get('/posts', ({ request }) => {
  const acceptedTypes = request.types()
  console.log(acceptedTypes) // ['application/json', 'text/html', '*/*']
})

国际化 ​

使用 language 方法根据客户端的 Accept-Language 头确定最佳语言。这有助于以用户偏好的语言提供内容。

ts
import router from '@adonisjs/core/services/router'

router.get('/welcome', ({ request, response }) => {
  const language = request.language(['en', 'fr', 'es']) || 'en'

  const messages = {
    en: 'Welcome',
    fr: 'Bienvenue',
    es: 'Bienvenido'
  }

  return response.send(messages[language])
})

languages 方法按客户端偏好顺序返回所有接受的语言。

ts
import router from '@adonisjs/core/services/router'

router.get('/welcome', ({ request }) => {
  const acceptedLanguages = request.languages()
  console.log(acceptedLanguages) // ['en-US', 'fr', 'es']
})

可用方法 ​

方法描述
accepts(types)返回最佳匹配的内容类型或 null
types()按偏好顺序返回所有接受的内容类型
language(languages)返回最佳匹配的语言或 null
languages()按偏好顺序返回所有接受的语言
charset(charsets)返回最佳匹配的字符集或 null
charsets()按偏好顺序返回所有接受的字符集
encoding(encodings)返回最佳匹配的编码或 null
encodings()按偏好顺序返回所有接受的编码

信任代理服务器 ​

当你的应用运行在反向代理（如 Nginx）或负载均衡器之后时，你需要配置信任哪些代理 IP 地址。这允许 AdonisJS 正确读取代理添加到请求中的 X-Forwarded-* 头。

ts
import env from '#start/env'
import { defineConfig } from '@adonisjs/core/http'
import proxyAddr from 'proxy-addr'

export const http = defineConfig({
  /**
   * 信任回环地址和私有 IP 范围。
   * 这对于大多数部署场景是安全的，你的代理
   * 运行在同一台机器或私有网络上。
   */
  trustProxy: proxyAddr.compile(['loopback', 'uniquelocal'])
})

trustProxy 选项接受 proxy-addr 包支持的任何值。常见配置包括：

ts
// 信任所有代理（不推荐用于生产环境）
trustProxy: () => true

// 信任特定 IP 地址
trustProxy: proxyAddr.compile(['127.0.0.1', '192.168.1.1'])

// 使用 CIDR 表示法信任 IP 范围
trustProxy: proxyAddr.compile('10.0.0.0/8')

自定义 IP 地址提取 ​

默认情况下，AdonisJS 使用标准方法从请求中提取客户端 IP 地址。但是，当运行在代理或 Cloudflare 等 CDN 之后时，你可能需要从自定义头中提取 IP。

ts
import env from '#start/env'
import { defineConfig } from '@adonisjs/core/http'
import type { IncomingMessage } from 'node:http'

export const http = defineConfig({
  /**
   * 从 Cloudflare 的 CF-Connecting-IP 头提取 IP
   * 如果头不存在，回退到标准 IP 提取
   */
  getIp(request: IncomingMessage) {
    const cloudflareIp = request.headers['cf-connecting-ip']

    if (cloudflareIp && typeof cloudflareIp === 'string') {
      return cloudflareIp
    }

    // 返回 undefined 以回退到默认 IP 提取
    return undefined
  }
})

getIp 方法接收 Node.js IncomingMessage 对象，必须返回字符串 IP 地址或 undefined 以回退到默认行为。当与在自定义头中提供真实客户端 IP 的 CDN 一起工作时，这很有用。
