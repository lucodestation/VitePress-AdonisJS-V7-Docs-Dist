Response ​

本指南涵盖 AdonisJS 的 Response 类以及用于构建 HTTP 响应的可用方法。你将了解到：

  • 以不同格式发送响应体
  • 处理头和 cookie
  • 处理重定向和文件下载
  • 理解响应序列化如何工作
  • 使用自定义方法扩展 Response 类

概述 ​

Response 类提供了在 AdonisJS 应用中构建 HTTP 响应的辅助工具。与直接使用 Node.js 的原始响应对象不同，Response 类为常见任务（如发送 JSON、设置头、处理重定向和流式传输文件下载）提供了流畅、富有表现力的 API。

Response 类通过 ctx.response 属性可用。你可以在应用中的路由处理器、中间件和异常处理器中访问它。对于许多简单的响应，你可以直接从路由处理器返回值，AdonisJS 会自动使用 Response 类发送它们。

发送响应体 ​

Response 类提供多种发送响应体的方式。你可以直接从路由处理器返回值，或使用显式的响应方法。

从路由处理器返回值 ​

最简单的方法是从路由处理器直接返回值。AdonisJS 会自动序列化该值并设置适当的内容头。

ts
import router from '@adonisjs/core/services/router'

router.get('/', async () => {
  /**
   * 返回纯文本，content-type: text/plain
   */
  return 'This is the homepage.'
})

router.get('/welcome', async () => {
  /**
   * 返回 HTML 片段，content-type: text/html
   */
  return '<p>This is the homepage</p>'
})

router.get('/api/page', async () => {
  /**
   * 返回 JSON，content-type: application/json
   */
  return { page: 'home' }
})

router.get('/timestamp', async () => {
  /**
   * Date 实例被转换为 ISO 字符串
   */
  return new Date()
})

使用 response.send() ​

你也可以显式使用 response.send() 方法，它提供相同的自动内容类型检测。

ts
import router from '@adonisjs/core/services/router'

router.get('/', async ({ response }) => {
  /**
   * send() 方法与返回值的工作方式相同。
   * 当你需要在发送前设置头或状态时很有用。
   */
  response.send('This is the homepage')
})

router.get('/data', async ({ response }) => {
  /**
   * 对象和数组自动被字符串化
   */
  response.send({ page: 'home' })
})

强制 JSON 响应 ​

当你需要确保响应以 JSON 发送时（即使它可能被检测为 HTML），使用 response.json() 方法。

另请参阅：响应体序列化

ts
import Post from '#models/post'
import type { HttpContext } from '@adonisjs/core/http'

export default class PostsController {
  async index({ response }: HttpContext) {
    const posts = await Post.all()

    /**
     * 显式设置 content-type 为 application/json
     * 并序列化 posts 数组
     */
    response.json(posts)
  }
}

处理头 ​

Response 类提供设置、追加和移除 HTTP 头的方法。头必须在发送响应体之前设置。

设置头 ​

使用 response.header() 方法设置响应头。如果头已存在，它将被覆盖。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class ApiController {
  async index({ response }: HttpContext) {
    /**
     * 设置自定义头用于 API 版本控制
     */
    response.header('X-API-Version', 'v1')

    /**
     * 设置缓存控制头
     */
    response.header('Cache-Control', 'public, max-age=3600')

    return { status: 'ok' }
  }
}

安全地设置头 ​

response.safeHeader() 方法仅在头不存在时设置它。当你想要提供默认值而不覆盖现有头时，这很有用。

ts
import type { HttpContext } from '@adonisjs/core/http'
import type { NextFn } from '@adonisjs/core/types/http'

export default class CorsMiddleware {
  async handle({ response }: HttpContext, next: NextFn) {
    /**
     * 仅当其他中间件尚未设置时设置 CORS 头
     */
    response.safeHeader('Access-Control-Allow-Origin', '*')

    await next()
  }
}

追加到头 ​

某些头可以有多个值。使用 response.append() 添加附加值而不移除现有的值。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class DownloadsController {
  async show({ response }: HttpContext) {
    /**
     * 为不同 cookie 追加多个 Set-Cookie 头
     */
    response.append('Set-Cookie', 'session=abc123; HttpOnly')
    response.append('Set-Cookie', 'preferences=dark-mode; Path=/')

    return { download: 'ready' }
  }
}

移除头 ​

使用 response.removeHeader() 移除先前设置的头。

ts
import type { HttpContext } from '@adonisjs/core/http'
import type { NextFn } from '@adonisjs/core/types/http'

export default class SecurityMiddleware {
  async handle({ response }: HttpContext, next: NextFn) {
    await next()

    /**
     * 移除 server 头以隐藏服务器实现细节
     */
    response.removeHeader('X-Powered-By')
  }
}

处理重定向 ​

response.redirect() 方法返回 Redirect 类的实例，它提供了用于创建具有不同目标和选项的重定向响应的流畅 API。

重定向到路径 ​

使用 response.redirect().toPath() 重定向到特定 URI 或外部 URL。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class AuthController {
  async logout({ response, auth }: HttpContext) {
    await auth.logout()

    /**
     * 登出后重定向到首页
     */
    response.redirect().toPath('/')
  }

  async external({ response }: HttpContext) {
    /**
     * 重定向到外部网站
     */
    response.redirect().toPath('https://adonisjs.com')
  }
}

重定向到命名路由 ​

response.redirect().toRoute() 方法接受路由标识符及其参数，使 URL 更改时重定向易于维护。

ts
import Post from '#models/post'
import { createPostValidator } from '#validators/post'
import type { HttpContext } from '@adonisjs/core/http'

export default class PostsController {
  async store({ request, response }: HttpContext) {
    /**
     * 验证传入的请求数据
     */
    const payload = await request.validateUsing(createPostValidator)

    /**
     * 创建帖子
     */
    const post = await Post.create(payload)

    /**
     * 重定向到新创建帖子的显示页面
     */
    response.redirect().toRoute('posts.show', [post.id])
  }
}

重定向回上一页 ​

使用 response.redirect().back() 重定向到上一页。该方法读取 Referer 头并验证引用者的主机是否匹配当前请求的 Host 头。如果引用者缺失、无效或来自未知主机，重定向会回退到 /。

你可以将自定义回退 URL 作为参数传递给 back()。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class CommentsController {
  async destroy({ response, params }: HttpContext) {
    /**
     * 重定向回用户来自的页面。
     * 如果未找到有效引用者，回退到 /posts。
     */
    response.redirect().back('/posts')
  }
}

允许外部引用者主机 ​

默认情况下，back() 只接受匹配当前请求主机的引用者。这防止了开放重定向攻击，即恶意引用者可能将用户发送到外部站点。

如果你的应用跨越多个域（例如 app.example.com 和 admin.example.com），你可以将可信主机添加到 redirect.allowedHosts 配置中，使 back() 也接受来自这些域的引用者。

ts
import { defineConfig } from '@adonisjs/core/http'

export const http = defineConfig({
  redirect: {
    allowedHosts: [
      'app.example.com',
      'admin.example.com',
    ],
  },
})

自定义先前 URL 解析 ​

使用 @adonisjs/session 包时，你可以通过设置 redirect.previousUrl 属性在会话中存储先前的 URL。设置后，back() 将使用会话值而不是 Referer 头。

当你的应用将用户重定向到第三方网站（如 OAuth 提供商）时，这很有用。当用户返回时，浏览器的 Referer 头将指向外部站点，因此 back() 会回退到 /，而不是用户最初所在的页面。通过在重定向之前将预期返回 URL 存储在会话中，你可以确保 back() 将他们带到正确的位置。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class AuthController {
  async redirectToProvider({ session, response }: HttpContext) {
    /**
     * 存储当前 URL，以便在 OAuth 流程
     * 完成后 back() 返回这里
     */
    session.put('redirect.previousUrl', '/dashboard')
    response.redirect().toPath('https://accounts.google.com/o/oauth2/auth')
  }

  async handleCallback({ response }: HttpContext) {
    /**
     * 这将重定向到 /dashboard（来自会话）
     * 而不是使用 Referer 头
     */
    response.redirect().back()
  }
}

TIP

基于会话的先前 URL 解析需要 @adonisjs/session 包。没有它，back() 将始终使用 Referer 头。

设置重定向状态码 ​

默认情况下，重定向使用 302 状态码。使用 status() 方法设置不同的重定向状态。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class PagesController {
  async oldPage({ response }: HttpContext) {
    /**
     * 移动页面的永久重定向（301）
     */
    response.redirect().status(301).toPath('/new-page')
  }
}

转发查询字符串 ​

在 AdonisJS 启动套件中，查询字符串转发通过服务器配置中的 redirect.forwardQueryString 选项默认启用。你可以在 config/app.ts 文件中验证这一点。

ts
import { defineConfig } from '@adonisjs/core/http'

export const http = defineConfig({
  redirect: {
    forwardQueryString: true,
  },
})

启用后，所有重定向会自动将当前 URL 的查询字符串带到目标。例如，如果当前 URL 是 /search?q=adonis&sort=date，你重定向到 /results，用户将被发送到 /results?q=adonis&sort=date。

你可以通过向 withQs() 传递 false 为特定重定向禁用转发。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class AuthController {
  async logout({ response }: HttpContext) {
    /**
     * 为此重定向禁用查询字符串转发。
     * 用户将被发送到 / 而不带任何查询参数。
     */
    response.redirect().withQs(false).toPath('/')
  }
}

如果默认未启用查询字符串转发，你可以通过不带参数调用 withQs() 为特定重定向启用它。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class SearchController {
  async filter({ response }: HttpContext) {
    /**
     * 将现有查询参数转发到新 URL。
     * 如果当前 URL 是 /search?q=adonis&sort=date，
     * 这会重定向到 /results?q=adonis&sort=date
     */
    response.redirect().withQs().toPath('/results')
  }
}

设置自定义查询字符串 ​

向 withQs() 传递对象以设置自定义查询参数。多次链接该方法以追加额外参数。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class ProductsController {
  async search({ response }: HttpContext) {
    /**
     * 使用自定义查询参数重定向。
     * 结果为 /products?category=electronics&sort=price
     */
    response
      .redirect()
      .withQs({ category: 'electronics' })
      .withQs({ sort: 'price' })
      .toPath('/products')
  }
}

重定向到预期 URL ​

toIntended() 方法重定向到先前通过 session.setIntendedUrl() 存储在会话中的 URL。如果未存储预期 URL，则重定向到提供的回退。存储的 URL 在使用后会被消费（从会话中移除）。

withIntendedUrl() 方法将当前请求 URL 作为预期目标存储在会话中。它仅对匹配路由的 GET、导航请求存储。

这些方法在安装了 @adonisjs/session 包时可用。完整示例请参阅登录后重定向到预期 URL。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class SessionController {
  async store({ auth, request, response }: HttpContext) {
    await auth.use('web').login(
      await User.verifyCredentials(
        request.input('email'),
        request.input('password')
      )
    )

    /**
     * 重定向到预期 URL 或 /dashboard
     */
    return response.redirect().toIntended('/dashboard')
  }
}

流式传输和下载 ​

Response 类提供流式传输数据和提供文件下载的方法。这些方法自动处理适当的头、缓存和清理。

流式响应 ​

使用 response.stream() 发送可读流作为响应。AdonisJS 等待路由处理器和上游中间件完成，然后开始从流中读取。

ts
import { createReadStream } from 'node:fs'
import type { HttpContext } from '@adonisjs/core/http'

export default class ExportsController {
  async generate({ response }: HttpContext) {
    /**
     * 从文件创建可读流
     */
    const stream = createReadStream('./exports/data.csv')

    /**
     * 将文件流式传输到客户端。
     * AdonisJS 自动处理背压和清理。
     */
    response.stream(stream)
  }
}

下载文件 ​

response.download() 方法流式传输文件并设置适当的下载头。它接受文件的绝对路径。

ts
import app from '@adonisjs/core/services/app'
import type { HttpContext } from '@adonisjs/core/http'

export default class InvoicesController {
  async download({ response, params }: HttpContext) {
    /**
     * 构建发票文件的绝对路径
     */
    const filePath = app.makePath(`storage/invoices/${params.id}.pdf`)

    /**
     * 流式传输文件以供下载，支持 ETag。
     * 只要文件内容不变，浏览器就会缓存响应。
     */
    response.download(filePath)
  }
}

使用自定义文件名强制下载 ​

使用 response.attachment() 强制下载并指定自定义文件名。浏览器将提示用户以给定名称保存文件。

ts
import app from '@adonisjs/core/services/app'
import type { HttpContext } from '@adonisjs/core/http'

export default class ReportsController {
  async export({ response, params }: HttpContext) {
    /**
     * 报告文件的绝对路径
     */
    const filePath = app.makePath(`storage/reports/${params.id}.xlsx`)

    /**
     * 使用用户友好的文件名强制下载。
     * 第二个参数设置 Content-Disposition 头中的文件名。
     */
    response.attachment(filePath, `monthly-report-${params.month}.xlsx`)
  }
}

设置响应状态 ​

Response 类提供设置 HTTP 状态码的方法。状态码向客户端传达请求的结果。

设置状态码 ​

使用 response.status() 设置 HTTP 状态码。此方法覆盖任何先前设置的状态码。

ts
import Post from '#models/post'
import type { HttpContext } from '@adonisjs/core/http'

export default class PostsController {
  async store({ request, response }: HttpContext) {
    const post = await Post.create(request.all())

    /**
     * 为成功的资源创建返回 201 Created
     */
    response.status(201)

    return post
  }
}

安全地设置状态 ​

response.safeStatus() 方法仅在尚未设置状态码时设置它。这在中间件中很有用，当你想要提供默认值而不覆盖显式状态码时。

ts
import type { HttpContext } from '@adonisjs/core/http'
import type { NextFn } from '@adonisjs/core/types/http'

export default class JsonApiMiddleware {
  async handle({ response }: HttpContext, next: NextFn) {
    await next()

    /**
     * 仅在尚未设置时设置默认成功状态。
     * 控制器特定的状态码优先。
     */
    response.safeStatus(200)
  }
}

状态快捷方法 ​

AdonisJS 提供在一次调用中设置状态码和响应体的快捷方法。

ts
import User from '#models/user'
import type { HttpContext } from '@adonisjs/core/http'

export default class UsersController {
  async show({ response, params }: HttpContext) {
    const user = await User.find(params.id)

    if (!user) {
      /**
       * 在一次调用中设置状态 404 并发送响应体
       */
      return response.notFound({ error: 'User not found' })
    }

    return user
  }

  async destroy({ response, params, auth }: HttpContext) {
    const user = await User.findOrFail(params.id)

    if (user.id !== auth.user.id) {
      /**
       * 设置状态 403 并发送错误消息
       */
      return response.forbidden({ error: 'Cannot delete other users' })
    }

    await user.delete()
    return response.noContent()
  }
}

处理 cookie ​

Response 类提供设置具有不同安全级别的 cookie 的方法。AdonisJS 支持签名 cookie、加密 cookie 和普通 cookie。

设置签名 cookie ​

response.cookie() 方法创建签名 cookie。签名 cookie 无法被篡改，但其内容对客户端可见。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class PreferencesController {
  async update({ response, request }: HttpContext) {
    const theme = request.input('theme')

    /**
     * 设置 2 小时后过期的签名 cookie。
     * 签名防止客户端篡改。
     */
    response.cookie('theme', theme, {
      maxAge: '2h'
    })

    return { success: true }
  }
}

设置加密 cookie ​

使用 response.encryptedCookie() 加密 cookie 值。app.appKey 加密该值，使其对客户端不可读。如果应用密钥更改，cookie 将无法解密。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class SessionsController {
  async create({ response, auth }: HttpContext) {
    /**
     * 在加密 cookie 中存储敏感会话数据。
     * 该值使用 app.appKey 加密。
     */
    response.encryptedCookie('session_data', {
      userId: auth.user.id,
      loginAt: new Date()
    })

    return { success: true }
  }
}

设置普通 cookie ​

response.plainCookie() 方法创建 base64 编码的 cookie，不进行签名或加密。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class TrackingController {
  async view({ response }: HttpContext) {
    /**
     * 为非敏感跟踪数据设置普通 cookie
     */
    response.plainCookie('last_visit', new Date().toISOString())

    return { success: true }
  }
}

支持的 cookie 值类型 ​

Cookie 值可以是以下任何数据类型：string、number、bigInt、boolean、null、object 和 array。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class CartController {
  async add({ response, request }: HttpContext) {
    const cartItems = [
      { id: 1, name: 'Product A', quantity: 2 },
      { id: 2, name: 'Product B', quantity: 1 }
    ]

    /**
     * 数组和对象自动被序列化
     */
    response.encryptedCookie('cart', cartItems)

    return { success: true }
  }
}

Cookie 选项 ​

所有 cookie 方法都接受 options 对象以控制 cookie 行为。这些选项与 config/app.ts 中 http.cookie 块下的配置匹配。

ts
import type { HttpContext } from '@adonisjs/core/http'

export default class AuthController {
  async login({ response, auth }: HttpContext) {
    /**
     * 使用安全选项设置身份认证 cookie
     */
    response.encryptedCookie('auth_token', auth.token, {
      domain: '',
      path: '/',
      maxAge: '2h',
      httpOnly: true,      // 防止 JavaScript 访问
      secure: true,        // 仅通过 HTTPS 发送
      sameSite: 'lax',     // CSRF 保护
      partitioned: false,  // 实验性：CHIPS
      priority: 'medium'   // 实验性：Cookie 优先级
    })

    return { success: true }
  }
}

domain

类型：string

Cookie 域。空字符串表示当前域。

path

类型：string

Cookie 路径。默认是 /。

maxAge

类型：string | number

Cookie 过期时间。可以是像 '2h' 这样的持续时间字符串或毫秒数。

httpOnly

类型：boolean

防止 JavaScript 访问 cookie。

secure

类型：boolean

仅通过 HTTPS 连接发送 cookie。

sameSite

类型：'lax' | 'strict' | 'none'

CSRF 保护。默认是 'lax'。

partitioned

类型：boolean

实验性：启用 cookie 分区（CHIPS）。

priority

类型：'low' | 'medium' | 'high'

实验性：浏览器的 cookie 优先级提示。

在响应发送后运行操作 ​

response.onFinish() 方法允许你注册在响应发送到客户端后执行的回调。这对于清理任务、日志记录或不应阻塞响应的操作很有用。

文件下载后清理 ​

一个常见用例是在临时文件流式传输到客户端后删除它们。

ts
import { unlink } from 'node:fs/promises'
import app from '@adonisjs/core/services/app'
import type { HttpContext } from '@adonisjs/core/http'

export default class FilesController {
  async download({ response, params }: HttpContext) {
    const filePath = app.makePath(`tmp/exports/${params.id}.zip`)

    /**
     * 在流式传输文件之前注册清理回调
     */
    response.onFinish(async () => {
      await unlink(filePath)
    })

    /**
     * 流式传输文件。下载完成后，
     * 清理回调将自动运行。
     */
    response.download(filePath)
  }
}

记录响应指标 ​

你可以使用 onFinish() 记录分析或指标，而不会延迟响应。

ts
import type { HttpContext } from '@adonisjs/core/http'
import type { NextFn } from '@adonisjs/core/types/http'

export default class AnalyticsMiddleware {
  async handle({ response, request }: HttpContext, next: NextFn) {
    const startTime = Date.now()

    /**
     * 在响应发送后注册分析日志记录。
     * 这不会延迟对客户端的响应。
     */
    response.onFinish(() => {
      const duration = Date.now() - startTime
      console.log(`${request.method()} ${request.url()} - ${duration}ms`)
    })

    await next()
  }
}

响应体序列化 ​

Response 类自动序列化响应体，并根据你发送的数据类型设置适当的内容类型头。

当你发送响应时，AdonisJS 执行两个操作：将值序列化为适合 HTTP 传输的字符串格式，并设置适当的 content-type 和 content-length 头。

数组和对象

  • Content-Type： application/json
  • 序列化行为： 使用安全字符串化（类似 JSON.stringify()，但移除循环引用并序列化 BigInt）

HTML 片段

  • Content-Type： text/html
  • 序列化行为： 按原样发送（以 < 开头的字符串）

数字和布尔值

  • Content-Type： text/plain
  • 序列化行为： 转换为字符串

Date 实例

  • Content-Type： text/plain
  • 序列化行为： 使用 toISOString() 转换为 ISO 字符串

正则表达式

  • Content-Type： text/plain
  • 序列化行为： 使用 toString() 转换为字符串

Error 对象

  • Content-Type： text/plain
  • 序列化行为： 使用 toString() 转换为字符串

JSONP 响应

  • Content-Type： text/javascript
  • 序列化行为： 适当字符串化

其他纯字符串

  • Content-Type： text/plain
  • 序列化行为： 按原样发送

其他数据类型

  • Content-Type： -
  • 序列化行为： 导致异常

这种自动处理意味着你很少需要手动设置 content-type 头。

ts
import router from '@adonisjs/core/services/router'

router.get('/api/data', async () => {
  /**
   * 返回 JSON，content-type: application/json
   * BigInt 值安全地序列化为字符串
   */
  return {
    id: BigInt(9007199254740991),
    timestamp: new Date(),
    active: true
  }
})

router.get('/page', async () => {
  /**
   * 返回 HTML，content-type: text/html
   */
  return '<h1>Welcome</h1>'
})

router.get('/text', async () => {
  /**
   * 返回纯文本，content-type: text/plain
   */
  return 'Hello, world!'
})

扩展 HttpResponse 类 ​

你可以使用宏和 getter 向 HttpResponse 类添加自定义方法和属性。这允许你创建符合应用需求的可重用响应辅助工具。

TIP

如果你对宏和 getter 的概念不熟悉，请阅读扩展 AdonisJS 指南。

添加自定义方法 ​

使用 HttpResponse.macro() 向应用中的所有响应实例添加方法。

ts
import { HttpResponse } from '@adonisjs/core/http'

export default class AppProvider {
  async boot() {
    /**
     * 添加自定义方法以发送结构一致的 API 响应
     */
    HttpResponse.macro('api', function (data: any, meta?: Record<string, any>) {
      return this.json({
        success: true,
        data: data,
        meta: meta || {}
      })
    })

    /**
     * 添加分页响应的自定义方法
     */
    HttpResponse.macro('paginated', function (items: any[], pagination: any) {
      return this.json({
        data: items,
        pagination: {
          page: pagination.page,
          perPage: pagination.perPage,
          total: pagination.total
        }
      })
    })
  }
}

扩充 HttpResponse 类类型 ​

添加自定义方法后，你必须通过扩充 HttpResponse 接口告知 TypeScript。否则，尝试使用自定义方法时会得到类型错误。

ts
import { HttpResponse } from '@adonisjs/core/http'

declare module '@adonisjs/core/http' {
  export interface HttpResponse {
    /**
     * 发送标准化的 API 响应
     */
    api(data: any, meta?: Record<string, any>): void

    /**
     * 发送分页响应
     */
    paginated(items: any[], pagination: {
      page: number
      perPage: number
      total: number
    }): void
  }
}

使用自定义方法 ​

定义后，你的自定义方法在所有响应实例上可用。

ts
import Post from '#models/post'
import type { HttpContext } from '@adonisjs/core/http'

export default class PostsController {
  async index({ response }: HttpContext) {
    const posts = await Post.all()

    /**
     * 使用自定义 api() 方法获得一致的响应
     */
    return response.api(posts, {
      version: 'v1',
      timestamp: new Date()
    })
  }

  async paginated({ response, request }: HttpContext) {
    const page = request.input('page', 1)
    const posts = await Post.query().paginate(page, 20)

    /**
     * 使用自定义 paginated() 方法
     */
    return response.paginated(posts.all(), posts.getMeta())
  }
}
