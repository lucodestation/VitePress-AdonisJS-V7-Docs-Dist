Edge 模板 ​

本指南涵盖在 AdonisJS 应用中使用 Edge 模板。你将了解到如何从控制器渲染模板、向模板传递数据、使用布局和组件、使用超媒体启动套件中的预构建组件，以及调试模板问题。

概述 ​

Edge 是 Node.js 的服务端模板引擎，允许你在服务器上组合 HTML 标记并将最终的静态 HTML 发送到浏览器。由于模板完全在服务端执行，它们可以利用核心框架功能，如身份认证、授权检查和翻译系统。

当你在 AdonisJS 中创建超媒体应用时，Edge 已预配置并可直接使用。模板存储在 resources/views 目录中，文件扩展名为 .edge，你通过 HTTP 上下文的 view 属性从路由处理器或控制器渲染它们。

Edge 在 edgejs.dev 有全面的文档，详细涵盖模板语法、组件系统和所有可用功能。本指南专注于在 AdonisJS 应用中使用 Edge，并介绍超媒体启动套件中包含的预构建组件。

你的第一个模板 ​

让我们创建一个显示博客帖子列表的简单页面。此示例演示了在 AdonisJS 中渲染模板的基本工作流。

步骤 1：创建模板文件 ​

使用 Ace 命令生成新模板。

bash
node ace make:view pages/posts/index
# CREATE: resources/views/pages/posts/index.edge

步骤 2：添加模板内容 ​

打开 resources/views/pages/posts/index.edge 并添加以下内容。

edge
@layout()
  @each(post in posts)
    <div>
      <h2>
        {{ post.title }}
      </h2>
      <div>
        <p>{{{ excerpt(post.content, 280) }}}</p>
      </div>
    </div>
  @end
@end

关于此模板需要理解的几个重要事项：

  • @layout() 组件用完整的 HTML 文档结构（包括 <html>、<head> 和 <body> 标签）包裹你的内容。我们将在本指南后面详细探讨布局。

  • @each 标签遍历 posts 数组并为每个帖子渲染内容。Edge 提供多个标签如 @if、@else 和 @elseif 用于在模板中编写逻辑。你可以在 Edge 语法参考中了解所有可用标签。

  • 双花括号 {{ }} 求值并输出 JavaScript 表达式。三花括号 {{{ }}} 做同样的事情但不转义 HTML，这对于渲染富内容很有用。

步骤 3：定义路由 ​

创建处理帖子页面请求的路由。

ts
import router from '@adonisjs/core/services/router'
import { controllers } from '#generated/controllers'

router.get('posts', [controllers.PostsController, 'index'])

步骤 4：创建控制器 ​

创建一个使用帖子数据渲染模板的控制器。

ts
import Post from '#models/post'
import type { HttpContext } from '@adonisjs/core/http'

export default class PostsController {
  async index({ view }: HttpContext) {
    /**
     * 渲染位于 resources/views/pages/posts/index.edge 的模板
     * 第一个参数是模板路径（相对于 resources/views）
     * 第二个参数是模板状态（与模板共享的数据）
     */
    return view.render('pages/posts/index', {
      posts: await Post.all(),
    })
  }
}

步骤 5：查看结果 ​

在浏览器中访问 http://localhost:3333/posts 查看渲染后的页面。

你也可以直接从路由渲染模板而不使用控制器。

ts
import router from '@adonisjs/core/services/router'

/**
 * router.on().render() 简写直接渲染模板。
 * 第一个参数是模板路径。
 */
router.on('/').render('pages/home')

理解模板状态 ​

你传递给 view.render() 的数据对象称为模板状态。此对象中的所有属性在模板中作为变量可用。

除了你显式传递的数据外，AdonisJS 自动与每个模板共享某些全局变量：

  • request 对象用于访问请求数据
  • auth 对象用于检查身份认证状态
  • Edge 辅助函数如 excerpt()、truncate() 和路由辅助函数

你可以在 Edge 参考指南中查看所有可用的辅助函数和全局属性。

模板语法速览 ​

Edge 使用花括号和标签的组合为模板添加动态行为。以下是最常见语法模式的快速回顾：

输出变量：

edge
{{ post.title }}

输出未转义的 HTML：

edge
{{{ post.content }}}

条件判断：

edge
@if(user)
  <p>Welcome back, {{ user.name }}</p>
@else
  <p>Please log in</p>
@end

循环：

edge
@each(post in posts)
  <h2>{{ post.title }}</h2>
@end

求值 JavaScript 表达式：

edge
{{ post.createdAt.toFormat('dd LLL yyyy') }}
{{ posts.length > 0 ? 'Posts available' : 'No posts yet' }}

关于 Edge 模板语法的完整覆盖，包括 partials、slots 和自定义标签等高级功能，请参阅 Edge 语法参考。

使用布局和组件 ​

你在第一个示例中看到的 @layout() 组件用完整的 HTML 文档结构包裹你的页面内容。此组件存储在 resources/views/components/layout.edge，包含标准的 HTML 样板：

edge
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My App</title>
</head>
<body>
  {{{ await $slots.main() }}}
</body>
</html>

$slots.main() 方法调用渲染你在页面模板中 @layout() 开始和结束标签之间放置的任何内容。这是 Edge 的 slots 功能，允许组件接受来自其使用者的内容。

创建组件 ​

Edge 中的组件是存储在 resources/views/components 目录中的可重用模板片段。此目录中的任何模板文件都成为 Edge 标签。

例如，如果你在 resources/views/components/card.edge 创建一个文件：

edge
<div class="card">
  {{{ await $slots.main() }}}
</div>

你可以在模板中这样使用它：

edge
@card()
  <h2>Card title</h2>
  <p>Card content</p>
@end

组件可以接受 props（参数）并具有多个命名 slots 以进行更复杂的组合。关于构建和使用组件的完整指南，请参阅 Edge 组件指南。

启动套件组件 ​

超媒体启动套件包含一组无样式组件，用于构建表单和常见 UI 模式。每个组件最多渲染一个 HTML 元素，并将未知 props 作为 HTML 属性传递，允许你直接应用类和其他属性。

Layout ​

渲染带有 head 和 body 元素的 HTML 文档。

  • Props：无
  • Slots：main（默认）
edge
@layout()
  <main>Page content goes here</main>
@end

Form ​

渲染带有自动 CSRF 令牌注入的 HTML form 元素。

Prop类型描述
actionstring表单 action URL
methodstringHTTP 方法。通过方法欺骗支持 PUT、PATCH 和 DELETE
routestring从命名路由计算 action URL
routeParamsarray命名路由的参数
routeOptionsobjectURL 生成的额外选项（例如查询字符串）
edge
@form({ route: 'posts.store', method: 'POST' })
  {{-- 表单字段 --}}
@end

@form({ route: 'posts.update', method: 'PUT', routeParams: [post.id] })
  {{-- 表单字段 --}}
@end

字段组件 ​

表单字段组件协同工作，创建带有标签和验证错误显示的可访问表单输入。

field.root ​

为子字段组件建立上下文的容器。

Prop类型描述
namestring字段名称，用于错误消息查找
idstring元素 ID，用于将标签与输入关联

field.label ​

渲染与字段关联的 label 元素。

Prop类型描述
textstring标签文本（替代使用 slot）

field.error ​

显示字段的验证错误。自动按字段名称查找错误。

edge
@field.root({ name: 'email' })
  @!field.label({ text: 'Email address' })
  @!input.control({ type: 'email', autocomplete: 'email' })
  @!field.error()
@end

Input 控件 ​

渲染 input 元素。必须是 @field.root 的子元素。它将所有 props 作为 HTML 属性传递给 input 元素。

edge
@field.root({ name: 'username' })
  @!field.label({ text: 'Username' })
  @!input.control({ type: 'text', minlength: '3', maxlength: '20' })
  @!field.error()
@end

Select 控件 ​

渲染带有选项的 select 元素。必须是 @field.root 的子元素。

Prop类型描述
optionsarray包含 name 和 value 属性的对象数组
edge
@field.root({ name: 'country' })
  @!field.label({ text: 'Country' })
  @!select.control({
    options: countries.map((country) => ({
      name: country.name,
      value: country.code
    }))
  })
  @!field.error()
@end

Textarea 控件 ​

渲染 textarea 元素。必须是 @field.root 的子元素。它将所有 props 作为 HTML 属性传递给 textarea 元素。

edge
@field.root({ name: 'bio' })
  @!field.label({ text: 'Biography' })
  @!textarea.control({ rows: '4' })
  @!field.error()
@end

复选框组件 ​

复选框组件创建具有共享名称的复选框输入以用于表单提交。

checkbox.group ​

为子复选框建立共享名称的容器。

Prop类型描述
namestring组中所有复选框的共享名称

checkbox.control ​

渲染复选框输入。必须嵌套在 @checkbox.group 和 @field.root 两者中。它将所有 props 作为 HTML 属性传递。使用 value 设置复选框值。

edge
@checkbox.group({ name: 'services' })
  @field.root({ id: 'design' })
    @!checkbox.control({ value: 'design' })
    @!field.label({ text: 'Design' })
  @end

  @field.root({ id: 'development' })
    @!checkbox.control({ value: 'development' })
    @!field.label({ text: 'Development' })
  @end

  @field.root({ id: 'marketing' })
    @!checkbox.control({ value: 'marketing' })
    @!field.label({ text: 'Marketing' })
  @end
@end

单选按钮组件 ​

单选按钮组件在组内创建互斥选项。

radio.group ​

为子单选按钮建立共享名称的容器。

Prop类型描述
namestring组中所有单选按钮的共享名称

radio.control ​

渲染单选输入。必须嵌套在 @radio.group 和 @field.root 两者中。它将所有 props 作为 HTML 属性传递。使用 value 设置单选值。

edge
@radio.group({ name: 'payment_plan' })
  @field.root({ id: 'free' })
    @!radio.control({ value: 'free' })
    @!field.label({ text: 'Free' })
  @end

  @field.root({ id: 'pro' })
    @!radio.control({ value: 'pro' })
    @!field.label({ text: 'Pro $29/month' })
  @end

  @field.root({ id: 'enterprise' })
    @!radio.control({ value: 'enterprise' })
    @!field.label({ text: 'Custom pricing' })
  @end
@end

警告组件 ​

警告组件显示带有可选自动关闭行为的通知消息。

alert.root ​

为警告标题和描述建立上下文的容器。

Prop类型描述
variantstring警告变体（例如 destructive、success）
autoDismissboolean警告是否应自动关闭

alert.title ​

渲染警告标题。

Prop类型描述
textstring标题文本（替代使用 slot）

alert.description ​

渲染警告正文文本。

Prop类型描述
textstring描述文本（替代使用 slot）
edge
@alert.root({ variant: 'destructive', autoDismiss: true })
  @!alert.title({ text: 'Unauthorized' })
  @!alert.description({ text: 'You are not allowed to access this page' })
@end

Button ​

渲染 button 元素。

Prop类型描述
textstring按钮文本（替代使用 slot）
edge
@!button({ text: 'Sign up', type: 'submit' })

@button({ type: 'button', class: 'btn-secondary' })
  <span>Cancel</span>
@end

Link ​

渲染带有基于路由的 URL 生成的锚点元素。

Prop类型描述
textstring链接文本（替代使用 slot）
routestring从命名路由计算 href
routeParamsarray命名路由的参数
routeOptionsobjectURL 生成的额外选项
hrefstring直接 URL（代替 route 使用）
edge
@!link({ route: 'posts.show', routeParams: [post.id], text: 'View post' })

@link({ route: 'posts.edit', routeParams: [post.id] })
  <span>Edit</span>
  <svg>{{-- 图标 --}}</svg>
@end

Avatar ​

渲染用户头像的图片或首字母缩写。

Prop类型描述
srcstring头像图片 URL（渲染 img 元素）
initialsstring回退首字母缩写（渲染 span 元素）
edge
{{-- 使用图片 --}}
@!avatar({ src: user.avatarUrl, alt: user.name })

{{-- 使用首字母缩写 --}}
@!avatar({ initials: user.initials })

调试模板 ​

使用模板时，你可能需要检查模板中可用的数据或调试为什么某些值没有按预期显示。Edge 为此提供了 @dump 标签。

@dump 标签漂亮地打印变量的值，使检查数据结构变得容易：

edge
@dump(posts)

要查看整个模板状态（模板中所有可用的变量），使用：

edge
@dump(state)

输出出现在渲染后的 HTML 中，显示数据的结构和值。在开发期间，模板在你更改时自动重新加载，因此你会在浏览器中立即看到更新，而无需重启服务器。

配置 ​

Edge 在超媒体应用中已预配置并开箱即用。但是，如果你需要注册自定义辅助函数、标签或插件，可以通过创建预加载文件来自定义 Edge。

创建用于 Edge 配置的预加载文件：

bash
node ace make:preload view

这会创建一个预加载文件，你可以在应用启动之前自定义 Edge。在此文件中，你可以注册 Edge 全局变量、插件和自定义标签。

如果你需要自定义模板存储的目录，可以修改 adonisrc.ts 文件中的 directories 选项。有关配置选项的更多详细信息，请参阅 AdonisRC 参考指南。
