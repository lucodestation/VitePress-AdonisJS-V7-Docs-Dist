创建自定义 auth 守卫 ​

本指南涵盖在 AdonisJS 中构建自定义身份认证守卫。你将了解到：

  • 何时创建自定义守卫而不是使用内置选项
  • 如何为你的守卫设计用户提供者接口
  • 如何实现守卫契约
  • 如何生成和验证令牌
  • 如何注册和使用你的自定义守卫

概述 ​

AdonisJS 附带 session、access token 和 basic auth 守卫，涵盖大多数身份认证需求。但是，你可能需要针对特定需求的自定义守卫，如 JWT 身份认证、API 密钥或与外部身份提供者集成。

自定义守卫由两部分组成：定义如何查找用户的用户提供者接口，以及处理身份认证逻辑的守卫实现。这种分离允许同一个守卫通过替换用户提供者来与不同的数据源（Lucid 模型、Prisma、外部 API）配合使用。

本指南通过构建一个 JWT 身份认证守卫作为实际示例来讲解。这些概念适用于任何自定义身份认证机制。

TIP

这是高级内容。在构建自定义守卫之前，请验证 session 守卫、access tokens 守卫或 basic auth 守卫是否不能满足你的需求。

项目结构 ​

本指南中的所有代码都放在一个文件中，你可以稍后扩展。在 app/auth/guards/jwt.ts 创建文件：

sh
mkdir -p app/auth/guards
touch app/auth/guards/jwt.ts

定义用户提供者接口 ​

守卫不应硬编码如何从数据库获取用户。相反，它们定义一个用户提供者接口，描述身份认证所需的方法。这让开发者可以根据他们的数据层提供自己的实现。

对于 JWT 守卫，提供者需要根据用户 ID（从令牌负载中提取）查找用户。首先定义接口：

ts
import { symbols } from '@adonisjs/auth'

/**
 * 用户提供者和守卫之间的桥梁。
 * 用守卫需要的方法包装实际用户对象。
 */
export type JwtGuardUser<RealUser> = {
  getId(): string | number | BigInt
  getOriginal(): RealUser
}

/**
 * 用户提供者必须实现的接口
 * 以与 JWT 守卫配合使用。
 */
export interface JwtUserProviderContract<RealUser> {
  /**
   * 供 TypeScript 推断实际用户类型的属性。
   * 运行时未使用。
   */
  [symbols.PROVIDER_REAL_USER]: RealUser

  /**
   * 从实际用户对象创建守卫用户实例。
   */
  createUserForGuard(user: RealUser): Promise<JwtGuardUser<RealUser>>

  /**
   * 根据用户 ID 查找用户。
   */
  findById(identifier: string | number | BigInt): Promise<JwtGuardUser<RealUser> | null>
}

JwtGuardUser 类型充当实际用户对象（Lucid 模型、Prisma 对象或纯对象）和守卫之间的桥梁。守卫使用 getId() 获取令牌负载的用户标识符，使用 getOriginal() 在认证后返回用户对象。

RealUser 泛型参数允许接口与任何用户类型配合使用。基于 Lucid 的提供者将返回模型实例，而基于 Prisma 的提供者将返回 Prisma 用户对象。

实现守卫 ​

守卫必须实现来自 @adonisjs/auth 的 GuardContract 接口。此接口定义将守卫与 AdonisJS 身份认证集成的方法和属性。

从类结构和必需属性开始：

ts
import { symbols } from '@adonisjs/auth'
import type { GuardContract } from '@adonisjs/auth/types'

export class JwtGuard<UserProvider extends JwtUserProviderContract<unknown>>
  implements GuardContract<UserProvider[typeof symbols.PROVIDER_REAL_USER]>
{
  /**
   * 此守卫发出的事件。JWT 守卫不发出事件，
   * 但接口要求此属性。
   */
  declare [symbols.GUARD_KNOWN_EVENTS]: {}

  /**
   * 此守卫类型的唯一标识符。
   */
  driverName: 'jwt' = 'jwt'

  /**
   * 在此请求期间是否已尝试认证。
   */
  authenticationAttempted: boolean = false

  /**
   * 当前请求是否已认证。
   */
  isAuthenticated: boolean = false

  /**
   * 已认证用户（如果有）。
   */
  user?: UserProvider[typeof symbols.PROVIDER_REAL_USER]

接受依赖 ​

守卫需要一个用户提供者来查找用户，需要 HTTP 上下文来读取请求头。它还需要如 JWT 密钥等配置选项。将这些添加为构造函数参数：

ts
import type { HttpContext } from '@adonisjs/core/http'

export type JwtGuardOptions = {
  secret: string
}

export class JwtGuard<UserProvider extends JwtUserProviderContract<unknown>>
  implements GuardContract<UserProvider[typeof symbols.PROVIDER_REAL_USER]>

  #userProvider: UserProvider
  #options: JwtGuardOptions

  constructor(
    ctx: HttpContext,
    userProvider: UserProvider,
    options: JwtGuardOptions
  ) {
    this.#ctx = ctx
    this.#userProvider = userProvider
    this.#options = options
  }

  // ... 类的其余部分
}

生成令牌 ​

安装 jsonwebtoken 包来处理 JWT 创建和验证：

sh
npm i jsonwebtoken @types/jsonwebtoken

实现 generate 方法以创建包含用户 ID 的签名 JWT：

ts
import jwt from 'jsonwebtoken'

export class JwtGuard<UserProvider extends JwtUserProviderContract<unknown>>
  implements GuardContract<UserProvider[typeof symbols.PROVIDER_REAL_USER]>
{
  // ... 构造函数和属性

  async generate(user: UserProvider[typeof symbols.PROVIDER_REAL_USER]) {
    const providerUser = await this.#userProvider.createUserForGuard(user)
    const token = jwt.sign({ userId: providerUser.getId() }, this.#options.secret)

    return {
      type: 'bearer',
      token: token,
    }
  }
}

该方法使用用户提供者获取用户 ID，然后使用该 ID 在负载中签名 JWT。

认证请求 ​

authenticate 方法从请求读取 JWT，验证它，并获取相应的用户：

ts
import { errors, symbols } from '@adonisjs/auth'

export class JwtGuard<UserProvider extends JwtUserProviderContract<unknown>>
  implements GuardContract<UserProvider[typeof symbols.PROVIDER_REAL_USER]>
{
  // ... 构造函数和属性

  async authenticate(): Promise<UserProvider[typeof symbols.PROVIDER_REAL_USER]> {
    /**
     * 如果在此请求期间已经认证则跳过
     */
    if (this.authenticationAttempted) {
      return this.getUserOrFail()
    }
    this.authenticationAttempted = true

    /**
     * 读取 authorization 头
     */
    const authHeader = this.#ctx.request.header('authorization')
    if (!authHeader) {
      throw new errors.E_UNAUTHORIZED_ACCESS('Unauthorized access', {
        guardDriverName: this.driverName,
      })
    }

    /**
     * 从 "Bearer <token>" 中提取令牌
     */
    const [, token] = authHeader.split('Bearer ')
    if (!token) {
      throw new errors.E_UNAUTHORIZED_ACCESS('Unauthorized access', {
        guardDriverName: this.driverName,
      })
    }

    /**
     * 验证令牌并提取负载
     */
    const payload = jwt.verify(token, this.#options.secret)
    if (typeof payload !== 'object' || !('userId' in payload)) {
      throw new errors.E_UNAUTHORIZED_ACCESS('Unauthorized access', {
        guardDriverName: this.driverName,
      })
    }

    /**
     * 从令牌负载中的 ID 查找用户
     */
    const providerUser = await this.#userProvider.findById(payload.userId)
    if (!providerUser) {
      throw new errors.E_UNAUTHORIZED_ACCESS('Unauthorized access', {
        guardDriverName: this.driverName,
      })
    }

    /**
     * 存储已认证用户并返回
     */
    this.user = providerUser.getOriginal()
    this.isAuthenticated = true
    return this.user
  }
}

实现辅助方法 ​

check 方法是不抛出的 authenticate 版本：

ts
async check(): Promise<boolean> {
  try {
    await this.authenticate()
    return true
  } catch {
    return false
  }
}

getUserOrFail 方法返回已认证用户或抛出异常：

ts
getUserOrFail(): UserProvider[typeof symbols.PROVIDER_REAL_USER] {
  if (!this.user) {
    throw new errors.E_UNAUTHORIZED_ACCESS('Unauthorized access', {
      guardDriverName: this.driverName,
    })
  }

  return this.user
}

支持测试认证 ​

authenticateAsClient 方法由 Japa 的 loginAs 辅助函数在测试期间使用。它返回测试客户端应包含的头：

ts
import type { AuthClientResponse } from '@adonisjs/auth/types'

async authenticateAsClient(
  user: UserProvider[typeof symbols.PROVIDER_REAL_USER]
): Promise<AuthClientResponse> {
  const token = await this.generate(user)

  return {
    headers: {
      authorization: `Bearer ${token.token}`,
    },
  }
}

完整实现 ​

以下是完整的守卫实现：

ts
import jwt from 'jsonwebtoken'
import { symbols, errors } from '@adonisjs/auth'
import type { HttpContext } from '@adonisjs/core/http'
import type { AuthClientResponse, GuardContract } from '@adonisjs/auth/types'

/**
 * 用户提供者和守卫之间的桥梁。
 */
export type JwtGuardUser<RealUser> = {
  getId(): string | number | BigInt
  getOriginal(): RealUser
}

/**
 * 与 JWT 守卫兼容的用户提供者接口。
 */
export interface JwtUserProviderContract<RealUser> {
  [symbols.PROVIDER_REAL_USER]: RealUser
  createUserForGuard(user: RealUser): Promise<JwtGuardUser<RealUser>>
  findById(identifier: string | number | BigInt): Promise<JwtGuardUser<RealUser> | null>
}

/**
 * JWT 守卫的配置选项。
 */
export type JwtGuardOptions = {
  secret: string
}

/**
 * JWT 身份认证守卫实现。
 */
export class JwtGuard<UserProvider extends JwtUserProviderContract<unknown>>
  implements GuardContract<UserProvider[typeof symbols.PROVIDER_REAL_USER]>
{
  declare [symbols.GUARD_KNOWN_EVENTS]: {}

  driverName: 'jwt' = 'jwt'
  authenticationAttempted: boolean = false
  isAuthenticated: boolean = false
  user?: UserProvider[typeof symbols.PROVIDER_REAL_USER]

  #ctx: HttpContext
  #userProvider: UserProvider
  #options: JwtGuardOptions

  constructor(
    ctx: HttpContext,
    userProvider: UserProvider,
    options: JwtGuardOptions
  ) {
    this.#ctx = ctx
    this.#userProvider = userProvider
    this.#options = options
  }

  async generate(user: UserProvider[typeof symbols.PROVIDER_REAL_USER]) {
    const providerUser = await this.#userProvider.createUserForGuard(user)
    const token = jwt.sign({ userId: providerUser.getId() }, this.#options.secret)

    return {
      type: 'bearer',
      token: token,
    }
  }

  async authenticate(): Promise<UserProvider[typeof symbols.PROVIDER_REAL_USER]> {
    if (this.authenticationAttempted) {
      return this.getUserOrFail()
    }
    this.authenticationAttempted = true

    const authHeader = this.#ctx.request.header('authorization')
    if (!authHeader) {
      throw new errors.E_UNAUTHORIZED_ACCESS('Unauthorized access', {
        guardDriverName: this.driverName,
      })
    }

    const [, token] = authHeader.split('Bearer ')
    if (!token) {
      throw new errors.E_UNAUTHORIZED_ACCESS('Unauthorized access', {
        guardDriverName: this.driverName,
      })
    }

    const payload = jwt.verify(token, this.#options.secret)
    if (typeof payload !== 'object' || !('userId' in payload)) {
      throw new errors.E_UNAUTHORIZED_ACCESS('Unauthorized access', {
        guardDriverName: this.driverName,
      })
    }

    const providerUser = await this.#userProvider.findById(payload.userId)
    if (!providerUser) {
      throw new errors.E_UNAUTHORIZED_ACCESS('Unauthorized access', {
        guardDriverName: this.driverName,
      })
    }

    this.user = providerUser.getOriginal()
    this.isAuthenticated = true
    return this.user
  }

  async check(): Promise<boolean> {
    try {
      await this.authenticate()
      return true
    } catch {
      return false
    }
  }

  getUserOrFail(): UserProvider[typeof symbols.PROVIDER_REAL_USER] {
    if (!this.user) {
      throw new errors.E_UNAUTHORIZED_ACCESS('Unauthorized access', {
        guardDriverName: this.driverName,
      })
    }

    return this.user
  }

  async authenticateAsClient(
    user: UserProvider[typeof symbols.PROVIDER_REAL_USER]
  ): Promise<AuthClientResponse> {
    const token = await this.generate(user)

    return {
      headers: {
        authorization: `Bearer ${token.token}`,
      },
    }
  }
}

注册守卫 ​

在 config/auth.ts 中注册你的自定义守卫。JwtUserProviderContract 接口与 session 守卫的用户提供者兼容，因此你可以重用它：

ts
import { defineConfig } from '@adonisjs/auth'
import { sessionUserProvider } from '@adonisjs/auth/session'
import env from '#start/env'
import { JwtGuard } from '#auth/guards/jwt'

const jwtConfig = {
  secret: env.get('APP_KEY'),
}

const userProvider = sessionUserProvider({
  model: () => import('#models/user'),
})

const authConfig = defineConfig({
  default: 'jwt',
  guards: {
    jwt: (ctx) => {
      return new JwtGuard(ctx, userProvider, jwtConfig)
    },
  },
})

export default authConfig

守卫工厂接收 HTTP 上下文并为每个请求返回新的守卫实例。

使用守卫 ​

注册守卫后，像任何内置守卫一样使用它：

ts
import User from '#models/user'
import router from '@adonisjs/core/services/router'
import { middleware } from '#start/kernel'

router.post('/login', async ({ request, auth }) => {
  const { email, password } = request.all()
  const user = await User.verifyCredentials(email, password)

  return await auth.use('jwt').generate(user)
})

router
  .get('/profile', async ({ auth }) => {
    return auth.getUserOrFail()
  })
  .use(middleware.auth({ guards: ['jwt'] }))

下一步 ​

此实现为 JWT 身份认证提供了基础。考虑扩展它：

  • 令牌过期（JWT 负载中的 exp 声明）
  • 用于获取新访问令牌的刷新令牌
  • 使用黑名单的令牌撤销
  • 角色或权限等额外声明
  • 针对不同失败场景的自定义错误消息
