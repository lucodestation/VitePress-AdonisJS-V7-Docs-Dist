构建 DevShow - 一个社区展示网站 ​

在本教程中，你将构建 DevShow。DevShow 是一个小型的社区展示网站，用户可以在其中分享他们构建的东西。 每个用户都可以创建账户、发布“展示条目”（一个项目、工具、实验或任何他们引以为豪的东西），并浏览其他人创建的条目。

概述 ​

我们在本教程中采用动手实践的方式，从头到尾构建一个真实的应用。你不是孤立地学习各项功能，而是会看到 AdonisJS 中的所有部分如何协同工作：路由、控制器、模型、验证、身份认证和模板共同协作，创建一个可运行的 Web 应用。

完成本教程后，你将构建出：

  • 帖子列表和详情页 - 显示所有帖子和单个帖子详情及评论
  • 帖子创建和编辑 - 带有验证的创建和更新帖子的表单
  • 评论系统 - 允许用户对帖子发表评论
  • 授权 - 确保用户只能编辑/删除自己的帖子和评论
  • 导航和样式 - 在页面之间具有适当导航的精美 UI

身份认证系统（注册、登录、登出）已包含在你的启动套件中，并且功能完整。

了解启动套件 ​

我们从 AdonisJS 超媒体启动套件开始，它已经内置了身份认证。让我们打开路由文件，看看有什么可用。

ts
import { middleware } from '#start/kernel'
import { controllers } from '#generated/controllers'
import router from '@adonisjs/core/services/router'

router.on('/').render('pages/home').as('home')

/**
 * 注册和登录路由 - 仅对访客可访问
 */
router
  .group(() => {
    router.get('signup', [controllers.NewAccount, 'create'])
    router.post('signup', [controllers.NewAccount, 'store'])

    router.get('login', [controllers.Session, 'create'])
    router.post('login', [controllers.Session, 'store'])
  })
  .use(middleware.guest())

/**
 * 登出路由 - 仅对已认证用户可访问
 */
router
  .group(() => {
    router.post('logout', [controllers.Session, 'destroy'])
  })
  .use(middleware.auth())

启动套件为我们提供了用户注册、登录和登出路由。注意 middleware.guest() 如何确保只有已登出的用户才能访问注册/登录，而 middleware.auth() 保护登出路由。

TIP

我们将在整个教程中使用 auth 中间件来保护需要身份认证的路由。

控制器如何工作 ​

让我们看看注册控制器，了解请求如何在应用中流转。

ts
import User from '#models/user'
import { signupValidator } from '#validators/user'
import type { HttpContext } from '@adonisjs/core/http'

export default class NewAccountController {
  async create({ view }: HttpContext) {
    return view.render('pages/auth/signup')
  }

  async store({ request, response, auth }: HttpContext) {
    /**
     * 验证提交的数据
     */
    const payload = await request.validateUsing(signupValidator)

    /**
     * 在数据库中创建新用户
     */
    const user = await User.create(payload)

    /**
     * 自动登录
     */
    await auth.use('web').login(user)

    /**
     * 重定向到首页
     */
    response.redirect().toRoute('home')
  }
}

每个控制器方法接收一个 HTTP 上下文对象作为第一个参数。上下文包含当前请求的所有信息：请求数据、响应对象、认证状态、视图渲染器等。我们只解构需要的属性（view 用于渲染模板，request 用于表单数据，response 用于重定向，auth 用于身份认证）。

create 方法只是显示注册表单。store 方法做繁重的工作。它验证数据、创建用户、登录并重定向到首页。这种将验证器、模型和认证结合在一起的方式，你将在整个教程中看到。

你可能注意到控制器引用了 User 模型和 signupValidator。启动套件已经包含了这些。我们将在数据库与模型章节探讨模型如何工作，在表单与验证章节探讨验证器。

视图如何工作 ​

当控制器调用 view.render('pages/auth/signup') 时，AdonisJS 会查找模板文件并将其渲染为 HTML。让我们看看注册视图的样子。

edge
@layout()
  <div class="form-container">
    <div>
      <h1> Signup </h1>
      <p>
        Enter your details below to create your account
      </p>
    </div>

    <div>
      @form({ route: 'new_account.store', method: 'POST' })
        <div>
          @field.root({ name: 'fullName' })
            @!field.label({ text: 'Full name' })
            @!input.control()
            @!field.error()
          @end
        </div>

        <div>
          @field.root({ name: 'email' })
            @!field.label({ text: 'Email' })
            @!input.control({ type: 'email', autocomplete: 'email' })
            @!field.error()
          @end
        </div>

        <div>
          @field.root({ name: 'password' })
            @!field.label({ text: 'Password' })
            @!input.control({ type: 'password', autocomplete: 'new-password' })
            @!field.error()
          @end
        </div>

        <div>
          @field.root({ name: 'passwordConfirmation' })
            @!field.label({ text: 'Confirm password' })
            @!input.control({ type: 'password', autocomplete: 'new-password' })
            @!field.error()
          @end
        </div>

        <div>
          @!button({ text: 'Sign up', type: 'submit' })
        </div>
      @end
    </div>
  </div>
@end

视图位于 resources/views 目录中。AdonisJS 使用 Edge 作为其模板引擎。Edge 模板看起来与 HTML 相似，但带有以 @ 开头的特殊标签。

@layout() 标签用通用布局（页头、页脚、CSS）包裹页面内容。@form() 和 @field.root() 标签是启动套件自带的组件。它们渲染标准的 HTML 表单元素，并内置了 CSRF 保护和验证错误显示等功能。

当你访问 /signup 时，路由调用控制器的 create 方法，该方法渲染此视图，Edge 将其转换为浏览器显示的 HTML。
