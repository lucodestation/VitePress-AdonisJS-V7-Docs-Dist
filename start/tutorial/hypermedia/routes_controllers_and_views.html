路由、控制器与视图 ​

在上一章中，我们创建了 Post 和 Comment 模型及其数据库表和关系。现在我们将通过构建用户实际可以看到帖子的页面，让这些模型活起来。

TIP

本教程涵盖基本的路由、控制器和视图。关于路由组、中间件、命名路由、路由参数验证和 Edge 模板组件等高级主题，请参阅路由指南、控制器指南和 Edge 文档。

概述 ​

目前，你的帖子和评论只存在于数据库中。让我们构建两个页面：一个列出所有帖子，另一个显示单个帖子及其评论。

在这里，你将看到完整的 MVC（模型-视图-控制器）模式的实际运作——模型处理数据，控制器协调逻辑，视图向用户展示一切。

在开始之前，请确保你的开发服务器正在运行。

bash
node ace serve --hmr

显示帖子列表 ​

让我们构建显示帖子列表的完整功能。我们将创建一个控制器、添加一个获取帖子的方法、注册一个路由，并创建视图模板。

步骤 1：创建控制器 ​

首先创建一个控制器来处理与帖子相关的请求。运行此命令。

bash
node ace make:controller posts

这会在 app/controllers/posts_controller.ts 创建一个新文件。打开它，你会看到一个基本的控制器类。让我们添加一个列出所有帖子的方法。

ts
import Post from '#models/post'
import { type HttpContext } from '@adonisjs/core/http'

export default class PostsController {
  async index({ view }: HttpContext) {
    const posts = await Post
      .query()
      .preload('user')
      .orderBy('createdAt', 'desc')

    return view.render('posts/index', { posts })
  }
}

这里需要注意几点：

  • 我们预加载了 user 关系，这样我们就能显示作者的名字而无需额外查询
  • 我们按创建日期排序帖子，最新的在前
  • 并将帖子传递给名为 posts/index 的视图模板。

步骤 2：定义路由 ​

打开你的路由文件并注册一个路由。

ts
import router from '@adonisjs/core/services/router'
import { controllers } from '#generated/controllers'

router.on('/').render('pages/home').as('home')
router.get('/posts', [controllers.Posts, 'index'])

路由定义将 /posts URL 连接到控制器的 index 方法。当有人访问 /posts 时，AdonisJS 会调用 PostsController.index() 并返回该方法返回的任何内容。

TIP

#generated/controllers 导入由 AdonisJS 自动生成，提供对控制器的类型安全引用。开发服务器会监视新的控制器并自动重新生成此文件——这就是为什么在创建新控制器时开发服务器必须正在运行。关于其工作原理的更多细节，请参阅控制器指南。

步骤 3：创建视图模板 ​

是时候创建视图模板了。

bash
node ace make:view posts/index

这会在 resources/views/posts/index.edge 创建一个新文件。打开它并添加以下代码。

edge
@layout()
  <div class="container">
    <div class="posts-list-title">
      <h1> Posts </h1>
    </div>

    @each(post in posts)
      <div class="post-item">
        <h2> {{ post.title }} </h2>

        <div class="post-meta">
          <div>By {{ post.user.fullName }}</div>

          <span>.</span>
          <div><a href="{{ post.url }}" target="_blank">{{post.url}}</a></div>

          <span>.</span>
          <div><a href="/posts/{{ post.id }}"> View comments </a></div>
        </div>
      </div>
    @end
  </div>
@end

此模板使用启动套件自带的现有 layout 组件。布局处理基本的 HTML 结构，你通过将其包裹在 @layout 标签中提供主要内容。

在里面，我们用 @each 循环遍历每个帖子，并显示其标题、作者姓名和查看帖子评论的链接。

访问 /posts，你应该会看到所有帖子的列表！

显示单个帖子 ​

现在让我们添加查看单个帖子及其详细信息的能力。我们将实现控制器方法、注册带动态参数的路由，并创建视图模板。

步骤 1：实现控制器方法 ​

将 show 方法添加到你的控制器。

ts
import Post from '#models/post'
import type { HttpContext } from '@adonisjs/core/http'

export default class PostsController {
  async index({ view }: HttpContext) {
    const posts = await Post
      .query()
      .preload('user')
      .orderBy('createdAt', 'desc')

    return view.render('posts/index', { posts })
  }

  async show({ params, view }: HttpContext) {
    const post = await Post
      .query()
      .where('id', params.id)
      .preload('user')
      .firstOrFail()

    return view.render('posts/show', { post })
  }
}

我们在这里使用 firstOrFail()，如果不存在具有该 ID 的帖子，它会自动抛出 404 错误。无需手动检查帖子是否存在——AdonisJS 会为你处理。

步骤 2：注册路由 ​

现在让我们为此控制器方法注册路由。

ts
import router from '@adonisjs/core/services/router'
import { controllers } from '#generated/controllers'

router.get('/posts', [controllers.Posts, 'index'])
router.get('/posts/:id', [controllers.Posts, 'show'])
  • :id 部分是路由参数。
  • 当有人访问 /posts/5 时，AdonisJS 会捕获那个 5 并使其在控制器中作为 params.id 可用。
  • 你可以随意命名参数，:id、:postId、:slug——只需在访问时保持一致。

步骤 3：创建视图模板 ​

创建用于显示单个帖子的视图模板。

bash
node ace make:view posts/show

这会创建 resources/views/posts/show.edge。打开它并添加以下代码。

edge
@layout()
  <div class="container">
    <div>
      <h1>
        {{ post.title }}
      </h1>
    </div>

    <div class="post">
      <div class="post-meta">
        <div>By {{ post.user.fullName }}</div>

        <span>.</span>
        <div><a href="{{ post.url }}" target="_blank">{{post.url}}</a></div>
      </div>

      <div class="post-summary">
        {{ post.summary }}
      </div>
    </div>
  </div>
@end

尝试从你的列表页面点击一个帖子。你现在应该能看到完整的帖子及其标题、作者和内容。

使用命名路由 ​

目前，我们在模板中硬编码了像 /posts/{{ post.id }} 这样的 URL。这可以工作，但如果我们决定将 URL 模式从 /posts/:id 改为 /showcase/:id，会发生什么？我们将不得不查找并替换应用中的所有硬编码 URL。

这就是命名路由的用武之地。命名路由让你为每个路由分配一个唯一名称，然后在构建 URL 时引用该名称。如果 URL 模式发生变化，你只需在一个地方（路由定义）更新它，所有链接都会自动使用新模式。

当你在路由定义中使用控制器时，AdonisJS 会根据控制器和方法名称自动生成路由名称。例如：

  • [controllers.Posts, 'index'] 获得名称 posts.index。
  • [controllers.Posts, 'show'] 获得名称 posts.show。

你也可以使用 .as() 方法手动命名路由，这对于不使用控制器的路由或当你想要自定义名称时很有用。

命名路由可以在整个应用中引用：

  • 在模板中使用 urlFor() 辅助函数
  • 在 @form 组件的 route 参数中
  • 在 @link 组件的 route 参数中
  • 在控制器中使用 response.redirect().toRoute()
  • 以及更多

关于 URL 构建和命名路由的完整指南，请参阅 URL 构建器文档。

让我们更新帖子列表页面以使用命名路由。

edge
@layout()
  <div class="container">
    <div class="posts-list-title">
      <h1> Posts </h1>
    </div>

    @each(post in posts)
      <div class="post-item">
        <h2> {{ post.title }} </h2>

        <div class="post-meta">
          <div>By {{ post.user.fullName }}</div>

          <span>.</span>
          <div><a href="{{ post.url }}" target="_blank">{{post.url}}</a></div>

          <span>.</span>
          <div><a href="/posts/{{ post.id }}"> View comments </a></div>
          <div><a href="{{ urlFor('posts.show', [post.id]) }}"> View comments </a></div>
        </div>
      </div>
    @end
  </div>
@end

向帖子视图添加评论 ​

最后，让我们显示每个帖子的评论。首先，我们需要在控制器中预加载评论及其作者。

ts
import Post from '#models/post'
import { HttpContext } from '@adonisjs/core/http'

export default class PostsController {
  async index({ view }: HttpContext) {
    const posts = await Post.query().preload('user').orderBy('createdAt', 'desc')

    return view.render('posts/index', { posts })
  }

  async show({ params, view }: HttpContext) {
    const post = await Post.query()
      .where('id', params.id)
      .preload('user')
      .preload('comments', (query) => {
        query.preload('user').orderBy('createdAt', 'asc')
      })
      .firstOrFail()

    return view.render('posts/show', { post })
  }
}

我们预加载评论以及每条评论的用户（作者），并按创建日期排序，最早的在前。现在更新视图以显示它们。

edge
@layout()
  <div class="container">
    <div>
      <h1>
        {{ post.title }}
      </h1>
    </div>

    <div class="post">
      <div class="post-meta">
        <div>By {{ post.user.fullName }}</div>

        <span>.</span>
        <div><a href="{{ post.url }}" target="_blank">{{post.url}}</a></div>
      </div>

      <div class="post-summary">
        {{ post.summary }}
      </div>

      <div class="post-comments">
        <h2>
          Comments
        </h2>

        @each(comment in post.comments)
          <div class="comment-item">
            <p> {{ comment.content }} </p>
            <div class="comment-meta">
              By {{ comment.user.fullName }} on {{ comment.createdAt.toFormat('MMM dd, yyyy') }}
            </div>
          </div>
        @else
          <p> No comments yet. </p>
        @end
      </div>
    </div>
  </div>
@end

刷新你的帖子详情页面，你现在会看到帖子内容下方列出的所有评论！

你构建了什么 ​

你刚刚完成了 AdonisJS 中完整的 MVC 流程：

  • 路由将 URL 映射到控制器操作
  • 控制器从模型获取数据并将其传递给视图
  • 视图使用 Edge 模板显示数据
  • 关系让你高效地预加载相关数据
  • 命名路由使你的模板易于维护
