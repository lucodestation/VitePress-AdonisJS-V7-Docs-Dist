命令行与 REPL ​

你可能想知道为什么我们要介绍 CLI 和 REPL，而不是直接进入功能构建。原因如下：在整个教程中，你会不断使用 Ace 命令来生成控制器、模型和其他文件。现在熟悉 CLI 可以避免以后打断我们的流程。

更重要的是，REPL 将成为我们实验模型和数据库的游乐场。当我们在后续章节探索数据库查询、过滤器和关系时，我们会使用 REPL 来尝试各种操作。它是一个一次性的环境，让我们可以专注于学习概念，而无需构建完整功能的繁琐过程。

探索可用命令 ​

让我们先看看 AdonisJS 提供了哪些命令。在终端中运行以下命令。

bash
node ace list

你应该会看到类似这样的内容：

注意命令是如何分组的？

  • make:* 命令帮助你生成文件。
  • migration:* 命令帮助你运行和回滚数据库迁移。
  • db:* 命令处理数据库填充，等等。

想了解某个特定命令的更多信息？只需在末尾加上 --help。这会显示该命令能做的所有事情，包括你可以传递给它的任何选项。

bash
node ace make:controller --help

使用 REPL ​

REPL 将在整个教程中作为我们的实验游乐场。让我们通过为 DevShow Web 应用创建和查询用户来探索如何使用它。

启动 REPL 并加载模型 ​

首先，启动 REPL：

bash
node ace repl

REPL 启动后，使用 loadModels() 辅助函数加载所有模型。REPL 提供了多个像这样的内置辅助函数，让实验更容易。这个辅助函数会让你的所有模型在 models 命名空间下可用。

ts
await loadModels()

// 访问 user 模型
models.user

创建用户 ​

让我们使用 User 模型（存储在 app/models/user.ts 文件中）创建几个用户，以便稍后登录我们的应用。create 方法接受模型属性作为对象，将它们持久化到数据库并返回一个模型实例。

ts
await models.user.create({ fullName: 'Harminder Virk', email: 'virk@adonisjs.com', password: 'secret' })

让我们再创建一个用户。

typescript
await models.user.create({ fullName: 'Jane Doe', email: 'jane@example.com', password: 'secret' })

获取所有用户 ​

现在你已经创建了几个用户，让我们使用 all 方法获取它们。该方法会执行 SELECT * 查询，并返回一个包含两个用户的数组。每个用户都是 User 模型实例，而不是普通的 JavaScript 对象。

typescript
await models.user.all()

查找并删除用户 ​

你可以使用 find 方法通过给定的 ID 查找用户。返回值是 User 模型的实例，或者 null（如果未找到用户）。

typescript
const user = await models.user.find(1)

user.id
// 1

user.email
// 'virk@adonisjs.com'

你可以通过在 User 实例上调用 delete 方法来删除此用户。

ts
await user.delete()

user.$isDeleted // true

如果你再次列出所有用户，应该只会看到 Jane 还在：

ts
await models.user.all()

退出 REPL ​

探索完成后，输入 .exit 或按 Ctrl+D 离开 REPL 并返回终端。
