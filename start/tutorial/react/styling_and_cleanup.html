样式与清理 ​

在上一章中，我们添加了用于创建帖子和评论的表单。我们还没有完成 DevShow 的构建——还有更多功能要添加——但我们已经构建了足够多的内容，值得暂停下来改进设计和用户体验。

目前，用户无法轻松地在页面之间导航，设计看起来也很简陋。让我们通过添加适当的导航链接和用 CSS 美化一切来解决这两个问题。

为应用添加样式 ​

让我们从添加 CSS 开始，让 DevShow 看起来更精致。Inertia 启动套件已经包含了一个带有一些基础样式的 CSS 文件。我们将添加 DevShow 特定的样式来增强帖子、评论和整体布局。

打开你的 CSS 文件，在末尾添加以下样式。

css

}

刷新浏览器并访问 /posts。你应该会立即看到改进后的样式，包括更好的间距、更清晰的边框和更易读的排版。

更新首页 ​

目前，首页没有告诉用户 DevShow 是什么或如何开始。让我们将其替换为一个正式的落地页，解释网站内容并链接到帖子列表。

打开首页组件并替换其内容：

tsx
import { Link } from '@adonisjs/inertia/react'

export default function Home() {
  return (
    <div className="hero">
      <h1>DevShow - Share what you have built</h1>
      <p>
        A small community showcase website to share your creations. Be it a project, tool,
        experiment, or anything they're proud of.
      </p>
      <div>
        <Link route="posts.index" className="button">
          Browse posts created by others
        </Link>
      </div>
    </div>
  )
}

我们使用来自 @adonisjs/inertia/react 的 Link 组件，并通过 route prop 引用命名路由。className="button" 应用了启动套件 CSS 中的样式。

访问首页 /，你会看到新的落地页，带有清晰的行动号召按钮，将用户引导到帖子列表。

添加帖子创建链接 ​

想要分享项目的用户需要一种简单的方式来访问创建表单。让我们在帖子列表顶部添加一个醒目的按钮。

更新你的帖子索引组件，在页头添加按钮。

tsx
import { InertiaProps } from '~/types'
import { Data } from '@generated/data'
import { Link } from '@adonisjs/inertia/react'

type PageProps = InertiaProps<{
  posts: Data.Post[]
}>

export default function PostsIndex(props: PageProps) {
  const { posts } = props

  return (
    <div className="container">
      <div className="posts-list-title">
        <h1>Posts</h1>
        <Link route="posts.create" className="button">Create new post</Link>
      </div>

      {posts.map((post) => (
        <div key={post.id} className="post-item">
          <h2>{post.title}</h2>

          <div className="post-meta">
            <div>By {post.author.fullName}</div>

            <span>.</span>
            <div>
              <a href={post.url} target="_blank" rel="noreferrer">
                {post.url}
              </a>
            </div>

            <span>.</span>
            <div>
              <Link route="posts.show" routeParams={{ id: post.id }}>
                View comments
              </Link>
            </div>
          </div>
        </div>
      ))}
    </div>
  )
}

posts-list-title 类使用 flexbox（来自我们之前添加的 CSS）将标题和按钮定位在页头的两侧。

访问 /posts，你会看到新的“Create new post”按钮位于右上角，让用户可以轻松分享他们的项目。

为帖子创建页面添加导航 ​

当用户在帖子创建表单上时，他们可能想返回浏览帖子。让我们在页面顶部添加一个返回链接。

更新你的帖子创建组件：

tsx
import { Form } from '@adonisjs/inertia/react'
import { Link } from '@adonisjs/inertia/react'

export default function PostsCreate() {
  return (
    <div className="form-container">
      <div>
        <Link route="posts.index">
          &lsaquo; Go back to posts listing
        </Link>
        <h1>Share your creation</h1>
        <p>Share the URL and a short summary of your creation</p>
      </div>

      <div>
        <Form route="posts.store">
          {({ errors }) => (
            <>
              {/* ... 表单的其余部分 ... */}
            </>
          )}
        </Form>
      </div>
    </div>
  )
}

访问 /posts/create，你会看到标题上方的返回链接，使导航更加直观。

为帖子详情页添加导航 ​

最后，让我们在单个帖子页面上添加返回链接，以便用户可以轻松返回完整列表。

更新你的帖子详情组件：

tsx
import { InertiaProps } from '~/types'
import { Data } from '@generated/data'
import { Form } from '@adonisjs/inertia/react'
import { Link } from '@adonisjs/inertia/react'

type PageProps = InertiaProps<{
  post: Data.Post
}>

export default function PostsShow(props: PageProps) {
  const { post } = props

  return (
    <div className="container">
      <Link route="posts.index">
        &lsaquo; Go back to posts listing
      </Link>
      <div>
        <h1>{post.title}</h1>
      </div>

      <div className="post">
        {/* ... 帖子详情 ... */}
      </div>
    </div>
  )
}

现在访问任意帖子详情页（从 /posts 点击一个帖子），你会看到返回链接，完成了 DevShow 中的整个导航流程。

你构建了什么 ​

你通过样式和导航改变了 DevShow 的用户体验。以下是你完成的内容：

  • 添加 CSS 来美化帖子、评论和整体布局，具有一致的间距和排版
  • 更新首页，添加了解释 DevShow 并链接到帖子的首屏区域
  • 在帖子列表上添加了“Create new post”按钮以便于访问
  • 在帖子创建和详情页面上添加了返回导航链接
  • 改善了整体导航流程，让用户可以轻松地在应用中移动
