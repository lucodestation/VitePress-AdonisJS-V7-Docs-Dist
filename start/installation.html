安装 ​

本指南介绍如何从零开始搭建一个新的 AdonisJS 应用。内容涵盖前置条件、项目创建和启动开发服务器。你不需要事先了解 AdonisJS，但具备基本的 Node.js 知识会很有帮助。

前置条件 ​

在开始之前，请确保已安装以下工具。

  • Node.js ≥ 24.x
  • npm ≥ 11.x

你可以使用以下命令验证已安装的版本。

sh
node -v
npm -v

在继续之前，请确认你的 Node.js 和 npm 版本满足这些要求。你可以从 Node.js 官网下载最新版本，或使用 Volta/nvm 等版本管理器。

创建新应用 ​

AdonisJS 提供了 create-adonisjs 初始化器包来搭建新应用的脚手架。该包会根据你在设置过程中的选择，创建一个包含所有必要文件、依赖和配置的新项目目录。

将 [project-name] 替换为你想要的项目名称。初始化器会创建一个以该名称命名的新目录，并在其中设置好你的 AdonisJS 应用。

sh
npm create adonisjs@latest [project-name]

该命令会启动交互式设置并询问你选择启动套件，你也可以通过 --kit CLI 选项预先指定启动套件。

sh
npm create adonisjs@latest [project-name] -- --kit=hypermedia
sh
npm create adonisjs@latest [project-name] -- --kit=react
sh
npm create adonisjs@latest [project-name] -- --kit=vue
sh
npm create adonisjs@latest [project-name] -- --kit=api

官方启动套件 ​

AdonisJS 提供四个官方启动套件。每个套件根据你希望如何构建用户界面和管理交互性，设置不同类型的应用。

  • 超媒体启动套件。使用 Edge 作为服务端模板引擎，并集成 Alpine.js 为前端添加轻量级的响应式行为。适合主要在服务器上渲染 HTML、只需要极少前端逻辑的应用。

  • React 启动套件。使用 Inertia.js 搭配 React 构建由 AdonisJS 后端驱动的全栈 React 应用。根据你的配置，它既可以作为服务端渲染应用运行，也可以作为单页应用（SPA）运行。

  • Vue 启动套件。与 React 设置类似，但以 Vue 作为前端框架。它利用 Inertia.js 并提供相同的全栈能力，包括后端驱动的路由、共享状态和 SPA 支持。

  • API 启动套件。一个包含两个应用的单体仓库设置：一个 AdonisJS 后端和一个空白前端项目，你可以在其中配置任何前端框架（TanStack Start、Nuxt、Next.js 或其他）。后端和前端之间已经配置好了端到端类型安全和共享的转换器类型。

所有启动套件都预先配置了合理的默认值、精简的开发工作流和开箱即用的身份认证功能。详细的对比和使用指南，请参阅选择你的路径指南。

社区启动套件 ​

除了官方套件外，AdonisJS 社区也维护针对特定用例的启动套件。

  • Slim 启动套件。一个极简的 AdonisJS v7 设置，包含框架核心和 Japa 测试运行器，专为希望从轻量级基础开始的团队设计。

  • MCP 启动套件。一个极简的 AdonisJS v7 设置，内置 MCP 支持，适用于你想在应用中暴露 MCP 工具、资源和提示的场景。

项目默认配置 ​

每个新建的 AdonisJS 应用都包含：

  • 预设的目录结构。
  • 配置了 SQLite 作为默认数据库的 Lucid ORM。
  • 用于登录和注册的内置身份认证流程。
  • 预定义配置的 ESLint 和 Prettier 设置。

这些功能帮助你快速上手。你可以随着项目发展自定义、扩展或移除它们。

启动开发服务器 ​

创建应用后，进入项目目录并启动开发服务器。

sh
node ace serve --hmr
sh
npm run dev

对于 Hypermedia / Inertia 套件：服务器运行后，打开浏览器访问 http://localhost:3333。你应该会看到 AdonisJS 欢迎页面，确认安装成功。

对于 API 套件：API 启动套件是由 Turborepo 管理的单体仓库。从项目根目录启动所有应用：

bash
npm run dev

这会同时启动后端（AdonisJS）和前端的开发服务器。后端运行在 http://localhost:3333，并返回一个 JSON 响应：

json
{ "hello": "world" }

你刚刚安装了什么 ​

你的启动套件包含：

  • 预配置的开发环境。TypeScript、ESLint、Prettier 和 Vite 都已用合理的默认值设置好。

  • 数据库设置。Lucid ORM 已配置 SQLite，随时可以开始构建模型和运行迁移。

  • 有条理的项目结构。路由定义在 start/routes.ts，模型位于 app/models/，控制器位于 app/controllers/，中间件位于 app/middleware/。这种约定让代码库在增长时保持条理。

  • 可用的身份认证。所有启动套件都包含功能完整的身份认证系统，带有注册和登录流程。

对于 Hypermedia / Inertia 套件

尝试在 http://localhost:3333/signup 创建账户，并在 http://localhost:3333/login 登录。users 表已存在于你的 SQLite 数据库（tmp/db.sqlite）中。

对于 API 套件

身份认证端点位于 POST /api/v1/auth/signup 和 POST /api/v1/auth/login。你可以用任何 HTTP 客户端（curl、Postman 或你的前端应用）测试它们。users 表已存在于你的 SQLite 数据库（apps/backend/tmp/db.sqlite）中。

开发服务器模式 ​

  • 热模块替换（--hmr）。这是大多数开发场景的推荐方式。HMR 在浏览器中更新你的应用而无需完整页面刷新，在即时反映代码更改的同时保留应用状态。这提供了最快的开发反馈循环，特别是在处理前端组件或样式时。

  • 文件监听（--watch）。此模式会在你更改代码时自动重启整个服务器进程。虽然由于需要完整重启，这种方式比 HMR 稍慢，但它确保每次更改后应用状态都是干净的，在处理服务端逻辑或 HMR 更新不够用时很有帮助。

探索其他命令 ​

ace 命令行工具包含许多用于开发和生产工作流的命令。

要查看所有可用命令，请运行以下命令。

bash
node ace
