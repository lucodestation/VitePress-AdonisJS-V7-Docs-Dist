常见问题 ​

AdonisJS 是否在积极维护？ ​

是的，AdonisJS 正在积极维护，有定期更新、错误修复和功能添加。该框架自 2015 年以来持续开发，并得到其核心团队的持续关注。

你可以通过查看 OSS Insights 来验证维护活动，它展示了整个 AdonisJS GitHub 组织的综合指标，包括最近的提交、及时的问题讨论和发布模式。

AdonisJS 与 Express、NestJS 和 Fastify 相比如何？ ​

AdonisJS 是一个全栈、开箱即用的框架，提供完整的开箱即用开发解决方案。这与 Express 和 Fastify 的极简主义方法形成对比，也不同于 NestJS 高度固执己见的企业级架构。

与 Express 相比：AdonisJS 提供身份认证、验证、ORM 和会话的内置功能，而 Express 需要你自己选择和集成这些组件。AdonisJS 提供更多的结构和约定，而 Express 提供最大的灵活性。

与 NestJS 相比：两个框架都原生支持 TypeScript 并提供结构化架构。NestJS 强调 Angular 风格的装饰器和企业级模式，而 AdonisJS 遵循受 Laravel 启发的约定，学习曲线更简单。AdonisJS 也更快地拥抱现代 Node.js 原语（如 ESM），使其更符合当前 JavaScript 生态系统的标准。

与 Fastify 相比：Fastify 专注于以最小开销实现最大性能，而 AdonisJS 通过全面的内置功能优先考虑开发者生产力。两者都提供出色的性能，但 AdonisJS 默认包含更多功能。

当你想要一个完整的框架，在 Node.js 中拥有内置解决方案和 Laravel 风格的开发体验时，选择 AdonisJS。当你需要最大灵活性（Express）、企业级模式（NestJS）或最小抽象（Fastify）时，选择替代方案。

AdonisJS 是否可用于生产环境？ ​

是的，AdonisJS 已可用于生产环境，自 2015 年以来已为数千个应用提供支持，从小型初创公司到大型企业系统。该框架高效处理高流量场景，并默认遵循安全最佳实践。

在生产环境中使用 AdonisJS 的公司包括 Marie Claire、Ledger、Kayako、Renault Group、Zakodium、FIVB、Petpooja、Paytm、Verifiables、Pappers、Edmond de Rothschild、France Travail 等众多公司。

虽然已可用于生产，但请考虑 AdonisJS 社区比 Express 或 Next.js 社区小，这意味着 Stack Overflow 上的答案较少，招聘可能更具挑战性。然而，熟悉 TypeScript 和现代框架的开发者能很快上手，且官方文档非常全面。

该框架可成功部署到所有主要托管平台，包括传统 VPS 提供商、Docker 容器以及 Railway、Render 和 Fly.io 等现代平台。

AdonisJS 是否原生支持 TypeScript？ ​

是的，AdonisJS 从底层开始就是用 TypeScript 构建的，并提供一流的 TypeScript 支持。不同于将 TypeScript 作为可选附加组件的框架，AdonisJS 专为 TypeScript 设计并充分利用其全部能力。

当你创建新的 AdonisJS 项目时，TypeScript 已配置了最佳设置。构建系统、类型检查和开发工作流无需额外设置即可无缝工作。每个框架 API 都是完全类型化的，提供完整的 IntelliSense 和编译时错误检查。

该框架使用高级 TypeScript 特性自动推断类型，这意味着你无需编写过多的类型注解即可获得类型安全。例如，验证模式自动推断验证后的数据类型，模型自动为所有属性和方法提供类型。

TypeScript 在构建过程中被编译掉，因此没有运行时开销。你的生产代码作为优化的 JavaScript 运行，性能与手写 JavaScript 相同。

谁在维护 AdonisJS？ ​

AdonisJS 主要由 Harminder Virk 维护，他于 2015 年创建了该框架，并继续领导其开发。该框架还有一个小型核心团队的贡献者，他们帮助处理文档、包维护和社区支持等特定领域。

Harminder 全职从事 AdonisJS 工作，作为他的主要职业重点，而不是副业项目。这确保了持续的投入、及时的问题响应和定期的功能开发。该框架通过 Insiders 和 Partners 计划获得财务支持，从而实现可持续的全职维护。

虽然一些开发者担心主要由一个人维护的框架，但这种模式已被证明可持续近十年。单一维护者确保连贯的愿景、一致的代码质量和快速的决策。许多成功的开源项目（Linux、Ruby on Rails、Laravel、Vue.js）都成功遵循了类似的模式。

代码库文档完善且结构良好，便于社区贡献。该框架在 MIT 许可证下开源，确保代码无论未来情况如何都保持可访问。

我在哪里可以获得 AdonisJS 的帮助？ ​

主要支持渠道是官方 Discord 服务器，社区成员和核心团队通常会在数小时内回复。服务器有针对不同主题的专用频道，包括一般帮助、数据库问题和部署问题。

对于较长的提问或架构建议，请使用 GitHub Discussions。对于错误报告和功能请求，请使用 GitHub Issues。官方文档非常全面，能回答大多数常见问题。

为了更快获得更好的答案，请提供清晰的上下文，分享相关代码片段，包含完整的错误消息，说明你的环境（版本），并解释你已经尝试过什么。

我可以使用 AdonisJS 构建 API 吗？ ​

是的，AdonisJS 非常适合构建 API，许多开发者主要选择它进行 API 开发。该框架提供了大量专为 API 设计的内置功能，包括 RESTful 资源路由、使用 VineJS 的内置验证、多种身份认证方案、用于序列化数据的转换器、CORS 处理和速率限制支持。
