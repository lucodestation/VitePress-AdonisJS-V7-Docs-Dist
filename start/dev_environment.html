开发环境设置 ​

本指南介绍 AdonisJS 应用推荐的开发环境。你将了解到如何：

  • 配置 TypeScript 及所需的编译器选项
  • 设置 ESLint 和 Prettier 以保证代码质量
  • 安装推荐的代码编辑器扩展
  • 为本地开发选择数据库

概述 ​

AdonisJS 应用开箱即带有一套完整配置的开发环境。TypeScript、ESLint 和 Prettier 都已预先配置了合理的默认值，让你无需手动设置即可立即开始构建。

本指南解释项目中已配置的内容，推荐可提升开发体验的可选编辑器扩展，并提供为本地开发选择数据库的指导。了解这些配置有助于你充分利用框架的全部能力，并在团队中保持一致性。

代码编辑器与扩展 ​

AdonisJS 适用于任何支持 TypeScript 的现代代码编辑器。该框架不依赖自定义的领域特定语言（DSL），因此大多数编辑器开箱即提供完整的语言支持。唯一框架特有的语法是 Edge 模板引擎，它可以从专门的语法高亮扩展中受益。

AdonisJS 扩展

链接：

  • VSCode

为 AdonisJS API 提供 IntelliSense、文件生成器，以及用于运行 Ace 命令的命令面板集成。

TypeScript 设置 ​

TypeScript 是 AdonisJS 中的一等公民。每个应用默认都使用 TypeScript 创建和运行，所有配置都自动处理。了解 TypeScript 在开发和生产环境中的工作方式，以及所需的编译器选项，有助于你对部署和工具链做出明智的决策。

必需的 TypeScript 配置 ​

AdonisJS 需要特定的 TypeScript 编译器选项才能正常工作。该框架严重依赖 experimental decorators（实验性装饰器）来实现依赖注入、模型定义和 Ace 命令。

以下 tsconfig.json 配置代表了 AdonisJS 应用所需的最低要求。

json
{
  "compilerOptions": {
    "module": "NodeNext",
    "isolatedModules": true,
    "declaration": false,
    "outDir": "./build",
    "esModuleInterop": true,
    "experimentalDecorators": true,
    "emitDecoratorMetadata": true,
    "skipLibCheck": true
  },
  "include": ["**/*", ".adonisjs/server/**/*"]
}
json
{
  "compilerOptions": {
    "module": "NodeNext",

    "outDir": "./build",

  },
  "references": [
    {
      "path": "./inertia/tsconfig.json"
    }
  ],
  "include": ["**/*", ".adonisjs/server/**/*"]
}

开发模式（JIT 编译） ​

在开发环境中，AdonisJS 使用由 @poppinss/ts-exec 包提供的即时（JIT）编译器。这种方法直接执行 TypeScript 文件而无需单独的编译步骤，让你在保存更改时获得即时反馈。

这与 Node.js 原生的 TypeScript 支持不同，因为 AdonisJS 需要：

  • 实验性装饰器支持（用于依赖注入和模型装饰器）
  • JSX 编译（如果你用基于 JSX 的模板引擎如 Inertia 替换 Edge）

由于 Node.js 内置的 TypeScript 加载器不支持这些功能，@poppinss/ts-exec 提供了必要的兼容层。

生产模式（预编译） ​

对于生产部署，AdonisJS 使用官方 TypeScript 编译器（tsc）将你的 TypeScript 代码编译为 JavaScript。此过程会生成一个 build/ 目录，其中包含为 Node.js 运行时优化的转译后的 .js 文件。

bash
node ace build

编译输出包括：

  • 转译后的 JavaScript 文件，装饰器已转换
  • 复制的静态资源和模板
  • package.json 和你的包管理器锁文件。你必须 cd 进入 build 目录，安装依赖并启动生产服务器。

另请参阅：部署到生产环境

ESLint 和 Prettier 配置 ​

AdonisJS 项目包含预配置的 ESLint 和 Prettier 设置，强制执行 TypeScript 最佳实践并在团队中保持一致的代码格式。

TIP

大多数代码编辑器支持在文件保存时自动运行 ESLint 和 Prettier。在编辑器中配置此项可消除手动格式化步骤，并立即捕获 lint 问题。

ESLint ​

默认的 ESLint 配置扩展了 AdonisJS 基础配置，其中包含针对 TypeScript、async/await 模式和框架约定的规则。你可以根据需要在 eslint.config.js 中覆盖或扩展这些规则。

js
import { configApp } from '@adonisjs/eslint-config'
export default configApp()

手动运行 ESLint：

bash
npm run lint

Prettier ​

Prettier 配置定义在 package.json 中，确保所有文件的格式一致。AdonisJS 预设包含针对缩进、引号和行长的合理默认值。

json
{
  "prettier": "@adonisjs/prettier-config"
}

手动运行 Prettier：

bash
npm run format

另请参阅：ESLint 配置参考、Prettier 配置参考

数据库设置 ​

AdonisJS 应用预配置了 SQLite，一个轻量级的基于文件的数据库。SQLite 无需安装，将数据存储在本地 tmp/database.sqlite 文件中，让你无需设置外部数据库服务器即可立即开始构建。

然而，大多数应用在生产环境中使用 PostgreSQL 或 MySQL。我们建议在开发早期就切换到你的生产数据库引擎，以避免模式差异和驱动特定行为导致的部署问题。

本地数据库工具 ​

你可以使用以下工具在本地运行 PostgreSQL 或 MySQL：

  • Dbngin（macOS 和 Windows），通过 GUI 管理 PostgreSQL 和 MySQL
  • Docker，在隔离容器中运行数据库
  • Postgres.app，在 macOS 上使用原生 PostgreSQL
